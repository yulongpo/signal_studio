# 当前界面增量与复核流程

状态：待审核设计。交互依据为当前项目、指定原型与本轮要求；其他会话只提供模型能力参考。统一标记数据契约见 [06](06_UNIFIED_ANNOTATIONS.md)。

本篇定义原生界面目标；[07 原型与交互评审](07_PROTOTYPE_AND_INTERACTION_REVIEW.md) 列出原型保留/调整项、10 类页面状态、24 条操作脚本及 M0-P 交付要求。原型先验证这些交互，再独立实现 Qt；FFSCN_TEST_GUI 能力依据见 [08](08_FFSCN_TEST_GUI_CAPABILITIES.md)。

## 1. 界面落位

| 区域 | 拟议增量 | 约束 |
|---|---|---|
| 文件/标记菜单 | 导入样本标签、导出标记、来源管理 | 标签绑定到明确的文件和样本通道；不覆盖源标签 |
| 分析菜单、宽带范围条 | `宽带信号检测…`；快捷键实施时检查冲突 | 无文件时进入现有工程/信号入口 |
| 主图工具、右键 | 手动标记、框选检测 ROI、检测活动标记、编辑所选标记 | ROI 与创建标记是明确互斥的工具；保留既有持续手动标记能力 |
| 右侧参数栏 | 可折叠“宽带检测”卡片；选中标记时显示详情与来源 | 检测卡片主要显示方案、范围、开始/取消和进度；不永久占满参数区 |
| 左工程树 | 标记按原始标签/手动/算法来源集合分组；检测运行只显示摘要 | 大集合显示数量、可展开摘要和进入表格入口，不为全部算法候选创建树控件 |
| 主图 | 原始标签、手动、算法三来源图层；待复核/已确认/已拒绝是状态过滤 | 接受算法结果不生成第二个框；局部详情与全局导航保持物理坐标一致 |
| 底部 | 将“当前文件结果”升级为“标记记录”；保留“后台任务”“日志” | 一张统一表，来源/运行/复核状态过滤；不再另开一张孤立检测结果表 |
| 窄带工作区 | 显示关联标记的来源、创建时修订及是否已变化 | 保留现有真实 DDC 与示例能力标识 |

```text
工程树                 全局导航与辅助图                  右侧参数
 文件                  宽带时频图 / 瀑布图                检测方案与范围
  标记                  原始标签 / 手动 / 算法图层         运行状态
   原始标签集合         选中标记及其原始/修订边界          标记详情与证据
   手动
   算法运行            标记记录 | 后台任务 | 日志          原有显示参数
  窄带通道
```

沿用品牌、字体和暗色视觉语言。来源用颜色与图例区分，复核/编辑状态用线型、图标和文字区分；颜色不独自表达语义。标记密集时只显示选中/悬停文字，概览使用聚合密度提示，不把抽稀后的显示数量称作存储数量。

当前底部展开固定 150 逻辑像素，只适合摘要。升级后支持垂直拖动并保存高度，建议初始约 240 逻辑像素、收起保持现有紧凑栏；最大高度受主图可用空间约束。在指定 2560×1440 逻辑工作区核验表头、过滤栏、可见行数和主图，不通过压缩字体塞入所有字段。标记记录保留文件/通道数量摘要与通道入口；后台任务同时保留现有加载、谱计算和窄带处理状态，不能被检测状态覆盖。

## 2. 检测方案与参数

普通入口选择“检测方案”。摘要说明适用输入、已验证状态、频率间隔、真实分析窗长、帧步长、模型上下文。高级区只开放该 profile 声明可修改的参数；模型文件/hash、预处理版本和设备信息放详情。模型缺失或不兼容时显示具体原因，不能用演示结果代替。

首个方案按 FFSCN_TEST_GUI IQ 主线设计；时间处理可选择粗定位、sample 包络精修或 ROI 精修，拆分开关单独表达。卡片只启用当前分支真正使用的最短活动/静默等参数；FFT 窗、谱步长、模型上下文和窗口滑动用分行的物理时长卡展示。后处理变化产生派生 run，可复用原始模型输出但不原地改旧结果。

显示 PSD/STFT 参数与检测计算参数独立。分数筛选只隐藏结果，不改变已存模型输出；改变推理或后处理门限须创建新 run/派生 run。字段名称用“模型分数”，提示未经校准时不等于概率；没有该值的手动/标签标记显示“—”。标签 SNR/CNR 和算法估计值分列，不相互覆盖。

沿用 `ui/parameter_input.h`：Enter、Tab/Shift+Tab、同窗口点击其他控件提交；输入过程、应用失焦、后台刷新不提交。滚轮不改值；卡片滚动和图谱缩放保留。切文件/通道/工程撤销未提交草稿。“运行”先提交合法草稿并冻结快照，失败则定位字段。切方案恢复各自已提交参数，不能把其他模型的阈值带入。

## 3. 范围、工具与预检

首期一个任务一个矩形。默认“当前可见区域”，另提供全部可用数据、活动标记的一个明确活动段、框选 ROI。多选标记不隐式取包围盒；多个突发之间的空隙不能因此成为请求中的活动时间。范围提交后固定，不追随视图。

时间与 `[0, availableSamples)` 相交，频率与有效分析频带相交。Loading 先等待结束或由用户停止得到 Partial；Partial 显示可分析前缀，尾部保持“未分析”。Failed、空范围、演示源不能进入真实检测。原始标签可记录未加载但物理存在的后续样本，不能据此扩大检测可用前缀。

ROI 工具进入时暂停手动创建手势；确认/Enter 提交、Esc 取消，完成后恢复原工具。ROI 不创建标记。命中顺序为活动工具控制点、选中标记、其余命中对象、背景；重叠对象弹出来源/名称选择列表。拖动只读来源框不会直接改变原始记录，须先进入“创建修订”。

预检显示格式/通道、实际范围、完整时间槽数量、真实观测时长、模型资源及边缘截断。报告范围与上下文范围分开：可在 ROI 外读取必要上下文，但不得越过可用前缀；保留未裁切估计，输出注明 `clippedAtRoi`。缺上下文按 profile 明确拒绝/部分覆盖，不能重复帧凑时间。

实数 ADC 仅允许明确通过实数验收的方案。沿用实数 `0…有效单边带宽` 坐标与不可创建复数 DDC 通道的约束；文件 Fc 不能被重复叠加。复数模型不可因 reader 能读取实数而解锁。

## 4. 任务体验

常驻显示状态、已处理/计划窗口、输出标记数、耗时；详情显示读取、谱生成、推理、时间定位、落盘计数。流水线并发推进，进度不由模拟定时器产生。取得稳定实测吞吐后再显示 ETA。

| 场景 | 行为 |
|---|---|
| 浏览另一文件 | 同工程任务继续；当前图只取当前文件标记；任务列表可定位源文件 |
| 缩放、配色、切辅助图 | 只更新投影，不重新推理 |
| 修改计算参数 | 修改下一次任务草稿；运行快照不变 |
| 重复点击运行 | 执行中的同配置请求去重；已完成后重跑创建新 run |
| 取消执行中任务 | Cancelling，到安全边界停止；保留已完整发布片段并标注部分覆盖 |
| EOF | flush 后完成；显式统计尾部不能检测区间，不自动循环 |
| 读错/源变化 | Failed/来源已变化，不能当空结果或正常 EOF |
| 切工程/关闭/删除来源 | 回收该工程任务后再完成操作；旧回调不得进入新 projectGeneration |
| worker 崩溃/超时 | 保留完整片段与错误；标记编辑、图谱和已有通道仍可使用 |
| 重开工程 | 恢复历史结果；未结束任务标为 Interrupted，不自动推理 |

首期不提供暂停和跨进程精确续算。取消后重跑可使用校验过的缓存，但不得标作断点续算。

## 5. 标记记录、复核与编辑

统一表首屏列为：选择、来源、复核状态、名称/类别、起止/时长或时间质量、中心频率、带宽；算法来源默认显示平均模型分数，来源混合时无值显示“—”。最大分数、窗口命中/覆盖、CNR、运行、修订、通道状态在详情或可选列中；不把窗口覆盖率当时间占空比。对时间未定位结果，起止为“—”，观察窗口另列；图中使用虚线频带与观察范围底纹，不绘制确定发射时间矩形。

过滤条件包含三来源、来源集合、run、状态、频段、时间、带宽和已建通道。树、表、图共享 annotationId/segmentId。双击定位该活动段；批量操作明确列出选中数量，筛选不会隐式选中所有隐藏行。表格数值排序、分页，图上空间索引裁剪。

原始标签默认锁定；手动标记可直接编辑；算法标记默认待复核。原始标签或算法框的编辑先进入修订模式，保存后只更新该 Annotation 的当前修订，原始边界可按需对照。接受/拒绝改变复核状态，不复制框、不改变 sourceKind。人工修订未自动证明算法准确。

首期包括单段移动/缩放、数值编辑、手动新增/删除活动段、单对象拆分/合并活动段、命名/备注、接受/拒绝/撤回、撤销/重做。合并仅限同一 Annotation 中满足条件的活动段；跨来源或跨 run 自动合并、批量智能修边后置。拆成独立对象时必须记录 derivedFrom，不能伪造新原始标签。

参数框编辑遵守同一提交规则。拖拽预览在松开后形成一次原子命令，Esc 取消；频率/样本边界合法性失败不得部分写入。标记撤销栈与视图历史分离。来源集合被删除时先检查引用，默认从视图移除并保留被通道引用的证据。

## 6. 证据与通道

选中算法标记可查看原始/修正频带、累积谱、噪底门限、时间能量轨迹、窗口覆盖与修订差异。选择标签显示原始字段、坐标转换与解析诊断。证据预览不触发模型，检测帧编号与显示 STFT 帧编号分开。

算法详情明确区分粗观测、sample 成功、ROI 成功和 fallback；原始结果未可靠定位时提供人工范围修订，不把 fallback 标成精修成功。指定真值集合后可查看二维时频 P/R/F1 与匹配，评价需显示来源/修订/阈值版本，并与频率评价分开。

仅已确认、时间/频率范围明确的标记活动段可建通道；手动标记创建完成即为人工确认，导入标签与算法结果默认待复核。未定位结果可通过明确的“采用观察范围”人工修订进入此流程，必须保留其范围是人为选取这一事实。

通道仍进入现有参数弹窗，校验源格式、保护带、输出率、滤波与范围。默认按一个活动段创建；不把多突发包围盒当连续有效信号。通道保存 annotationId、revisionId、segmentId 和创建时范围快照。后续编辑/拒绝/重跑只显示“来源已变化”，不后台删除或重算 DDC；更新通道由显式命令完成。

## 7. 典型验收旅程

1. 导入真实信号及配套标签 → 查看三来源图层和标签字段 → 创建一条手动标记 → 修订标签边界 → 撤销/重做 → 保存重开，原始值和修订都保留。
2. 检测可见区域 → 运行时缩放 → 统一表新增算法来源集合 → 查看证据 → 接受同一标记 → 无重复框 → 建真实 DDC → 修改该标记后通道显示来源变化。
3. 标签包含多个短突发 → 显示多个活动段与组关系 → 检测分别定位 → 间隔不画成连续发射；标签范围超过 Partial 前缀时仅标不可用，原始标签不截断。
4. 模型缺失/取消/崩溃/切工程 → 标签和手动编辑继续可用 → 历史任务保留覆盖事实，不显示“全文件未发现信号”。
5. 大来源集合导入 → 表格与图层按视区工作 → 数量可核对 → 过滤后批量操作不会修改未选对象。

未来原生视觉验收仅在第二连接屏 Redmi 27 NU、DISPLAY6、3840×2160 物理、150% DPI 的实际全屏窗口完成，记录连接序号、名称、设备路径、物理/逻辑尺寸；分别验证 D3D11 与软件回退。本文示意不是原生截图验收。
