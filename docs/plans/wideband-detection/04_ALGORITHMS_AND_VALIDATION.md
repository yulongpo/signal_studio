## 2. HY epoch-210：保留独立历史频率基线

### 已有数值依据

本地 `reports/eval1000_timefps1ms_20260908/REPORT_1000.md` 记录：1000 个互不重复的 60 Msps、10 ms WAV；45679 个真值载波、46497 个预测频带。评价按一行标签一个载波，不重复计其多个突发，只评价频率的一对一匹配。

| 频率 IoU | Precision | Recall | F1 |
|---|---:|---:|---:|
| ≥0.3 | 96.21% | 97.94% | 97.07% |
| ≥0.5 | 94.74% | 96.43% | 95.58% |
| ≥0.7 | 88.83% | 90.42% | 89.62% |

IoU≥0.5 已匹配目标中心频率 MAE 9.84 kHz、带宽 MAE 39.62 kHz；漏检不进入 MAE。报告不是全新盲测，不含时间/类别效果。两张 RTX 3090 吞吐约 0.88 文件/s，单个 10 ms 文件平均 2.257 s、P95 2.605 s，不能描述为实时检测。本次只核对报告，未复跑这些数值。

冻结身份：epoch-210 权重 SHA-256 `b6cd6aaf28e695b4bcae94db25dd527d2b717269b1562cf47e0840d09d8a253a`；主脚本 `593ff4a6653678c33a5a2c673f13a5693de95597277ba303c749fa3f7c1bb1de`。哈希来自报告，不表示本机正式部署已可用。

历史配置包括 broad_nfft `[16384,65536,393216]`，1 ms 时间槽、10 帧，切片 `[4096,8192,16384,32768,65536]`、75% 步进，模型输入 `[1,10,65536]`，score=0.4、NMS=0.25、噪底+2 dB、min-support=0.1、max-gap=0.1、smooth=9。多 FFT 分支独立计算后以 Hz 融合，不可删掉大 FFT 分支却引用原指标。

### 本次发现的预处理分歧

`docs/STFT_TIME_FPS_1MS.md` 与冻结评估路径描述：当一个 1 ms 时间槽含多个 FFT 记录时，先平均复数 FFT 再转功率；当前 `FFSCN_TEST_GUI/algorithm/stft.py` 已改为先算各 FFT 功率再平均，并按 `Fs*sum(window²)` 做 PSD density 归一化。两条路径数值不同，不能将新路径称为原评估的等价移植。

因此将 `hy-ffscn-legacy-eval` 与主线 `ffscn-gui-iq-v1` 严格分开；后者的参考权重、窗口与后处理也不同，不能描述成只改了 PSD 归一化的 epoch-210。历史兼容不代表推荐保留相干抵消问题；修正也不能免除输入分布与准确率复验。各自的 periodic Hann、FFT 边界、padding、dB 下限、切片插值、归一化、解码/融合顺序都形成独立 golden。若将来另做 epoch-210 修正谱实验，须新 profile，不占用 GUI 主线身份。

功率谱 density 与 spectrum 的归一化含义不同，须按窗口能量和采样率明确。只有输入幅度确已按满量程规范归一化，才允许标为 dBFS/Hz；任意 cf32 数据不能自动套用该单位。[SciPy periodogram 定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.periodogram.html)

当前 GUI 默认权重 epoch-1200、score=0.7、NMS=0.3 等也不同于历史评估。后处理 percentile 噪底/支持区间修正与 SCN 邻带最小值规则分别属于各自 profile，不统一替换。首期 M0 先明确权重、输入和后处理的完整组合，M3 同源对照后选正式默认。

## 3. SCN 最大谱对照契约

依据当前 `scn_dev` 工作树：累计平均谱和最大谱，但**只用最大谱做模型推理**；平均谱不得额外跑一支。当前参考参数为累积 16 帧、模型长 32768、步进 16384、score=0.4、NMS=0.5、topK=200、maxCandidates=150、CNR=3 dB、带宽裕量=3 dB；正式 profile 仍需冻结源谱单位/归一化和权重。

处理顺序为 CNR 过滤、跨窗融合、带宽修正、跟踪。对融合后的每条候选，以 `max(1,floor(bandwidthBins/10))` 作为两侧邻带宽度；邻带排除全部融合候选覆盖区域，从平均累积谱的有效邻带点取**最小值**作为噪底，不能取均值。门限为该噪底+裕量；在原候选内部用最大谱找达门限的首末点，只向内收缩。

没有有效邻带、邻带全被占用或带内无有效达标点时保留原边界并记录 skip reason；不把空集合最低值变成阈值，不向外扩大范围。后续显示/复核筛选不得改变噪底屏蔽集合，否则隐藏一个标记就会改变另一条结果。

该能力只能说明一定观察窗口内存在载波。平均/最大谱生成方式、dB 或线性累积语义、尾窗填充、3 点峰值解码、score/NMS 的边界比较必须在 M0 形成逐阶段 golden。历史 SCN 测试存在 `scn_session` 未通过记录，不能宣称参考工程全测已通过，也不能替代本项目测试。

## 4. FFSCN-17 实验契约

参考固定提交 `649cc247f948d8ef71975c9ae1ed4675e12bb68a`，epoch-155 checkpoint 与 HY 权重独立。谱输入 `[1,1,10,N]`，hm/bw/off 输出 `[1,1,1,N/4]`。最近 10 个真实帧从旧到新排列；短谱插值保持原物理 span，不能将重复谱行当作 10 帧。

支持 N 为 `{8192,16384,32768,65536,131072}`。短谱选择按原 bin 数到支持宽度的**绝对差最近**，等距向上，不是 log2 最近，也不是一律向上取整；例如 10000 → 8192。插值位置为 `i*srcCount/dstCount`，末端 clamp。超过 131072 的谱使用 131072 窗、65536 步，尾窗末端锚定并去重。整个 10×N 张量使用样本标准差 ddof=1 归一化，常量输入归零，非有限值报错。

该分支是 7 点局部峰、score 严格大于门限、NMS 严格大于阈值；SCN 参考是 3 点峰及不同边界比较，不共用无差别解码器。参考 score=0.7、NMS=0.3、topK=512。

历史 engine 为 FP32、TensorRT 10.11/CUDA 12.9、RTX 5060 Laptop 环境，模型 downNums=13、MobileNetV3 large、FPN=64。manifest 中 ONNX SHA-256 为 `113d9d64955695790647c26f0d426aa96216f2fc744423a12f21198720fd5867`，engine 为 `dd88ab057d5af35e412447428de1a0163f79d0d7ac6a5c1a86308b898d50fd81`。

合成验证中 N=8192 原张量通过 atol=1e-4/rtol=1e-3；N=131072 存在 hm 263 项、bw 1 项超差，尽管解码候选均为 2 个且边界接近。FP16 曾出现 3 vs 2 候选，因此没有作为交付精度。不能用最终数量相同覆盖原张量不一致；该路径目前只列实验，后续逐 shape 判定。

TensorRT engine 的平台、版本、GPU 兼容依赖其构建选项，不能默认从原机器复制即用；部署预检应记录兼容模式及目标环境，必要时在授权实施阶段重新构建并验证。[NVIDIA 支持矩阵](https://docs.nvidia.com/deeplearning/tensorrt/latest/getting-started/support-matrix.html)

## 5. 时间定位与目标关联

神经网络前向主要提供窗口内频带；**FFSCN_TEST_GUI 的整条处理链已经能输出时间事件**，不能把它等同于仅有频带候选。首期独立实现其跨窗关联/碎片拼接、STFT 粗定位/带宽修正，以及可选择的 sample 包络和 ROI 两种精修策略，最后去重并发布多活动段。每一方法记录有效参数、门限、最短开/关持续时间、滤波/窗支持、精修状态及失败原因；失败保留粗估计或 WindowObservation，不伪造精确矩形。

当前 GUI 的粗帧 min_burst=10 ms/split_gap=20 ms 与细化 min_on=5 ms/min_off=10 ms 属于不同生效分支，细化启用时不先跑粗时间过滤。不能把它们当成四个同时起作用的门限。默认配置仍不能直接证明覆盖生成器的全部 1–8 ms 突发；短突发 profile 须单独评估，两个突发的间隔不能因跟踪或拼接直接当成持续发射。

长 FFT 的观测支持往往大于帧步长，模型 10 帧上下文也不总等于恰好 10 ms 独立信息。时间误差报告要区分窗口/滤波误差、标签文本量化和模型定位误差。TorchSig 样本级边界可提供更精确对照，但 `train/baseline/0000000` 仅作为导入及联动夹具，不能单独承担盲测或泛化声明。

同频持续活动可以保持 trackId；活动消失后封闭段，重现生成新 segment；跳频/交叉目标保留多段和关联置信度，首期不宣称能正确恢复 emitter 身份。标签提供的 emitter_id 可用于对照，不输入算法替算法关联。

## 6. 数据分布与评价口径

生成器 60 MHz/10 ms 的历史测试与 10 MHz/20 ms 的新配置分开；后者配置 20000/4000 不代表完整数据已生成，当前报告只验证了小批量。60 MHz 批次曾包含不符合排除要求的 GMSK，正式验收必须按 manifest/标签审核实际构成，不能直接认定干净。

建议四组数据：G 为 GUI 10 文件时频基线（M0 核实能否完整恢复，否则新建并命名基线）；H 为原冻结 1000 文件频率回放；L 为两类标签的导入及联动 golden（含指定 TorchSig 样本）；T 为实施时锁定的独立 holdout，覆盖纯噪声、低 CNR、极窄/极宽、密集/重叠、频带边缘、同频间歇、长持续、1–8 ms 短突发及真实采集。split/seed、IQ/标签 hash、profile、评价器版本、坏文件清单一起冻结，分域报告。

GUI 时频评价在每个阈值独立求一对一匹配，优先最大化满足阈值的匹配数，再最大化这些匹配的 IoU；真值与预测在同一 RF/基带坐标和样本时间范围。旧频率评价和最初审计的匹配方法保留各自版本，不静默重算后沿用原指标名称。

频率评价保留 IoU=0.3/0.5/0.7、P/R/F1、匹配成功的中心/带宽误差及漏检数；时间事件另报时间 IoU、时频 IoU、起止误差中位/P95、分裂/合并率、未知时间比例。纯噪声报告每 MHz·s 误报及每文件误报，包含零检测文件。按 CNR/SNR、带宽、时长与来源分层；分数不是概率，未经校准不写“90% 可信”。

模型只输出定位时，类别列保持未知；原始标签类别和人工备注带来源显示，不暗示完成真实调制识别。不得用修改后的人工标签替换原评估真值而不披露版本。

## 7. 验证顺序与退出门槛

| 层级 | 核心验证 | 通过标准 |
|---|---|---|
| L0 数据与标签 | 两类解析、字节/采样/频率映射、多段与来源 | TorchSig 本例恰好 4 条、样本精确一致、频率转换在已定义容差内；TXT 量化可解释，无静默丢行 |
| L1 预处理 | 整块/多种分块、ROI、FFT/归一化/插值逐阶段 golden | 整数映射/数量精确；浮点容差按 dtype/阶段在运行前冻结；不能用宽松最终框阈值吞掉前处理错误 |
| L2 推理 | 相同输入张量参考运行时与目标部署运行时 | 逐 shape 原张量误差报告、解码数量/排序/边界一致性；临界门限样本单列；超差配置保持实验 |
| L3 算法效果 | GUI 同源处理链迁移对照、独立 holdout；HY 频率另报 | 同一冻结数据和评价器下，GUI 主线 TF-F1@0.5 下降不超过建议 1 个百分点，并报告分组与按文件 bootstrap 差值区间；不能拿 H 集频率 F1 代替 G/T 集时频验收 |
| L4 时间能力 | sample/ROI/粗定位/不拆分组合；短突发/间隔、边缘/重叠 | 两种精修方法和 fallback 语义可复现；建议短突发专集事件 Recall≥90%、起止 P95≤1 ms 作为首轮目标，未达到则明确时间能力未完成，不用手动修边抵消漏检 |
| L5 产品/部署 | 真实文件→推理→统一标记→DDC→重开；取消/故障/大集合 | 见 05；无假结果、无坐标串用、无源/工程污染 |

L3 的 1 个百分点和 L4 的数值是本次提出的审核目标，不是历史承诺；M0 冻结数据与定义后执行，不能看到结果后改门槛。精确时间定位失败时可交付明确标示的窗口级检测，但应在本期验收清单中将时间定位标为未完成，不能以手动圈框代替其通过。
