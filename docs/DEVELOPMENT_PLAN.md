# Signal Studio 开发计划

## 1. 项目状态

- 当前产品版本：V1.0 目标版本
- 当前需求基线：SS-SRS-BL-1.0，正式生效，只读
- 当前开发阶段：M1 宽带浏览基础
- 当前里程碑：M1
- 当前主要任务：明确最小架构，验证大文件访问、图谱渲染、STFT 缓存和任务调度方案
- 最后更新时间：2026-07-15

## 2. 总体里程碑

### M1 宽带浏览基础

IQ 文件导入、RAW 格式配置、大文件分块访问、时域/频谱/STFT 显示、缩放和平移、游标和选区、基础缓存、基础任务调度、基础项目保存。

### M2 宽窄带联动闭环

信号区域、窄带通道、DDC、滤波、抽取、重采样、窄带图谱、双向定位和项目恢复。

### M3 专业分析能力

参数估计、星座图、眼图、调制识别、多通道对比、模型推理和结果导出。

### M4 工程化发布

性能优化、稳定性、崩溃恢复、安装包、用户文档和发布测试。

## 3. 当前迭代

- 完成条件：形成可执行设计，明确待验证指标，并为实现和测试建立追踪入口。
