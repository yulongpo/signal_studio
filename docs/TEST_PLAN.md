# Signal Studio 测试计划

## 1. 测试目标

验证 BL1.0 的功能、DSP 数值、性能、稳定性、兼容性、项目恢复、异常处理和安装发布要求。当前为测试计划，未声明任何测试通过。

## 2. 测试环境

目标平台为 Windows 10/11 x64；需求基线给出 Qt 6.11、MSVC 2022 x64、CMake。具体 CPU、GPU、磁盘、Python/CUDA 版本和参考数据集待确认。

## 3. 测试分层

- 单元测试：坐标、格式解析、DSP 节点、序列化。
- 集成测试：读取、缓存、渲染、任务和项目服务。
- UI 核心流程测试：导入、宽带浏览、区域、通道和恢复。
- DSP 数值回归：与参考实现和固定数据比较。
- 性能测试：首帧、FPS、内存、吞吐、缓存和多通道。
- 稳定性测试：长时间交互、取消、故障注入和恢复。
- 安装与发布测试：安装、升级、卸载、依赖和 CPU 回退。

## 11. RAW IQ 测试数据约定

本轮只定义方案，不生成或提交大型二进制文件。仓库尚无明确 Python 工具体系，因此暂不创建生成脚本。

建议结构：

```text
tests/test_data/
├─ README.md
├─ manifests/
└─ generated/
```

`generated/` 应加入 `.gitignore`；`manifests/` 保存参数和 SHA-256；小型固定样本可提交，大型性能样本只生成不提交。生成器应使用确定性参数和固定随机种子，优先使用 Python 标准库与 NumPy（若后续仓库确认可用）。

至少定义以下样本：Int8 Little Endian IQ、Int8 QI、Int16 Little Endian IQ、Int16 Big Endian IQ、Float32 Little Endian IQ、带文件头偏移、空文件、只有文件头、缺少一个分量的文件尾、多余字节、最后一个样本、越过文件尾、超大样本索引、可验证递增 I/Q 序列和复正弦信号。

每个 manifest 至少记录文件名、数据类型、IQ/QI、字节序、头偏移、样本数、采样率、中心频率、预期前若干样本、SHA-256 和生成参数。
