# 标记交互统一与窄带通道流程实施计划

依据：本会话用户明确要求执行的 U0–U4 方案。工作分支 `rebuild/a143-native`；启动基线 `a69a68e5b3b7994ebfada013397e58ae154a41da`。不读取或合入 `rebuild/m5-final-deepseek`。本轮不改变宽带模型、输入适配、检测参数或 worker 协议。

## 节点与执行边界

| 节点 | 实现与自检 | 退出条件 |
|---|---|---|

| U1 选择与展示 | Qt/domain 统一所选 ID、当前对象/段、锚点和悬停；一致筛选、跨页定位、左树按需加载、来源色与选择高亮分开 | 排序/分页/过滤/重叠/多段/视区外定位及持续发布通过相关回归，本地提交 |
| U2 编辑与删除 | 三来源自动修订、主表编辑、完整范围草稿、图形修改、撤销、筛选内批量软删除；原始证据不变 | 三来源操作一致；无逐字段非法中间态、输入 Delete 误删或隐藏选择误删；一次命令可撤销；本地提交 |
| U3 通道与持久化 | 可选质量；统一通道请求、字段诊断；LocatedSegment/UserRange 快照；原生工程 v6、兼容 v1–v5、首次升级备份与原子发布 | Pending/Rejected/未定位时间经有效配置可生成真实 CPU DDC；Partial、物理映射、保存重开、旧工程迁移通过；本地提交 |
| U4 综合验收 | 项目现有 Debug/Release 构建、CTest、原生脚本截图、GPU显示与软件回退；少量代表性真实 IQ/DDC；文档、README、复审 | 指定第二屏 4K/150% 全屏证据完整，能力及限制准确；本地提交后统一推送当前分支 |

每节点严格按“实现 → 自检 → 必要修复 → 复审 → 本地提交”完成，之后再开始下一节点。最终统一推送，不以旧节点或浏览器证据替代新 Qt 验收。U0 等待用户确认是本方案自身的退出条件。

## 已确定的产品规则

1. 选择限定当前文件/样本通道和当前筛选，跨页保留；全选覆盖全部匹配。缩放不修改选择，单击对象不自动缩放，定位才改变视区。图、表、左树共享 ID 和当前活动段。
2. 三来源同等直接编辑，自动修订同一对象；`origin`、`sourceKind` 和原始检测证据不可变。主表每行一个对象，范围为当前段；时间未定位对象只编辑频率，保留未知时间。
3. 批量删除明确对象/段/通道数量；软删除和段删除名称不同，最后一段删除按对象删除处理。通道保留创建快照；撤销只触及本次对象，不能删除之后后台发布的结果。
4. 质量标记 Pending/Accepted/Rejected 显示“待判断/已采纳/已忽略”，不作为编辑或通道门槛。名称、备注和质量不使通道失效；几何/段结构变化恢复待判断，绑定几何变化才显示差异。
5. 统一通道入口一次绑定一个对象。有定位段默认当前段，可裁剪；无段时默认可见时段与可用前缀交集，空交集仍打开配置并给出具体原因，显式选择前缀才扩大范围。UserRange 不回写成算法活动段。
6. 数据源身份、可读范围、物理坐标、复数 DDC、滤波保护带和重采样能力仍真实校验。已知 WAV 元数据冲突需修复元数据路径，不绕过来源检查。
