# U0 相对获批 M0-P 的局部修订

本表只记录用户本轮明确要求的标记交互修订；不修改冻结 `docs/prototype/wideband-detection-r1/`。旧 README 中的默认模型参数属于历史配置，仍以当前原生 R2/R3 输入适配版本为准；U0 不调整算法。

| 原 M0-P 依据 | 本次获批修订 | U0 可检查入口 |
|---|---|---|
| P06/P07、I09：标签/算法先“创建修订”再编辑 | 三来源直接图形/数值修改，自动修订同一 ID，原始来源和证据保留 | 图中拖当前段；表格双击/F2；右侧完整范围编辑和原始证据 |
| I07/I11/I12：共用 ID，但左树预览、表格选择及范围表达不一致 | 一份选择集合、当前对象/段、锚点与悬停；跨页保留，过滤/关层剔除，全部匹配全选；树按需加载并按 ID 定位 | 三处选中与悬停；260+ 场景；分页、排序、来源和质量过滤 |
| I18/I19：对象/多段细节分散 | 一行一个对象，几何列明确当前段；只当前段显示控制点，多段全体高亮 | Manual/ALG 01 第二段按钮、主表“第 2/2 段”、拆分/合并/删除 |
| I10/I22：Review 和段确认与通道前置混在一起 | 质量标记可选；文字不重置质量，几何/结构恢复待判断；质量变化不影响通道可创建性/范围关系 | 次级质量菜单；改名/备注与已有通道“范围一致” |
| I22：先确认当前段，未知时间结果拒绝创建 | 无需接受/段确认/创建修订；LocatedSegment 绑定当前段；UserRange 人工指定提取范围，允许无 segmentId | 三处右键及统一通道按钮，默认 ALG 02；视区未读尾部场景 |
| I22：修订编号不同即可显示 changed | 比较绑定几何和物理来源；名称/备注/质量的修订差异不等于通道失效 | ALG 01 已有通道，分别文字/几何修改、删除/撤销 |
| I11/I19：删除对象/删除段入口语义不足 | 当前筛选内批量软删，预览对象/段/通道；一次撤销；最后一段明确按对象删除 | 两对象多选→删除所选；Manual 删除当前段/最后一段 |
| I23：旧 demo/原生版本 | U0 仅用独立 demo v6 展示快照兼容规则；未来 U3 才做原生工程 v6、旧版迁移和原子备份 | 保存/重开浏览器演示；JSON 含 demoOnly，不能导入为原生工程 |

保留：工程树、全局导航、辅助图、主图、右侧详情及底部记录布局，三来源色，物理 RF/时间轴，时频/瀑布轴方向，单对象多段，原始证据，不合并跨对象；空白拖框缩放、坐标轴平移、持续手动标记、重叠命中列表；Enter/Tab/应用内焦点提交、Esc 取消、应用失焦/后台刷新不提交、切文件取消草稿、参数滚轮保护。检测入口/任务/ROI/模型参数沿用已批准实现，局部原型仅链接旧页面，不以静态摘要替代后续 Qt 真实检测卡。

U0 不演示真实导入、worker、文件访问、FIR 输出或原生迁移。通道表单检查和示意的“CPU DDC/FIR”是未来实现契约，成功仅创建演示快照。
