# U0 独立复审记录

日期：2026-10-15。对象为独立局部原型 `docs/prototype/annotation-interactions-u0/` 及两个自检入口。主 Agent 根据会话中两次独立复审整理；不表示用户已确认原型。

## 规格复审

只读复审 Agent：`/root/u0_contract_review`。以用户本轮 U0–U4 方案及 [M0-P 修订对照](M0P_DELTA.md) 为依据，独立 Edge 定点操作，未修改文件、运行 Qt/GPU 或进入 U1。

首轮发现并修正：

| 问题 | 最终处理及复验 |
|---|---|
| 整文件快照撤销会删掉之后发布的结果，回退视图/文件 | 改按 Annotation/Channel ID 差异撤销；之后发布、视图、物理来源和当前文件保留，跨文件行为有直接断言 |
| 空白拖动改成平移，坐标轴没有原有行为 | 恢复 M0-P 空白拖框缩放、轴拖动平移、轴滚轮仅缩放对应物理维度；缩放不更改选择 |
| 排序使用多段包围范围，与主表当前段不同 | 起止、频率、带宽按当前段；未知时间双向排序置尾 |
| 拖动失焦后松鼠标仍提交几何 | blur/Esc/pointercancel 取消捕获和草稿；平移预览回滚；文本草稿失焦仍保留不提交 |
| 保存→刷新→重开→追加结果产生重复 ID | 追加时核对全部文件已占用 ID，含软删除对象；再次保存重开成功 |

最终结论 **SPEC_PASS**，无剩余交付阻断。独立复验上述路径、Partial 人工范围不回写算法段/原始来源，未出现页面异常。Window blur 是浏览器事件级检查，不宣称原生 OS 切窗验收。

## 质量复审

只读复审 Agent：`/root/u0_quality_review`；规格通过后开始。首轮结论 QUALITY_FAIL，实际独立 Edge 操作发现三项问题，均修正并定点复验：

| 问题 | 最终处理及复验 |
|---|---|
| 删除对话框“取消”或“×”按 Enter 误确认删除 | 只有文本输入的 Enter 执行默认提交；按钮保留自身语义。取消/关闭不删除、不生成撤销命令 |
| 草稿提交时重绘，吞掉随后表格/树/详情的首次点击 | 提交状态后延迟 DOM 刷新至本次点击目标处理完成；一次点击同时完成提交及目标操作 |
| 未改数值也通过中心/带宽往返生成浮点几何修订 | 仅修改目标字段对应的物理量；未修改字段精确保留，完整范围也保留未变轴；无操作不生成修订，时间修改不重建 Hz |

另定点复验后台发布保留编辑器焦点、当前行不被 sticky 表头遮挡、无页面异常。共 7 组质量定点复验通过，最终 **QUALITY_PASS**。

最终完整回归曾因 HTML 排版空白导致“未知时间 —”文本严格比较失败；改为比较规范化可见文本，不放宽数值排序要求。最终结果以 [验证记录](VALIDATION.md) 和归档原始 JSON 为准。

## 用户确认边界

方案的 U0 退出条件为“对照现有 M0-P 明确列出修订，用户审核确认”。因此本地提交后交用户审阅；**用户未确认前不开始 U1–U4，不推送本节点**。

页面只保存浏览器演示状态。原生选择层、编辑层、真实 CPU DDC、工程 v6 升级及指定第二屏验收仍属 U1–U4；不以复审通过宣称它们已经实现。
