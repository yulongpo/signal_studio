# U3 独立复审

基线为 U2 `f2ec417`。规格代理 `u3_spec_review`、质量代理
`u3_quality_review` 只读检查当前源码及证据，不代替运行验证。

规格首审提出完整时间/频率包含约束，以及 Loading 可读前缀仍被
窄带显示拦截；次审提出 MHz 显示舍入会误拒绝合法的默认精确频带。
修复跨 domain/application/JSON、读取器及窄带显示，表单保留未编辑
的精确 Hz；严格范围校验保留。后续静态结论为 **SPEC_PASS**。

质量首审无 Critical，提出两项 Important：名称的 UTF-8 字节上限与
工程字符长度不一致，可能创建后无法保存；旧创建重载只限制时间，
也可能生成无法保存的越界频带快照。

r6 已统一名称校验和完整物理频带包含约束，并新增对应行为覆盖。
规格增量复审再次给出 **SPEC_PASS**；质量复审给出 **QUALITY_PASS**，
两项 Important 均关闭，未发现新的 Critical、Important 或必须修复的
Minor。质量代理同时只读核对 12/12 原生场景、三次真实 CPU DDC、
v6 重开及原始备份，确认模型推理标记为 false。

原生迁移夹具恢复了原始 JSON 所引用的五个来源/标记分片，逐项检查
原始字节数及 SHA-256，未绕过工程存储校验。交互捕获通过 Qt 的
鼠标上下文事件进入实际可见菜单，再点击真实 QAction 的菜单区域；
不调用业务槽替代菜单，不声明已完成 OS 物理鼠标输入验收。

r7 另外修复内置资源固定格式诊断被空前缀检查遮蔽的问题，保留
已有格式断言及读取边界。最终静态复审为 **SPEC_PASS / QUALITY_PASS**，
没有未关闭的重要项。重新构建后相关格式/处理器 2/2 及原生 12/12
通过；最终完整 Debug 23/23、Qt 108/108、零跳过也已完成，
见 [验证记录](VALIDATION.md)。
