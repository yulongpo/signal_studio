# U1 选择与展示

工作基线为用户已确认的 U0 提交 `6615b33`。用户在 2026-10-15 明确回复“确认 U0 原型，继续 U1–U4（推荐）”。本节点只落实选择和展示，不提前实现 U2 编辑/删除语义及 U3 通道/工程 v6。

## 实现约束

- 由文件上下文内的一份业务状态管理所选 ID、当前对象/段、选择锚点及悬停；Qt 行选择、树选择和图形只投影该状态。样本通道切换不得带入其它通道的选择。
- 三处同样过滤，跨页保留选择；过滤/关层剔除不匹配项；全部匹配全选覆盖其它页。排序、分页及后台发布保持明确的当前对象。
- 图选后表跳页、树按 ID 加载并定位，不清空其它树分组展开状态。悬停仅更新覆盖层，不生成光谱计算。
- 一个对象多段全体高亮，只当前段显示控制点；主表几何及排序按当前段，未知时间保留“—”，不能使用包围盒作为编辑范围。
- 保留来源色；当前对象、其它已选及悬停分别表达。单击选择不缩放，定位才调整视区；原图谱手势不变。
