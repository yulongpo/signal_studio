# U2 编辑与删除

基线为已完成自检和本地提交的 U1 `3384e17`。只在
`rebuild/a143-native` 实现，不读取其它开发分支。

本节点落实三来源直接图形/数值编辑、同 ID 自动修订、不可变原始证据、
当前段范围、未知时间的频率编辑，以及统一的对象/段删除预览和撤销。
参数草稿遵守 Enter/Tab/应用内焦点提交、Esc 取消、上下文切换撤销，
后台发布不得覆盖草稿或抢焦点。完整范围一次校验、一次提交。

| 实现位置 | 责任 |
|---|---|
| `application/annotation_service.*`、`application/session.cpp` | 统一编辑权限、修订与证据；提交上下文校验；仅受改段确认失效；未知观察频率提交；对象/段删除及选择派生状态归一化 |
| `ui/annotations/annotation_panel.*` | 表格双击/F2 草稿、当前段数值、完整范围对话框、统一删除预览和菜单 |
| `ui/charts/plot_widget.*` | 三来源直接拖拽，独立手势草稿；未知时间仅频率控制点和频率提交 |
| `ui/parameter_input.h`、`app/main_window.*` | 应用内提交与取消保护、File/模态窗口边界、输入框 Delete，以及树按下至松开期间延后重建 |

编辑上下文绑定工程代次、文件、样本通道、对象、基础修订和当前段，
提交前重新核对，防止后台修订或上下文切换把旧输入写入其它目标。
图形预览在手势内保存，不把未提交草稿写进标记的兼容范围；取消
不会产生修订，释放时一次校验、一次修订、一次撤销。

无活动段时清理按标记统计 PSD 的派生状态，避免统一删除后因失效
选择阻止保存。恢复原始时按段 ID 和几何识别未变化的兄弟段，保留
其完整状态；原始证据本身始终不变。

质量菜单可选化、统一通道请求、UserRange 和原生工程 v6 留给 U3。
本节点名称和备注不重置质量；旧通道关系仍可能按修订号显示 Changed，
U3 再统一改为比较绑定几何与物理来源，不在本节点提前宣称关系已闭环。

继续用既有构建/CTest/截图入口。U2 原生场景复用 Capture 及已有的
原生对话框裁剪，主窗口仍为指定第二屏 4K、150% DPI 全屏；不会新增
截图引擎。三来源标记中四条标签来自实际 SigMF，其余为明确的 UI 夹具。
DDC 和模型证据与交互证据分开。

中间产物位于 `out/tasks/wideband-detection/U2/`；最终证据归档本目录。
实现、自检、独立复审和本地提交完成后才进入 U3。
