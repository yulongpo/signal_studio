| 同上真符号 RMS EVM | 理想≤5%，源 SNR20dB≤18% | 最大 4.64409% |

恢复正例包括三种调制理想/20dB、QPSK/16QAM α=.20/.50、实际输出 1.5/4 MS/s 自动 Rs，以及 100 ppm 发射时钟偏差。只允许统一正增益、延迟和 BPSK π / QPSK、QAM π/2 固有模糊对齐；未逐点旋转或重排。条件 EVM 是模板锁定诊断，独立真符号 EVM 另行计算。20dB 指发射生成器在源采样网格加噪的 SNR，不是滤波后的测量值。

八个强行套 QPSK 的负例（噪声、短突发、真实短 QPSK、低 SNR、OFDM、FSK、GMSK、频跳）不报载波锁定；指定不适用体制保留真实 raw。短文件/低置信 Rs、预算、Partial 前缀、来源变化、过期请求和取消均有定向断言。

实际 DDC 测试覆盖 20 MS/s + 1 MHz → 2 MS/s，1.5/2/4/8 倍率、小数带宽的邻近可执行 Fs、源边缘/超源倍率、非法手工值和资源拒绝；奇数源 Fs 不被二倍抽取截断。>2^53 来源位置用整数商余精确验证。

v6 测试覆盖所有分析参数往返、缺字段旧工程实际 Fs/快照/未确认旧 Rs 保留、11 种非法可选设置的原子拒绝。Qt 覆盖 CI16 RAW 与 CF32 SigMF 实际扫描、标记、通道、两图、同步、保存重开、切换通道、手工候选接管及已有 Undo/Redo、草稿/滚轮规则。

## 最终构建与回归

最终两配置均执行完整 35 项 CTest。Debug 本轮 760.93 秒、Release 196.28 秒，均为 34/35；唯一失败为旧 `roundTwoFlatResponsiveControls` 的固定 165px 溢出前提。启用实际系统字体后，控件会按 sizeHint 收窄，165px 仍能容纳高优先级 N。测试现明确设置空闲焦点，并按“更多设置”按钮实际最小预算构造拥挤宽度；原祖先关系、可见性、取值和恢复断言全部保留。完整 `ux_layout` 补测 Debug 1/1（24.54 秒）、Release 与恢复测试合计 2/2（7.12 秒，其中布局 6.42 秒）通过。最终 **35 个必要项均有通过证据**；不将失败首轮写成同一轮 35/35。归档显式记录 `retestedFailures`。

此前单进程主 UI 多次达到 480 秒保护，失败和部分原文保留。原 106 个业务 data 行现按几何、参数/工作流、标记互斥分三组，各自 TIMEOUT=480；没有删除断言、跳过用例或降低 DPI。三组 Debug 31/58/23 通过（94.434/299.126/103.430 秒），Release 同样 31/58/23（28.457/74.107/29.857 秒）；112 个 PASS 包含三组共 6 个 init/cleanup，业务仍是原来的 **106** 个。归档按 Qt `-datatags` 冻结清单验证完整并集、无重复，不以总数替代用例集合。原先 33 项变为 35 项仅因主 UI 从一项分为三项。

新增窄带 UI 两配置均完整 **11/11**（9 个业务 data 行），记录 `NARROWBAND_VALIDATION_NODE=W8`。W8 清除继承的 SS_UI_CASES，避免将定向运行当作全量。归档门槛的独立检查已实测：完整 106 行可接受，仅 workspaceLayout 的日志被拒绝。工作区父对象从构造开始固定、空取消幂等；offscreen/显式软件模式不创建不适用的 QRhiWidget，软件坐标仍由实际绘制矩形与像素断言验证。

归档补测还依据 CTest 的实际构建目录核对 Debug/Release，不能以文件名替代配置。真实日志的配置匹配正例及双向跨配置拒绝检查通过，见 `evidence/retest-configuration-gate.json`。外部文件变化检测同时位于自动分析入口和结果定时器，覆盖修改后立即刷新的竞态，并保留暂停自动重启的行为。补强后完整窄带 UI 两配置再次 11/11，Qt 耗时 Debug 58.742 秒、Release 9.900 秒；原 9 个业务 data 行集合不变，构建与 CTest 原文另存 `final-review-race-*.txt`。

额外六个独立 Rs 正例在最终两配置完整回归中执行。DSP 预审发现并修复两项状态缺陷：待确认旧 Rs 不得触发恢复、同步眼图偏移必须作用于恢复时钟。新增 Manual→Unknown、估计失败/CFO Off 不产生 RRC 阶段、Unknown+手工 CFO 数值、±0.25/±2 UI 来源位置及幅值断言。两配置完整恢复回归均通过；最终补强 Debug 1/1 为 9.87 秒，Release 0.68 秒。源文件空闲/处理中变化、清图与 pending 结束也有 Qt 回归。

测试环境为 Windows、VS2026/x64/C++20、Qt 6.11.1 EXACT；独立发射器使用 Python 3.13、numpy 2.4.4、scipy 1.17.1。256 MiB 同步工作区为预算估算门槛，未将其描述为实测进程峰值内存。

## 原生与独立部署

2026-10-23 活动探针：连接序号 2、Redmi 27 NU、`\\.\DISPLAY6`，监视器路径含 `DISPLAY#XMIB005`。Windows 首选模式与当前尺寸均 3840×2160，Qt 逻辑 2560×1440，DPR=1.5，非主屏。未使用虚拟帧缓冲或旧设备身份代替。

Debug/Release × QRhi D3D11/QPainter 四种模式，各完成同一 12 场景，合计 48 个。包括双格式真实导入、四档倍率预览、默认真实 DDC、未知 Rs 原始星座、非整数 SPS 手工眼图、手工/自动 Rs 同步、v6 重开与取消。GPU 记录顶点绘制、纹理上传及实际 D3D11 后端；软件报告明确 QPainter。正式调制两图使用同一数值接口和坐标变换。

原生场景的工程创建及手工标记由应用 API 建立夹具，导入配置、倍率、提取、Rs/同步操作由真实 Qt 控件和 QPA 输入驱动；扫描、CPU DSP 和保存重开实际执行。现有完整 UI 回归另覆盖标记鼠标手势。报告不将夹具设置 API 冒充逐步人工鼠标操作。

两配置 GPU/软件的 SignalStudio.exe 均从对应部署目录、仅系统 PATH、清除 Qt/DPI 覆盖的环境重开实际工程，通过真实恢复后的星座与眼图检查。CRT/Qt 自动部署机制保留。独立启动证据与指定实屏证据分别记录。
