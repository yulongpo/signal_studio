# 窄带采样与真实星座／眼图

从工程入口添加 RAW 或 SigMF 文件，确认真实 Fs、RF 中心频率和数据格式；等待扫描完成，或只使用已读前缀。选择标记的活动段，点击“提取窄带”。

通道默认使用目标 `2 × 提取带宽`，可选 1.5×、2×、4×、8×或手工输出 Fs。预览显示目标与实际 Fs、实际带宽倍率、有理 L/M、FIR 和调整原因。自动模式不超过源 Fs；手工 Fs 不被改写，无法执行时显示原因。20 MS/s 源、1 MHz 提取带宽的默认实际 Fs 为 2 MS/s。倍率不是符号 SPS。

进入“调制分析”即可看真实原始 IQ 星座，不需要先猜符号率。点数只影响散点绘图，自动轴范围使用整个实际分析窗；I/Q 等比例。去 DC、功率归一化必须显式选择。关闭自动缩放后可输入两轴共用范围，超出范围的点不夹到边框。

眼图需要 Rs。选择“手工 Rs”输入已知周期，或“自动估计 Rs”查看最多五个候选、方法和评分，再用“采用为手工 Rs”接管。评分不是概率；带宽与旧工程默认数字不会自动当作 Rs。手工折叠显示“周期假设，未锁定”。实际 `SPS=实际 Fs/Rs`，支持非整数值；每 UI 4/8/16 个绘图插值点不会增加物理 SPS。

选择 BPSK、QPSK 或 16QAM 分析假设，点击“恢复单载波”，启用 CFO、RRC、Gardner 和对应相位恢复。未知 Rs 先估计，已提交的手工 Rs/CFO 保留。星座和眼图标题可切换 Raw、CFO、匹配滤波、定时、载波阶段。“更多同步设置”提供 CFO 模式/值、RRC 开关/滚降/跨度、相位、环路带宽及预算。调制选择不是自动识别，条件 EVM 也不是已知真符号误差。

眼图支持 I/Q 双分量或单分量、1–4 UI、32/64/128/256 轨迹与定时偏移。旧工程其它合法周期/轨迹原值仍显示。没有可靠 Rs、观测太短或实际 SPS 不足时给出空态/未锁定原因，原始 IQ 保留。FSK、OFDM、GMSK 不适用本期恢复链。

默认分析预算 1 Mi、最多 8 Mi 个复样本；同步还受 256 MiB 工作区限制。超限应缩小时间窗口。跨缓存块保持连续，切换文件/通道/工程或参数后旧结果失效。“取消”清空结果，“分析”重新计算。

源文件在页面空闲或分析中被外部改写时，两图和锁定结果失效，普通刷新不会自动重启该物理文件；可明确重新分析，来源完整性不再匹配时需重新导入。加载前缀或正常上下文变化仍按当前请求重新分析。

参数在 Enter、Tab/Shift+Tab 或应用内切换焦点时提交；输入途中和后台刷新不提交草稿，滚轮不改参数。v6 保存已提交的策略和分析配置；旧通道实际 Fs、来源快照和未确认旧 Rs 保留，运行时样本数组不写入工程。深度学习识别和解调页仍包含明确标示的合成演示。
