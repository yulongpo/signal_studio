# 宽带界面优化变更说明

- 图谱常用参数回到所属标题栏：波形分量、PSD N/统计范围/统计类型、STFT N、唯一色表、电平与显示入口。标题栏保持单行，低优先级操作按宽度进入溢出。
- PSD、STFT、电平、显示和文件属性使用统一临时层。再次点击同一入口、外部点击、Esc、应用失焦及上下文切换按规格关闭；内部下拉不误关。右侧常驻栏仍由用户手动收起。
- 右侧改为显示、检测、标记、通道四页。显示摘要提供文件属性和设置跳转，标记/通道保留原编辑器；手动页签选择在当前上下文内优先，后台进度不切页。
- 检测拆分模型与输入谱。基础配置和短预检在首屏，专业、后处理、资源及计算/诊断详情按需展开；运行/取消区固定在滚动区域外。
- 历史派生复制源文件、父任务、参数和冻结范围，不自动运行。同文件查看来源/详情保留草稿，跨文件派生撤销旧草稿。取消始终指向明确的任务ID。
- 任务行显示真实状态、文件/模型、阶段、计数、结果及首条异常；提供查看来源、详情、派生和取消。列表内 Enter 查看来源，Alt+Enter 详情，Ctrl+Enter 派生，Ctrl+Shift+X 取消。
- 谱方法记忆最近已提交的合法参数，首次访问使用默认值；无关表单行完整隐藏。Bartlett 的零重叠不污染 Welch，PSD/STFT 历史独立，方法历史不写入工程格式。
- 非法参数保持已提交业务值，并保留可恢复草稿与字段提示。Enter、Tab/Shift+Tab、应用内点击提交有效值；输入中、后台刷新和应用失焦不提交。滚轮不改参数，容器滚动和图谱缩放保留。
- 任务筛选下拉完整显示迟到的任务 ID，弹出宽度按实际行测量并约束在屏幕内；后台刷新保留当前键盘选项，不重新创建既有行。

检测协议、物理坐标、既有标记/通道数据结构和工程v6不变；有效带宽仍按文件保存，通用显示偏好继续全局保存。原生验收使用当次实际4K/150%外接屏，1920×1080仅用于离屏布局检查；没有执行1366×768工作。
