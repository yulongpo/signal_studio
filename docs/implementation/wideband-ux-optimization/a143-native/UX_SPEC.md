# 交互规格

## 单行图谱控制

导航只做导航/读取停止。辅助波形只显示分量；PSD显示N/统计时间范围/统计类型/谱来源状态，详细方法进设置。主图提供模式/STFT N/唯一色表/电平/显示/设置，并保留持续标记、ROI、最大化。低优先级项进入溢出，保持原标题栏高度与图谱预算，不缩字塞入整排编辑框。

电平层包含参考电平、动态范围、自动适配；显示层包含RF/基带、网格、色阶。所有入口绑定同一Session及已提交状态，PSD/STFT/检测N互相独立，窄带按活动通道绑定。

## 临时设置层

同一时间一个，稳定主窗口宿主、不透明背景与正确叠放；普通刷新不reparent、不抢焦点/滚动位置。点击同入口开关，打开另一层关闭前层。外部点击按输入规则提交合法值并关闭，原点击继续执行。内部下拉/子菜单属于内部，Esc先关子列表，再撤销当前层草稿并关层。应用失焦关闭但不提交、保留草稿；切文件/通道/工程关闭并撤销草稿。窗口调整重定位，图谱/锚点隐藏则关闭。常驻右侧栏仍手动收起。

## 四页上下文

显示页提供源状态、简明摘要、文件属性及工具栏跳转；检测页基础配置/短预检/固定CTA；标记页保留完整编辑与来源入口；通道页保留真实来源、参数、快照关系和编辑入口。无对象时只有操作引导，不铺空字段。

显式检测/ROI/历史派生/通道编辑总是展示目标页。手动页签覆盖自动标记切页；自动标记切页仅无草稿且当前上下文无手动覆盖。覆盖在切文件/通道后解除，不持久化隐藏永久锁。后台刷新只更新值。首次默认显示，布局和合理最近页签保留。

## 检测行为

宽带检测只展示；检测当前区域明确选择visible；ROI确认精确半开样本范围且回到检测页，取消恢复前工具不新增对象。查看来源/详情不加载历史配置，同文件保留草稿、跨文件按既有规则撤销草稿。派生先复制历史快照、切文件核验身份，再加载parentRunId、FFT/hop/T/滑动、谱/阈值/策略与冻结范围custom；不自动运行。

模型/谱拆分保持原configurationKey；正式两模型保留已有谱型，FFSCN-17明确实验，fixture只测试模式。SCN裕量禁用。基础为模型、谱、范围、score与时间定位；专业/后处理/资源折叠但不删参数。无草稿不驻留说明书，预检成功一行、失败第一阻断原因加详情。真实物理计算放折叠详情。运行按钮滚动外且只检测上下文可见。

任务卡以文本表达阶段、进度、结果及错误；详情保留冻结请求、实际观测、覆盖和原始JSON。键盘及鼠标取消同一明确runId，任务终态/不存在为空操作。
