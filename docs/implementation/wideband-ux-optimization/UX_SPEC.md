# 交互规格

这是实现规格，不是已交付界面。物理时间、频率、手势、标记选择和检测请求语义保持现状。

## 主区域

左侧工程树不变。中间三个图谱保持上下关系：全局时间导航、辅助图、主图。每个图谱标题栏放该图的高频控件，一行放不下时进入该图自己的溢出菜单，不用右侧长表单代替。

导航图保留滚轮缩放、拖动时间窗和停止读取。不在这里放大表单。

辅助图保留“时域波形 / 功率谱 / 检测证据”互斥切换。波形模式只显示 `waveformMode`。PSD 模式只显示 `psdFft`、`psdScope` 和统计类型，并提供谱估计弹层。两种模式的控件不能同时出现。

主图保留“时频图 / 瀑布图”切换、`manualTool`、`detectionRoiTool` 和最大化。色表、动态范围、参考电平、自动适配、网格和色阶从这里或锚定弹层到达。`colormap` 是唯一色表编辑器。

PSD N、STFT N 和检测 FFT N 是三套配置。名称上区分。改显示 N 或色表不得改已冻结检测任务。

## 右侧四页

页签对象名为 `contextDisplay`、`contextDetection`、`contextAnnotation`、`contextChannel`。右侧仍可收起、恢复，并用键盘切换。

显示页放当前视图和显示作用域，不重复编辑已经在工具栏里的同一值。检测页放检测卡。标记页放现有检查器，不再复制底部标记表的整段概要。通道页放现有通道摘要和编辑入口。文件概要按需打开，不占常驻首屏。

页签切换按现有 `ParameterInputPolicy`：应用内焦点变化提交有效草稿；无效草稿拒绝并保留；窗口失焦不提交。切换文件、通道或工程仍丢弃未提交草稿。滚轮不改输入值，侧栏滚动和图谱缩放保留。

## 检测卡

模型与输入谱分成两个可见下拉。稳定模型 `ffscn-gui-iq-v1` 与 `scn-max-psd-v1` 各保留模型默认和四种谱：瞬时、平均、最大、最小。`ffscn-17-experimental-v1` 继续标为实验，只保留今天已有的模型默认项。`pipeline-fixture-v1` 仅在 `enableDetectionTestFixture` 为真时可见，不新增谱型组合。SCN 的 `detectionBandwidthMarginDb` 继续禁用。

范围、阈值和策略进入首屏。分支参数和高级参数默认折叠，展开后不得丢值。预检成功只留一行可运行说明。失败时显示第一条可处理原因，并保留详情入口。运行按钮留在检测页的固定操作区。

`deriveWidebandDetection` 复制历史请求快照，写入 `parentRunId`，并把历史范围冻结为 `custom`。它不直接运行。`openRunSource` 只定位源文件和任务，不把历史请求写入当前配置。

其他文件有未结束任务时，当前文件的取消按钮不可用，并显示文件名和状态。`viewRunningDetection` 只定位，不取消。底部列表按条取消指定 `runId`。界面仍拒绝在任一未结束任务存在时提交新任务。队列上限和 worker 协议不变。

检测范围 ROI 与时间策略 ROI 标签必须不同。框选确认后聚焦检测页并标为自定义范围。Esc 恢复上一工具，不新建标记或任务。

## 谱弹层

Welch、Bartlett、DPSS、Burg 和窗函数切换时，隐藏当前方法不适用的字段，但在该 `SpectralSettingsWidget` 实例内记住各方法上次合法值。Bartlett 实算重叠仍是 0。实例销毁前不写入工程 JSON，不升版本。PSD 与 STFT 历史互不影响。

## 验收屏幕

原生验收只认外接 4K、150%：连接序号 1、友好名称 U27U2D、原生设备路径 DISPLAY2，使用该屏全屏和实际 DPI。1920×1080 只作为 offscreen 布局探针，不是原生 DPI 验收。不使用 1366×768。这些检查都还没跑。
