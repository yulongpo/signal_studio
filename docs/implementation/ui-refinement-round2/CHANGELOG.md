# 第二轮 UI 变更

宽带和窄带的图谱设置改为标题栏右对齐。常用字段按实际宽度直出，其余字段进入单层“更多设置”，不再把下拉编辑器转换为带子菜单的命令。每个字段只有一个实际编辑器；打开设置层或编辑草稿时保持位置，普通刷新不重新创建控件。

## 窄带操作

观察页上排为波形与PSD，下排为时频图；上下比例可以拖动，并由QSettings保存。合成星座合入原有调制分析页，眼图设置位于眼图标题栏。原有混合全局参数条及右侧重复入口已移除。

PSD图标题栏提供“统计谱/驻留帧谱”。统计谱的PSD N与STFT N独立；点击时频图驻留后，PSD显示随STFT的实际点数，切回统计谱恢复原N。工程内预设以外的合法N也能正确显示。帧谱说明在切回统计谱后清除，包括两种点数相同的情况。

识别页的配置可以滚动，运行/停止保持可见；未运行时显示空结果。运行、停止、完成、过期状态分别维护，后台DDC显示刷新不会覆盖识别反馈。合成星座、识别和解调继续明确标示为演示，未增加真实识别或解调算法。

通道标题保留名称及短物理摘要，完整来源、修订与路径放入按需详情。长计算过程进入诊断信息，图内保留单位、异常和必要补零提示；删除空权重哈希、内部布尔标志等常驻文字。

## 工程树

工程树保持在左侧。文件与通道采用名称和简短物理摘要的双行显示，完整路径、格式和其它物理信息保留在Tooltip或详情中。长名称随可用宽度省略；当前文件与通道使用一致的蓝色活动标识。

标记继续保留三来源颜色，多选、当前对象、焦点和悬停分别呈现。分组显示数量，选择计数及批量操作合为一行；完整筛选计数仍可通过Tooltip查看。首次展开当前文件及标记/通道分组，检测历史默认折叠；已有展开状态、按需加载、滚动、选择锚点与显式定位行为保留。

## 代码与兼容性

共用布局在`ui/chart_control_strip.h`，宽窄带绑定在`app/main_window.cpp`，窄带页面在`ui/narrowband_workspace.cpp`，树呈现在`ui/project_tree_presentation.h`。新布局偏好使用QSettings，未增加工程字段或工程版本。

参数继续由Enter、Tab/Shift+Tab或应用内点击提交；输入中、应用失焦及后台刷新不提交。非法草稿、Esc撤销、滚轮保护、上下文切换撤销和设置层自动关闭规则沿用既有策略。DSP点数/物理坐标、worker协议、检测请求、来源证据、真实CPU DDC和工程v6契约保持。按用户后续要求，旧工程兼容已取消：仅接受v6，移除v1–v5导入迁移、旧通道快照推导和升级备份。

新增独立`--ui-refinement`原生24场景入口，由`scripts/screenshot.ps1 -UiRefinement`运行。它单独记录本轮界面证据，未改写此前R/U/W验收计数。用户要求停止新增测试之前已完成的两条综合UX用例及八项树呈现检查保留；此后未再加入测试。旧UI用例改从新的实际可见入口操作，过期工程迁移用例随兼容功能移除。
