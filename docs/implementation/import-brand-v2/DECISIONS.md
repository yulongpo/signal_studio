# Decisions

1. 基线从实际8d0564a继续，不回退任务制定SHA。用户最终明确授权每节点本地提交、全部完成后正常推送；不强制覆盖远端。
2. 延用Int16IqFile为旧业务兼容适配器，底层新增格式读取器，不重写稳定DSP/QRhi。实数无已验证解析信号路径，业务和处理器拒绝复数DDC。
3. 导入采用单个串行SourceLoader，4MiB附近完整帧，首屏片段16384样本且不超过物理4MiB。预览单worker可替换请求与代次取消，不用图谱伪数据。停止保留完整前缀，重新完整读入不是续读。
4. 原生项目v4和版本1格式模板是不同协议，拒绝原型导出JSON直接进入工程/模板。模板只保存格式，不覆盖各源Fs/Fc；用户明确格式或SigMF冲突覆盖需要确认。模板最近8项，用户模板128项/JSON1MiB，批量256项。
5. SigMF依据执行时官方[1.2.6规范](https://sigmf.org/)，支持已验证datatype/Fs/一致capture频率/通道交织、同目录配对、首段头/尾字节。未知datatype、必需扩展、分段变频/段间header明确拒绝，不能默认为CI16；未知非解码字段和annotations告知，不虚构自动标记。global offset是外部样本编号而非文件头字节。用户缺失参数人工确认后可使用，默认值不意味着已识别。
6. 品牌qrc共享静态库并显式资源锚定。原包ICO无24px，按原始尺寸PNG无重绘封装，PE层实查；windowIcon多尺寸PNG无需SVG。展示SVG失败自动PNG，用SS_BRAND_FORCE_PNG做回退验证。
7. 主窗口始终第二连接屏全屏，捕获沿用QWidget::grab原生窗口方法，导入/关于为实际模态窗口裁切，不假称全屏像素；每张记录监视器/DPI/窗口像素、非黑检查。
