# Signal Import A1.2 Native UX

信息架构、颜色、尺寸及加载阶段以任务 references 的 A1.2 HTML/设计说明/截图为依据，不嵌入浏览器。当前主窗口仍是 A1.4.3。

| Control | State / Validation |
|---|---|
| 文件条/拖放/选择 | 只读本地文件，保存完整路径工具提示；读入时不修改队列 |
| 三页导航 | 快速导入/批量导入/格式模板；切页保留已提交参数 |
| 结构/分量 | 复数/实数与六编码分开；摘要只读推导 |
| 字节序 | 8位隐藏、不落无效字段；回多字节恢复上次有效选择 |
| IQ布局 | 实数隐藏/NotApplicable；返回复数恢复IQ/QI/Planar |
| 整数归一化 | 浮点禁用，保留浮点原值；整数旧CI16默认为满刻度归一化 |
| Fs/Fc/BW | Fs>0、Fc>=0、实数BW<=Fs/2、复数BW<=Fs；BW0全带。单位大小写/空白/科学记数；非法值保留旧值 |
| 预览时间 | ns/us/ms/s，无单位ms；只读有界片段，起始位置限制在实际样本范围内 |
| 预览位置菜单 | 起始时间框上下文菜单：起始/中间/尾部/指定uint64样本；不改变原型双栏布局 |
| 头/尾/通道 | uint64十进制、通道1..128、选中通道范围检查；严格完整帧，不静默吞尾 |
| 参数确认 | 无可信完整格式/必填参数时必须人工确认，不盲猜CI16 |
| 实际预览 | PSD/波形/散点或直方图/STFT；后台计算、代次取消、最多4MiB磁盘片段和16384点 |
| 批量表格 | 独立源参数/状态/来源/错误，进入快速页编辑；成功、失败、取消、Partial区分 |
| 选中/重试/取消 | 无选中项导入全队列，否则仅选中行；同路径+完整解释参数去重；修改后重新检查重复；单条取消不动成功行 |
| 模板页 | 原型三列格式卡、导出当前配置、保存模板底栏；增加原生模板JSON导入，用户模板与最近历史持久化，版本/字段/大小严格验证 |
| 模板应用 | 仅覆盖格式，Fs/Fc/BW各源保留；SigMF/已手动格式冲突前确认，缺必填项仍需人工确认 |
| SigMF | Fs/格式/capture频率优先于文件名；来源冲突提示允许直接编辑覆盖；未知格式/不安全路径/不支持分段明确禁用导入 |
| 加载卡 | 校验/真实顺序读取/首屏分析；实测完整帧进度，停止不等于失败 |
| 完成/保留 | 至少一个有效源且预览就绪后可进入工程；无数据不创建节点；重新完整读入不是续传 |

全部参数禁止滚轮改变；保留侧栏滚动。草稿仅Enter/Tab/Shift+Tab/外部点击提交，窗口失焦与刷新不提交，切源撤销草稿。核心控件有稳定objectName/可访问名称/标签与工具提示。Tab/Enter/Esc沿用Qt与统一参数策略。拒绝/关闭停止任务，线程安全回收，源文件不修改。
