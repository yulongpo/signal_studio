# UX-R3 交互合同

工程身份是任意已存在目录下的 `.ssproj` 文件，名称与目录无绑定。新建立即原子保存；打开/最近工程只把完整校验成功的候选替换会话。另存为明确复制或引用伴随资产；旧 v6 JSON 从显式入口只读预览后转换至新文件，原文件和原资产保留。保存失败保留修改状态。源文件重定位核对格式、长度及轻量内容签名，不能把标记静默绑定错误数据。

两图轴刻度与标题分开预算：默认 A 单位置顶，B 标题承载，C 旋转标题可选。动态字体测量保证长刻度；辅助图/主图共用最大左边距。鼠标坐标始终由实际 plotRect 映射，刻度及绘图切换不改变物理语义。

信号导入后在有界目录发现标签，严格同名 data/name.data ↔ label/name.txt。可信 profile 校验后导入并显示数量/来源；未知 TXT 打开映射预览，Fs/Fc/索引基准/单位需明确，取消不修改对象。无标签反馈可手工创建；重复来源不重复导入，变动来源保留旧修订供明确重载。

窄带顶页签：观察、星座、眼图、调制识别、解调。共享同步配置按需展开；各页消费同一通道/来源/代次下的真实分析结果。纯显示切换不重跑恢复；配置、源或通道变化令依赖失效。旧 Modulation 对应星座，DeepLearning 对应识别，已有分析配置保留。无模型显示不可用。

检测路径：统一配置入口 → 冻结请求/预检 → 任务阶段/已发布数 → 结果复核 → 编辑标记 → 通道配置。选择只改变选择状态，定位才改变视区。已有未知时间、部分覆盖、取消前缀、不可变来源快照与 2B/倍率/手工 Fs 规则继续有效。

可点击设计预览见 `prototype.html`；它只解释信息架构，不能作为原生功能验收证据。
