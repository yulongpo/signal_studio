## 使用入口与行为

- MATLAB 生成器 WAV 放在 `data/`，同主名 TXT 放在相邻 `label/` 后，添加信号可自动发现标签。文件菜单“从标签定位 WAV / DATA 信号…”支持反查；同名 WAV 与 DATA 同时存在时明确选择。WAV 编码、Fs、IQ 布局、有效样本数继续由 RIFF 预检读取，Fc 由用户确认。
- 手工入口为“文件 → 导入标签…”及底部“统一标记记录 → 导入标签…”。两者共用选择、字段映射、预览和原子发布路径，选择器及预览显示目标信号。未知 TXT 必须确认字段含义；取消、失败及上下文切换不发布部分结果。同源重复导入保留原始证据及人工修订。
- 宽带默认使用“紧凑标题栏”，现有显示页仍可选择 A/B/C。窄带五个页面的波形、PSD、STFT、星座、眼图和置信度时间轴共用紧凑呈现；合成与未部署状态继续明确显示。导航图保持原有简化布局。
- X/Y 名称、单位及必要原点说明移入既有 32px 宽带/30px 窄带标题栏。空间不足优先显示短名称和完整单位，完整语义可悬停查看，也可在已有“更多设置”的坐标轴说明查看。标题栏不增高，图内仅保留刻度及操作区域。
- 绘制、热图、ROI、标记手柄和游标仍使用实际 `plotRect()`；星座等比例。布局及文字变化复用同步分析结果，不通过重跑 DSP 实现调整。RF 极窄范围的刻度精度按量级及间隔测量，并稀疏不能区分的刻度。

## 面积与证据方法

修改前已从原二进制采集宽带 24 场景和窄带 26 场景的真实 GPU 截图。新宽带矩阵覆盖 A/B/C/CompactHeader × 波形/PSD × 时频/瀑布 × 长短刻度，共 32 场景；同一场景在同一控件尺寸、字体和分栏下临时切换 A→CompactHeader，直接读取两次真实绘图区，要求辅助图至少增加两行文字高度。

首轮 Release 实屏测得辅助图高度 **88→127 逻辑像素，增加 39px，绘图面积增加 44.318%**；字体行高 16px，要求为 32px。主辅图左侧对齐、刻度完整及物理坐标交互同时检查。最终报告以归档 JSON 为准。

窄带报告同时记录当前真实绘图区、实际刻度墨迹、标题栏文字和旧版固定边距在相同画布尺寸下的几何比较。旧边距比较是明确标注的同尺寸计算，不伪造旧截图。首轮 10 种窄带图谱面积增加约 **4.139%–13.512%**；真实修改前截图另行保留。窄带刻度现在测量当前字体，不再依赖固定 48px 文字框。

本轮实屏探针：**Redmi 27 NU，连接序号 1，`\\.\DISPLAY6`，物理 3840×2160，逻辑 2560×1440，DPR 1.5**。设备身份来自本次 Windows DisplayConfig，不能套用旧连接序号。GPU 与 QWidget 软件回退分别运行，offscreen 测试不作为硬件显示证据。
