# R3 检测流程适配

前置节点：R2 `e4db9c8` 已自检、复审并本地提交。本节点继续在 `rebuild/a143-native`，不使用其它分支的实现或证据。

## 提交与计算

配置面板不再把参考 FFT、10/16 帧、5 帧滑动、1 ms 谱步长当成启动条件。FFT 分析网格为32–262144点，窗口帧数和滑动帧数为正整数；文件、坐标、有限值和实际资源边界继续检查。已有参数提交手势与布局保留。

既有能力下拉框增加当前谱、平均谱、最大谱和最小谱选项；每个模型/谱选项独立保存已提交配置。平均谱按线性功率平均后转换为dB。FFSCN默认选项保留真实时间张量，其余显式谱选项按窗口归约为一行；SCN使用选定的实际谱。切换文件或配置仍撤销未提交草稿。

不规则分析网格先匹配到上一个不小于它的2次幂FFT，再映射到用户分析网格；模型适配由R2负责。主FFSCN/SCN的`down_nums=11`、最小2048点，与当前SCN导出包32768点的固定部署网格分开记录。补零量和真实支持保存，补零不增加实际分辨率。

## 短文件、范围与尾部

v2谱帧数按可用前缀和谱步长向上取整，最后一个不完整时间槽保留。窗口使用`min(请求帧数, 实际可用帧数)`，不复制谱帧凑足参考上下文。短ROI仍可使用保存的真实邻近FFT支持，结果裁剪到提交的物理范围。尾部窗口锚定最后可用帧；Partial任务只读取已加载前缀，未读尾部保存为排除范围。

完整文件、可见范围、ROI与活动段均走同一个不可变任务快照和来源计划。显示抽帧、缩放、后续参数草稿不会改变已提交计算。历史v1保存记录继续按原冻结配置读取，新任务使用v2。

## 有界传输与证据

实际谱帧映射保留在主进程并写入本地证据，worker控制消息只传窗口身份，二进制传实际张量；不会把4096帧或64KiB控制消息上限解释为模型能力。按真实张量、DSP工作集及证据分片预算降低执行批量；实际执行批量与用户提交的批量分别记录。单窗口仍超出格式或资源预算时给出具体原因，不提示恢复参考FFT/帧数。

原始head字节与JSON分片分开估计：SCN每窗口必需`3×8192×4=98304`字节原始head。SCN后处理JSON按`1024+1536×topK`预留，依据每原始候选最多六个有限值DTO（原始、测量、两组融合、精修及最终候选）；另有64KiB通用封套预算。此上界用于自动降低批量及单窗口保存能力检查，不作为算法FFT或时间长度限制。累积证据仍受用户请求的保存预算约束，不能据此宣称无限长文件可一次完成。

执行失败、取消、成功零结果分别保存。结果发布、取消前缀和重开恢复保持原契约。代表性验证仅证明功能与流程，不替代L3/L4或真实RF效果验收。

## 验证范围

来源测试覆盖17样本短ROI、奇数3001点网格、4096点匹配FFT、Partial尾部和证据过大时的明确失败。任务测试覆盖不可变快照、短上下文、4097真实谱帧的本地证据保存重开、取消及失败恢复。UI测试核对非默认FFT/帧数/谱步长/滑动值的实际提交、各谱配置隔离和草稿撤销。

真实模型验证入口复用`SignalStudioDetectionTaskTests --real-adaptation WAV 输出目录`，只处理一份冻结生成器WAV的少量代表范围；覆盖FFSCN变参、SCN平均谱/不规则网格、17样本Partial及正常零结果。最终结果和身份见本目录`SELF_REVIEW.md`，未完成前不得据此声明通过。
