# M3 真实模型前向与频率关联

2026-10-14。M2 `cc103e3` 和输出整理 `9080162` 完成本地提交后恢复本节点。实现范围为批准规划的 F01–F05、L1/L2、频率层对照；时间活动段、二维效果、真实算法段到 DDC 和最终部署继续按 M4/M5 执行。

## 正式处理链

`SignalStudioDetectionWorker` 使用本仓库 C++ TensorRT 后端，延迟加载已部署的官方 DLL 与冻结模型包。应用和 worker 运行不需要 Python 或外部业务源码。开发与独立数学核对使用用户指定的 `D:/profiles/anaconda/python.exe`。

主线模型为 epoch-1200 的独立图实现及 FP32 引擎。模型包清单、源 checkpoint、引擎、运行库、目标设备、精度和输入/输出形状分别保留身份；生产请求冻结引擎 SHA，worker 重新核对实际资产和 CUDA 设备。B1/B2 输入为 `[B,1,10,65536]`，原始 hm/bw/off 为 `[B,1,1,16384]`。没有 FP16 或夹具的自动回退。

64 KiB 控制包不重复传送最高 topK 的全部浮点候选。正式响应使用有限 float32 原始 head 二进制 `[B,3,1,N/4]`；应用以相同注册解码器重建候选。候选保留真实 `peakIndex`，不从裁剪后的边界倒推身份。同窗口多个目标、A–B–C NMS、严格门限、topK 和跨窗口一对一关联均有独立行为检查。

轨迹分数与命中数来自同一个唯一窗口集合，同窗口碎片贡献最大分数。mean、max、hits、窗口 ID、完整 eligible 分母、名义槽范围和实际 FFT 支持分别保存。主线的同中心包含碎片裕量使用参考的 2 个 bin；频率融合与观察支持不会生成发射活动段。

GUI 频率处理从唯一真实 STFT 帧求全局 10% percentile，再以轨迹名义观察范围的平均 dB 谱修正频边。精确分位使用有界磁盘 spool 和 ordered-float radix 统计，保留 NumPy 2.4 的 float32 插值政策。原始、融合和修正频率，以及噪底、门限、实测标志和 skip reason 均存证。最终报告按不可变 ROI 裁剪；完整模型上下文不被 ROI 截短。详见 `FREQUENCY_EVIDENCE.md`、`FREQUENCY_PARITY.md`。

SCN 单个引擎只支持固定 B1；逻辑 B2 顺序执行两次 B1。每次只用 16 帧最大谱经 minmax 归一化前向，平均谱前向调用数为 0。正式顺序是每窗口 CNR ≥3 dB、整数测量频边、IoU 0.1 / overlap 0.5 / gap 0 融合、平均谱邻带最小噪底 +3 dB / 最大谱向内收边、150 候选上限，然后进入时间窗口关联。未经过 CNR 筛选的全部融合候选始终参与噪底屏蔽。原型卡片的噪底裕量仍用于 sample/ROI 时间精修；方案说明及实际窗口证据明确区分这一参数和固定 SCN 频率对照。

## 记录、恢复和界面

每个原始 head 以 SHA-256 绑定到持久化映射，结果分片验证其相对路径、实际字节和形状。窗口结果、频率修正后的 Annotation 和最终完成标记依次原子落盘，再发布到已有三来源统一标记表。最终分片同时按 4096 条与字节/驻留预算先到为准拆分。恢复逐记录解码为 Annotation，不累计整个最终 JSON 数组；超过 8 MiB 的合法多分片集合能够精确恢复。

生产任务取消或失败后，已完成并落盘的窗口前缀在终态发布前恢复为明确的频率观察。完整 eligible 分母保留，不把取消前缀变成已处理完整文件。没有定位时间的观察保持 `WindowObservation`、无活动段、类别未知，不能直接建立通道。终态持久化失败不自动发布。

检测继续使用 M0-P 的常驻配置卡、固定运行/取消动作、ROI、三层图例、统一结果表、复核和来源快照。原生验收仍复用 `scripts/screenshot.ps1` 与既有 Qt Capture，增加 `-ProductionModel` 的两个真实模型场景，保留原有 23 个场景及屏幕/GPU条件。算法观察没有活动段时，几何输入显示空占位并禁用，不残留上一条标签的坐标。没有添加新的配置对话框或改变原型流程。

## 资源与边界

CPU 中间工作集保持 256 MiB。模型设备预算独立为初始 4 GiB，并严格检查实际可用显存；engine blob 另限 128 MiB。真实 readback 记录 FFSCN workspace 657,328,128 字节、SCN 40,534,016 字节。CPU、模型显存、Qt 图谱 GPU 显示和后续 RSS 实测分别记账，M5 继续做资源/吞吐验收。

TensorRT Logger 遵守已安装 SDK 的线程安全契约；异步输出失败先 drain stream，再释放 host buffers。三个 queued-copy 失败位置和后续推理恢复已经实测。旧资产预备报告保留原始路径及历史边界；本节点生产证据以 `SELF_REVIEW.md` 列出的新日志和报告为准。

17 阶的 131072 正式默认形状仍未通过原始张量对照，因此明确预检拒绝；8192 的预备实验不能冒充全部形状通过。HY 频率历史、G1 历史二维指标、当前频率数值对照和后续 G/T 时间效果均独立记账。本节点没有复现历史二维 F1，也没有把频率观察称为精确时间检测。
