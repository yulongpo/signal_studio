# R1 校验与能力核对

状态：当前分支 `rebuild/a143-native`；起点 `c305030`。本轮只使用当前分支及其 M0–M4 已提交证据。R1 不修改产品行为；R2–R6 必须在本节点自检、本地提交后顺序执行。

## 判断

参考默认 FFT、帧数和滑动步长被重复用作产品合法性判断，是当前可用性问题。注册配置应描述默认行为与模型身份，不能要求用户恢复默认值才能启动。数据源、分析网格、模型张量及历史参考配置必须分开。

FFSCN 仓库内网络的时间头为 `mean(dim=2)`，卷积下采样仅沿频率轴；FPN 逐级二倍上采样并相加，因此频率宽度须在内部按网络总频率步幅对齐。网络频率总步幅为 2048；对齐后的最小输入宽度为 2048。原生 TensorRT 的固定 `10×65536` 来自既有导出，不是权重的时间帧数限制。结构前向结果见 `model-capability-probe.json`，该证据不证明检测精度或新 engine 的等价性。

SCN 输入为 32768 个通道的一维频率向量；时间积累发生在图外。真实谱帧数量可变，必须继续只向网络提供最大保持谱。32768 属于后端频率网格，不能约束用户 FFT。

## 阻断清单与处置

| 位置 / 条件 | 分类 | 后续处置与行为检查 |
|---|---|---|
| `DetectionCard::configurationError` 固定 FFSCN 10×65536、SCN 16×32768 | 参考默认值 | 移除相等比较；不同合法 FFT/帧数可以提交，保持草稿提交规则 |
| `DetectionCard::profileValidationError` FFT/frame/hop 与注册值完全相等 | 参考默认值 | 只核对能力身份；分析参数单独校验；不同 hop/滑窗真正进入快照 |
| `validateDetectionRequest` profile 全字段注册值相等 | 参考默认值 | 保留 profile 身份/backend；分析网格由有效整数、FFT 实现及实际预算决定 |
| `FixedDetectionSource::validateConfig` 固定10/16帧、5帧滑窗、1ms、固定FFT | 可适配 | 解耦网格配置；保留正帧数、正步长、FFT二次幂与有界内存 |
| `DetectionCard::contextValidationError` 不足完整 FFT+默认帧支持即禁用 | 可适配 | 实际帧计划决定可执行；短数据使用实际支持，FFT边界补零有记录，不复制谱帧 |
| `buildWindows` 不足配置帧数整段排除、尾部不满时间槽排除 | 可适配 | 保留实际短窗/尾部支持与覆盖，不把默认窗口当启动门槛 |
| `prepareDetectionModelInput` 注册 FFT/frames 相等 | 可适配 | 输入按实际分析宽度/实际帧数验证长度；FFSCN内部对齐；SCN功率域频率重分箱 |
| `validateDetectionModelPackage` 注册分析形状及固定IO shape | 可适配 | 包声明/实际 engine IO 描述后端形状，校验权重、dtype、布局与绑定；支持动态时间/频率 |
| `DetectionModelBackend` 写死FFSCN shape及输出宽度、固定SCN时间帧数 | 可适配 | 动态设置实际形状并读取实际输出；输入输出映射保留来源频率坐标 |
| worker `modelBatch` shape 与请求配置必须完全相等 | 可适配 | 保留包长度、batch与来源关联；允许不超过配置窗口的真实短帧数；传递实际layout |
| decoder 用请求 FFT 推定模型 bin 宽 | 可适配 | 依据模型布局解码，再反变换到分析频率网格与Hz，裁剪合法源频带 |
| TensorRT/CUDA ABI、engine平台兼容、资产hash/IO dtype | 必要条件 | 保留真实兼容判断；实际运行失败给出原因，不能伪造推理 |
| 文件不存在/不可读、格式错误、来源变更/代际不一致 | 必要条件 | 保留并隔离旧回调；标签/手动/历史结果仍可用 |
| 时间/频率非空、有序、物理边界、有效前缀 | 必要条件 | 保留；Partial明确已读/未读，不静默截断原始标签 |
| NaN/Inf、整数溢出、字节长度与内存边界 | 必要条件 | 保留；运行批量按实际预算降低，最终不可执行时明确错误 |
| batch≤2、topK≤512 | 导出能力 / 参考默认值 | 当前包批量上限由engine描述，逻辑工作分批；topK受实际输出和资源限制，不能照搬参考上限 |
| 旧测试“9帧必须失败” | 错误产品约束 | 改为非默认形状实际适配；错误张量字节数、非有限值仍应失败 |

## 实施契约

1. 用户分析参数继续保持现有控件及含义；显示抽取与检测独立。模型适配版本独立记录，旧工程/运行按原有语义读取，不重算旧结果。
2. FFSCN 使用同一冻结权重导出动态 TensorRT 输入。频率按2048向上对齐，新增列为归一化域中性值，记录有效bin范围并裁剪输出；不把对齐当真实频率分辨率提升。
3. SCN 对实际帧取最大谱，在功率域按物理频率网格重分箱到32768；保持每窗min/max归一化。默认32768点输入为恒等映射。
4. 短窗实际帧数单独携带，实际支持、FFT补零、观察窗口与精修活动段分别保存。不用重复帧补齐，也不制造未读样本。
5. R2实现模型/layout与worker适配；R3再改真实来源短窗、UI提交和任务流程。R4补原型闭环，R5稳定性/性能与正式回归，R6文档/交付/最终推送。
