# M0｜宽带检测契约冻结

状态：执行中的正式决策记录，2026-10-13。来自用户批准的 Review Draft 4；后续实现不得静默改变配置身份或历史结果语义。

1. 本地离线单文件单 ROI，一次一个计算任务，其余排队；任务携带 projectGeneration/fileId/runId 和不可变快照。
2. 三来源统一 Annotation，原始证据不可变，修订与复核分开。接受不复制框；旧 Mark ID 与 Channel.sourceMarkId 原样迁移。活动段采用零起始样本半开区间，序列化为 uint64 十进制字符串，RF/基带轴显式声明。
3. 原始标签适配只有生成器带键 TXT 和用户指定 TorchSig rfbench SigMF。同名 rfbench JSON 仅补充/核验。新增受限双通道 PCM16 WAV 元信息适配，RIFF chunk 解析不假设固定头长。
4. 主线配置固定为 `ffscn-gui-iq-v1`，源权重 epoch-1200；SCN 最大谱是对照，HY epoch-210 是独立历史频率基线，FFSCN-17 是实验。模型身份和已验证能力分开；历史二维 F1=0.8261 不写成本项目结果。
5. 初始主线全有效带宽对齐。GUI 子带参考是整段 FFT 重采样，后续有界实现需要独立版本与数值对照；不直接声称块 FFT 与整段等价。短于10个真实时间槽默认拒绝未验证 shape，不复制谱帧。
6. sample/ROI/粗定位是互斥策略；细化负责时间拆分时不先用粗帧最短突发删除目标。fallback 保留原因与时间质量；窗口覆盖率不是占空比或任务完成率。
7. schema 文件限定结构，运行时另校验 uint64 上限、范围正序/物理边界、有限数、ID引用、来源身份、评分/窗口统计及工程内路径。JSON schema 单独通过不等于语义合法。
8. 工程 v5 保存统一索引、修订与来源集合；大结果不可变分片先落盘、manifest后发布、正常保存才更新工程索引。缺核心数据不部分替换当前 Session；终态与覆盖范围分别记录。
9. 当前 Qt 主图背景框选缩放、坐标轴平移、滚轮轴控制继续作为基线。M0-P 先交可点击原型并确认交互，再进 M1/M2；原型仅浏览器演示，原生验证使用第二连接屏 4K/150%。
10. 每节点完成、验证、更新状态后本地提交；最后全部完成才推送。用户已授权，不为常规构建/修复/提交重复询问。仅在影响用户目标、无法依据现有契约确定或必须作人工评审时提问。

结构契约位于 `contracts/wideband-detection/v1/`，模型 profile 位于 `contracts/wideband-detection/profiles/`。本节点不承诺稳定第三方 ABI；后续 worker控制消息使用版本/长度/序号/二进制布局显式定义。资源预算沿用单次读取32MiB、双块队列、CPU中间缓存256MiB、结果分片4096条或8MiB、图层最多10Hz；以实测报告记录调整。
