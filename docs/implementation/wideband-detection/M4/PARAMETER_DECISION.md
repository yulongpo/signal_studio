# M4 参数生效规则：用户确认方案 A

用户已明确确认方案 A：保留 M0-P，补足算法参数语义。保持原型布局、控件、固定动作、策略说明和参数启用矩阵；原批准 22 个文件与指纹继续保留。

| 情况 | 已批准原型及当前 Qt | 冻结 GUI 数学能力 |
|---|---|---|
| ROI | 边缘比例、平滑可编辑且说明生效 | 自适应正像素阈值、固定 5 单元平滑；不读取 sample 的边缘比例/平滑值 |
| sample/ROI 关闭拆分 | min on/off 禁用并说明不生效 | 仍先按 min on 删除短 run、按 min off 合并，之后输出首尾单段 |

首轮 domain 核心遵循右列数学行为。用户确认 A 后，当前实现已补足左列参数语义，并以独立 v2 数值版本记录；参数变化测试、同源对照及原生截图仍按节点要求完成，不能仅因确认就宣称 M4 验收通过。

建议方案 A：保留 M0-P 全部交互和启用矩阵，在独立实现中补足参数语义。ROI 自适应时间/频率门限乘以 `edgeRatio/0.6`，固定 5 单元平滑按 `smoothSeconds/0.001` 调整为相邻正奇数（至少 1）；默认值仍对应冻结参考。关闭拆分时不应用可编辑 min on/off，输出首个至最后一个可靠 on 单元的单段；保留必要的信号可靠性检查。该扩展使用新数值版本，参考默认与扩展参数分别对照，不能称所有参数组合与旧 GUI 完全等价。全局噪底裕量仍用于频率处理，sample 的门限仍由带限线性功率得出。

方案 B：保留冻结 GUI 精修数学行为，更新 M0-P 的参数矩阵及对应 Qt 控件规则：ROI 禁用 sample 边缘比例/平滑并解释自适应门限与固定平滑；sample/ROI 关闭拆分后仍启用 min on/off 并解释其过滤作用。布局、三来源、任务及复核流程保持。更新后的原型与 Qt 一起回归；原批准版本及其指纹继续保留。

方案 A 的确定细节：ROI 平滑窗口取 `2*floor((5*smoothSeconds/0.001)/2)+1`，限制为 1–63 个单元；默认 1 ms 对应 5。关闭拆分时，sample 保留固定 0.5 ms 可靠性最短 run，ROI 仅保留一个有效池化单元的可靠性要求，不读取用户的 min on/off；首尾输出统一单段。两者记录实际生效值和 `durationParametersApplied=false`，不将固定可靠性规则叫作用户参数生效。

sample 高覆盖连续轨迹的默认比例仍为 0.5；使用 `0.5*(edgeRatio/0.6)` 使已启用的边缘比例保持可调，默认 0.6 仍对齐参考。该非默认参数扩展同样使用 v2，不把固定 0.5 覆盖用户输入描述成参数生效。

此次确认不改变分数、模型、数据或验收门槛，不使用手工修边代替算法评价。默认 ROI 与旧参考对照；扩展参数以及 no-split 作为经用户批准的独立算法版本评估，不把有意改变的参数语义称为旧参考完全等价。

补审后的作用域修正：仅 Sample/ROI 的不可靠结果可以进入独立测量的 Coarse 回退；回退固定使用既定 6 dB、minBurst 10 ms、splitGap 20 ms，忽略界面已禁用的 Coarse 历史值，保留已启用的拆分开关及用户存储配置。直接 Coarse 使用其生效的时长值；无可靠活动时保留 fallback/未知观察，不以默认时长再次分析。保存证据明确记录固定回退政策与实际有效参数。SCN 的无效裕量控件例外另见 SCN_PARAMETER_DECISION.md，仍等待用户确认。
