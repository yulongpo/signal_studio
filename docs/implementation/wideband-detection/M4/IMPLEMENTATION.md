# M4 时间定位与复核实现

本节点接在 M3 提交 `6ed5ce0` 之后。产品交互继续使用获批 M0-P；参数语义采用用户确认的 A 方案，数值版本为 `signalstudio-refinement-m0p-parameters-v2`。节点退出证据以实际自检、评价和原生报告为准，本文件只说明实现及边界。

sample 直接读取真实源样本上下文，做相对频移和原长度 complex64 raised-cosine FFT 切带，再从线性功率定位活动。没有把显示抽帧、补零后的模型窗或名义窗口当作实际活动。任意 FFT 长度使用混合基数及必要的 Bluestein，逆变换归一化；滤波支持、因果平滑、源坐标和门限均保存。平滑使用 float64 rolling 后存为 float32，其与冻结 Torch float32 cumsum 的差异必须独立诊断，不能只看最终框相似就称数值等价。

ROI 使用实际 STFT 时间格和 RF bin 边界，在 512×64 池化坐标上进行正像素、时间及频率筛选，再映射回实际帧/样本。插值不能增加真实帧数。可调边缘比例与平滑及关闭拆分后的 min on/off 规则见 `PARAMETER_DECISION.md`；默认及扩展版本分别报告。fine 失败时只允许已独立测量的 coarse 活动作为回退，无法测得活动则保留未知时间，不把整个观察窗伪装成精确事件。

活动去重采用严格样本 overlap/touch；正的一样本间隔不桥接。跨候选合并保留不可变父快照和 derivedFrom，唯一窗口按最高分贡献一次再计算 mean/max。合并摘要不继承一个父候选的门限、噪底或频率测量。最终原始记录只接受未确认 Pending algorithm-origin r0、原始活动一致及无人工编辑字段；工程中的正常人工修订仍由既有工程持久化保存。

任务 manifest v2 保存实际 computationPhase 与候选处理进度；v1 历史结果继续可读。进度包含回退，不能解释为成功数。原始 head、固定网格及来源指纹继续由 M3 链路验证；任务终态在精修后再次核验源身份。工作区预算、事件数量、融合比较量与累计物理 cell 读取均有限制，取消或真正读取/数值失败不能被吞成成功。

复核卡只绘制保存的至多 512 点实测平滑功率聚合，选择时不重读 IQ；卡片同时显示保存的实际比较门限。接受确认同一对象，不复制记录；创建通道保存源/模型/run/revision/segment 快照。人工修改后通道关系变为 Changed，原通道的样本范围和来源快照不静默更新。CPU DDC、QRhi 显示和 TensorRT 推理分别留存证据。

G 是冻结的 10 个生成器 WAV 新基线，T 是独立生成的 96 文件 holdout。二者均不能被称为真实 RF 采集。数据、代码、profile、运行预算和评价口径须在正式结果之前冻结；失败文件保留全部真值，未知时间按 zero-IoU 预测计入分母。纯噪声误报率只用实际完成的观测时长和带宽，失败文件另列，不能当作成功零检出。

原生检查复用 `scripts/screenshot.ps1` 与既有 Qt capture，在实际第二连接屏 Redmi 27 NU / DISPLAY6、4K、150% DPI 全屏运行。新增真实 sample、确认、DDC、保存重开、人工修订及 ROI 参数场景；探针切换按当前可见图谱等待实际 QRhi，并以快照内容核验跨序列化保存。浏览器原型、offscreen 测试及生成数据分别标明各自证据范围。
