上下文变化取消旧请求。辅助证据隐藏时关闭旧详情并清空上下文。

用户明确不执行大型 RFbench 事件验证，因此新增测试只使用常规大小真实导入及小型合成分页文本。

见 POST_REVIEW_FIX.md。检测、DSP 和持久化实现仍未修改。

二次复审指出的重复词跨页与 CRLF 搜索偏移已修复：按原文匹配范围扩展视口，
