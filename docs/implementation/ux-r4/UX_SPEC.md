# UX-R4 R1 交互规范

原型：`prototype.html`。可切换来源、段、质量、模拟多选、调整侧栏宽度、展开详情和复制；
此原型仅证明信息架构，原生点击与功能验收以 Qt 为准。

1. 对象摘要：名称 / 类别、来源、质量、当前第 n/m 段。长名称允许正常换行，
   完整身份只在技术详情。多选明确当前对象及选择数量；不暗示几何编辑作用于全部对象。
2. 当前范围：起始/结束 ms、频率下/上界 MHz，标明 RF/基带，派生持续时间与带宽。
   保留 Enter、Tab、应用内失焦提交和 Esc 取消；窗口失焦不提交。
3. 主操作：定位、创建窄带通道位于范围之前。定位改变视图；普通选择不改变视图。
4. 段管理：上一段/下拉序号/下一段；拆分、合并、增加段；危险删除单独一行。
   未定位时间显示原因，采用观察范围需要明确人工操作，不制造活动段。
5. 技术详情默认关闭，以独立非模态窗口容纳滚动事实、原始全文和复制。
   侧栏和辅助区使用同一组件与事实生成器。完整原始 JSON/路径/证据引用/修订历史不能丢失。
   切换对象或文件时同步或关闭详情，不能显示过期来源。

按钮：primary 用于定位/创建；secondary 有边框，tertiary 用于低优先级详情，
destructive 使用危险色；toggle 明确 checked。所有状态保留 hover/pressed/focus/disabled。
侧栏最窄 320、默认 390、展开 650 逻辑像素；常用按钮至少 28 px，图谱按钮至少 24 px。
不缩小全局字号。控件采用可伸缩布局及字体测量。工具栏低频参数进入既有“更多设置”，
同一参数仍只有一个编辑器，重排不得提交或丢失草稿。

图、树、表、右侧属性以业务 ID/activeSegmentId 为唯一选择依据；来源颜色与当前/悬停/焦点
样式独立。原始数据、软删除撤销、来源快照、.ssproj 和实际分析管线保持原有契约。
