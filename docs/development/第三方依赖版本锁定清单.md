# 第三方依赖版本锁定清单

Signal Studio 公共 API 不暴露任何第三方类型。第三方依赖仅经适配器在 .cpp 内 PRIVATE 链接。

## 1. 实际使用的依赖

| 依赖 | 版本 | 来源 | 许可证 | 用途 | 安装方式 | 发布包包含 |
|---|---|---|---|---|---|---|
| Qt | 6.11.1（最低 6.10.3） | `D:\softwares\Qt\6.11.1\msvc2022_64` | LGPLv3/商业 | UI 框架 | 系统安装 | 是（windeployqt 部署运行库） |
| CUDA Toolkit | 12.4 | NVIDIA 官方 | CUDA EULA | cuFFT GPU FFT 后端 | 系统安装 | 否（可选运行时） |
| cuFFT | 随 CUDA 12.4 | NVIDIA | CUDA EULA | GPU FFT | 随 CUDA | 否（可选） |
| MSVC 2022 Runtime | 14.44 | VS BuildTools | Microsoft | C++ 运行库 | VS BuildTools | 是（VC143 CRT DLL） |

## 2. 声明但本机未安装（环境偏差）

| 依赖 | BL1.0 用途 | 状态 | 替代 |
|---|---|---|---|
| oneMKL | CPU FFT 默认后端（ADR-006） | 未安装 | cuFFT GPU 后端可用；CPU FFT 接口返回 unavailable |
| Eigen3 | 内部矩阵运算 | 未安装 | 未使用 |
| oneTBB | 并行 | 未安装 | 未使用 |
| HDF5 | Dataset 存储 | 未安装 | JSON 清单实现 |
| ONNX Runtime | 模型推理 | 未安装 | NullInferenceSession 诚实返回 unavailable |
| pybind11 | Python 绑定 | 未安装 | Python 绑定留待后续 |
| spdlog/fmt/nlohmann-json/tomlplusplus/gtest/benchmark | 构建/测试 | 未安装 | 手写 JSON/日志；GoogleTest 用自定义 `--case` 运行器 |

vcpkg manifest 模式会从源码编译 Qt（与系统 Qt 冲突），故未启用；`vcpkg.json` 保留 BL1.0 声明作为版本锁定记录。

## 3. 获取优先级（按任务文档 §5.2）

1. 项目批准依赖管理器（vcpkg manifest）- 未启用（Qt 冲突）
2. vcpkg manifest mode - 未启用
3. Conan - 未用
4. CMake FetchContent - 未用
5. 官方安装程序 - Qt/CUDA/MSVC 经此安装
6. 官方源码发行包 - 未用
7. 官方 Git 固定 Tag/Commit - 未用

## 4. 重复安装

`scripts/bootstrap.ps1` 检测 OS/VS/Qt/CMake/Ninja/CUDA/依赖管理器，复用兼容版本，不降级或覆盖其他项目依赖。
