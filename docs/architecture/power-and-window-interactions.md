# 电平参数、游标标注与窗口交互

## 参数与功率范围

`domain/power_display.h` 定义无 Qt 依赖的 `PowerDisplayRange` 和自动适配函数。有效范围为动态范围 `0 < D ≤ 10000 dB`、参考电平 `−200 ≤ R ≤ 100 dBFS/Hz`。`Session::setPowerDisplayRange` 一次应用到全部文件和通道，令 PSD 纵轴为 `[R−D,R]`；不记录逐字符历史，不改变驻留坐标。手动 PSD 纵轴可独立调整，下一次电平参数应用时重新对齐。

参数下拉框保留预设及自定义输入，关闭自动补全。`editTextChanged` 通过独立入口即时应用有效数值，刷新时跳过正在编辑的输入框。空值、单独正负号及非法范围保留编辑内容，沿用最近有效参数；结束编辑后显示规范格式。参考电平仍存入旧 `referenceLevelDb` 字段，不升级工程格式。PSD 纵轴校验为有限、严格递增、跨度不超过 10300 dB；QSettings、工程 JSON 和视图恢复使用相同规则。

“自动适配电平”仅执行一次：从当前可见热图实际帧和当前 PSD 的完整不可变线性功率数组取有限正值的极值，按分析功率下限 `1e-20` 转为 dB，再在上下各留 3 dB。当前 PSD 为平均谱或驻留帧谱；宽带显示波形时，未显示的 PSD 不参与适配。结果达到合法边界时提示，数据未就绪或无有效功率时禁用入口。GUI 按数值快照身份缓存适配结果，悬停和普通刷新不重复扫描矩阵。

宽带曲线计算保留 `averageSpectrum` 的线性功率快照，窄带计算回调同时提交平均谱、STFT 帧及显示数组。当前帧谱用共享所有权的别名指针引用原 STFT 帧，不复制或重新计算。参数变化仅更新色阶纹理/PSD 几何，自动适配也复用已有 FFT/DDC 结果。

## 游标与反馈

`cursor_overlay.h` 将数值读数拆成横轴坐标、纵轴坐标和幅值/功率标注。波形/PSD 的横轴信息贴竖线底端，幅值/功率位于竖线上端；时频/瀑布图按实际轴方向排列时间和频率，功率优先位于十字右上方，靠边时换侧并限位。悬停和驻留文字直接叠加在谱图上，不绘制背景或边框，每段文字完整放在游标线一侧并避开游标线。游标线及每个文字像素使用其实际背景的 RGB 反色；驻留使用加粗实线，悬停使用细虚线。标签限制在绘图区内，避开顶部状态说明。帧/bin、分箱、源样本等元数据可在幅值/功率文字的工具提示中查看，也保留在诊断属性中。

GPU 路径单独生成透明白色游标/文字蒙版，先绘制数据和普通覆盖层，再使用 QRhi 混合因子 `OneMinusDstColor`、`OneMinusSrcAlpha` 合成蒙版，输出 `a × (1 − C) + (1 − a) × C`，其中 `C` 为当前帧的实际背景、`a` 为文字/线条的抗锯齿覆盖率。不读回 GPU 图像，也不从热图功率猜测背景色；透明像素不改变背景。软件回退把同一蒙版一次性以 QPainter Difference 合成，避免十字交点或两组游标重叠时重复反色。诊断增加 `inverseCursorDrawCalls`，原生测试逐像素对比游标线和文字与背景的反色关系。

驻留标注先布局，重叠的悬停标注隐藏；鼠标离开只清除悬停。重新分析后按原物理驻留坐标读取新结果，数据不可用时显示坐标及“数据不可用”；移出视图时隐藏对应驻留标注。覆盖层刷新不更新图谱数据缓冲或功率纹理。

`interaction_feedback.h` 共用绘图区/坐标轴命中、光标形状和轴高亮颜色。绘图区十字，轴悬停张手，平移握手，框选十字。宽带标记编辑和导航保留各自操作反馈；窄带专用图形只对支持的操作显示反馈。释放、离开、Esc、取消和切页清除临时状态。

## 主窗口顶栏

仅主窗口使用 `FramelessWindowHint`。原 34 逻辑像素应用菜单栏右侧放置最小化、最大化/窗口化、关闭按钮，对话框保留系统装饰。菜单和按钮不进入空白顶栏的拖动/双击处理；空白区拖动调用 `QWindow::startSystemMove`，普通窗口 6 像素边缘调用 `startSystemResize`。最大化/全屏关闭边缘缩放。

普通几何独立记录，最大化使用当前屏幕可用工作区，窗口化恢复最近普通几何并限制到该工作区。窗口动作取消未完成图谱手势，保留工程、任务及驻留坐标；关闭按钮调用原关闭路径。窗口恢复后继续使用同一 D3D11 QRhi API，图谱资源按实际尺寸重建。

原生验收入口为 `scripts/verify-linked-cursors.ps1`。验收程序使用 Windows 原生输入验证顶栏拖动和边缘缩放，并核对三个按钮、空白区双击、菜单隔离、几何恢复，随后回到连接显示器 2 的原生 4K/150% 全屏。报告同时保留电平即时输入、自动适配数值、驻留标签位置、FFT/DDC 复用和 GPU 资源计数。
