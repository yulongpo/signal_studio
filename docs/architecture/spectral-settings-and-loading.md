# 独立谱参数、补零和前缀加载

## 数据与统计契约

`PsdSettings` 与 `SpectrogramSettings` 分别进入请求身份。宽带使用全局显示偏好，窄带按通道保存；新通道默认 Welch、平均谱、整个通道。PSD 参数变化不替换已有 STFT 矩阵；STFT 参数变化不启动全通道 PSD，驻留帧谱直接使用所选 STFT 的完整数值及参数。

FFT 档位为 32–65536（5–16 阶），N 始终是可见频段中的点数，频率上边界排除。默认观测长度为 `ceil(FsAnalysis / (B/N))`；自定义分段时长覆盖该长度。缩小频段重新计算 CZT 与所需观测长度，补零只改变频率网格，不增加真实分辨率。时间范围内没有真实输出样本时返回明确的无数据状态。

PSD 支持周期图、Bartlett、Welch、等权 DPSS 多窗和复数 Burg。周期图对完整选定区间作一次估计，超过单帧长度上限时提示缩短区间或采用分段方法。Bartlett 固定零重叠，Welch/多窗/Burg 按配置分段；平均、最大、最小在完整统计区间内逐频点计算。默认 50% 重叠；窗函数为矩形、对称 Hann/Hamming/Blackman/Blackman-Harris/Flat-top/Kaiser（β=8.6）。DPSS 默认 NW=3.5、K=6，独立计算 Slepian 三对角算子的特征向量；Burg 默认 16 阶、允许 1–256，拟合仅使用真实样本。

窗系数按真实有效观测长度生成，然后补零。FFT 密度为 `|X|²/(FsAnalysis × sum(wValid²))`，尾段按有效窗能量加权；单点或退化窗采用非零有效窗。DPSS 的 NW/K、Burg 阶数都按有效长度校验；不足时返回原因，不切换算法。显示有效观测时长、补零样本量、Δf 和 ENBW；Burg 不使用窗函数，其 ENBW 字段为 0。参照 [SciPy Welch](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.welch.html)、[SciPy DPSS](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.windows.dpss.html) 与 [Burg 定义](https://www.mathworks.com/help/signal/ref/pburg.html)。使用明确窗系数对照，不能将 SciPy 默认周期 Hann 和本工程对称 Hann 混用。

窄带 PSD 有独立可取消线程，完整处理每个分段及短尾段，不再限制为 64 个代表帧。进度回调提供未完成阶段结果；波形和 STFT 独立计算。DDC 仍按需处理有界 IQ 块，共享缓存由互斥量保护。IQ LRU 为 128 MiB，分析缓存总计 128 MiB，单帧工作缓冲不超过 64 MiB；单帧分析样本另限制为 262144。DPSS 迭代检查取消。运行任务和缓存不写工程。

## 短时频图与游标

正常 STFT 按配置重叠生成完整帧，并在显示预算内覆盖整个可见区间。窄带不足 10 帧时，按 `(i+0.5)/10` 安排显示中心，缩小实际步长并在范围之外补零；有效数据少于 10 时可重复观测。界面区分配置/实际重叠、步长、补零帧和重复观测，时间轴保持原物理范围。

每帧保存整数源区间、中心、独立 ID 和相对显示位置。纹理、悬停及点击使用同一显示位置到帧映射。重复源中心通过点击帧 ID 区分；驻留功率读数和 PSD 使用同一个帧。重算后按驻留物理坐标重新选择有效帧。游标及文字仍无背景、避开线条，并对底图取反色。坐标、网格可由 CPU 覆盖层绘制；数据曲线及热图由 QRhi 顶点缓冲/标量纹理/LUT 绘制。

窄带隐藏页面可能在布局完成前接收功率矩阵。页面显示或尺寸变化时更新 GPU 热图的目标矩形，复用相同纹理，不重新分析。原生切页验收同时检查目标矩形和绘图区右下方实际像素，避免“有 GPU 绘制调用但只覆盖旧的小区域”的误判。

## 顺序读入与前缀

`SourceLoader` 顺序实际读取 4 MiB IQ 块，逐点计算 ADC 计数等效复数模；峰值桶达到 2048 个时相邻合并，保留峰值及真实样本位置。运行快照只包含计数和不超过 2048 个包络点，不保留整个文件 IQ。完成块后才发布已读计数，停止后等待当前块结束，因此保存前缀总是完整 IQ 样本边界。

读入时导航显示进度、已读字节和样本数，标题栏提供停止按钮，图谱等待。结束后使用全文件或已读前缀进行分析；导航恢复 GPU 包络曲线。导航滚轮只改变跨度，以当前窗中心为锚点并在头尾修正；点击和拖动仍定位。源索引使用 uint64，先整数减原点，再投影到像素。

所有映射读取通过 `availableSamples()` 限制逻辑长度；DDC 配置检查通道提取区间不超出前缀。超出前缀的标记和通道保留，并在工程树及通道状态显示“来源未读入”。源文件大小/修改时间构成指纹，重开和实际分析请求检查指纹；变化或读入失败禁用分析。新建临时节点在停止时尚无完整样本且没有引用记录时撤销。关闭或替换工程后旧读入任务停止，回调由工程/配置/请求代次隔离。

## 状态、控件与兼容

工程版本 3 保存独立谱参数、物理样本数、可用前缀与源指纹。uint64 仍使用十进制字符串；完整校验后才替换状态，数值/枚举错误均返回导入失败。版本 1/2 保持原统计范围，新通道才采用全通道默认。旧 FFT 值超出新档位时保留，显示旧值和确认提示；分析计划明确拒绝，不静默改写。

自定义下拉框第一项保存唯一最近自定义值，第二项为分隔线，随后保留预设。手动有效输入与自动电平适配替换自定义项，选择预设不会删除它。更新列表保留焦点、选区和光标；编辑中间态不提交，结束编辑恢复有效规范值。最近自定义值保存到独立 QSettings 键。

选中标记仍保留，保存只使用限时状态栏和日志反馈，不再在热图顶部持续绘制“已保存”提示。

所有勾选框共用 `ui/checkbox_style.h`：未选中采用灰蓝边框与蓝灰底色，选中采用亮蓝底色及白色勾号；悬停、键盘焦点、按下、禁用和部分选中分别显示。宽带、窄带及通道配置对话框使用同一规则，图标打包为 Qt 资源，不依赖 Windows 原生黑色指示器。

- Qt UI：独立参数与缓存、自定义首项、中心保持、停止/重开前缀、驻留/反色、电平、75% 波形及既有宽带工作流。
- `scripts/verify-spectral-loading.ps1`：独立输出目录、系统 PATH、连接显示器 2 原生 4K/150%、真实大 IQ 的读入/停止/重开、补零帧谱及 D3D11 数据绘制；常规 GPU smoke 另覆盖四页与软件回退。
