# 游标联动与可见频段分析

宽带和窄带采用相同的频段分析与游标契约。`N` 是当前可见频段的频点数，`Δf = B/N`，频率上边界不重复计入。缩小频段会增加目标采样时长；不足时补零，保留 N 和原时间轴，补零不增加真实分辨率。当前独立参数与加载契约见 [频谱参数与前缀加载](spectral-settings-and-loading.md)。算法参考 [SciPy ZoomFFT 的公开定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.ZoomFFT.html)，由本仓库独立实现。

## 数值与映射

`SpectralAnalysisPlan` 在纯 C++ 领域层保存频率网格、分析采样率、实际输入样本数、所需时长和 Hann 等效噪声带宽。频段缩小时先进行整数模 NCO 混频和 Kaiser FIR 二倍降采样，分析采样率保持至少 `2B`；随后通过 Bluestein 卷积实现 CZT。每帧采样数为 `ceil(FsAnalysis/Δf)`，原始采样数再乘降采样比，因此实际帧时长至少为 `N/B`。

输出功率为 `|X[k]|²/(FsAnalysis × sum(w²))`，单位 `dBFS/Hz`。平均 PSD 在线性功率域平均，驻留帧 PSD 直接使用 STFT 帧的同一份数值。频段缩放不会改变通道的 DDC 配置。宽带提供源 int16 IQ，窄带提供已有通道输出；频率内部保持基带 Hz，宽带会话游标另保存 RF 值。

所有真实观测样本来自当前可见时间窗；不足的帧在窗外补零。滤波邻域读取受可见边界限制，边界之外零延拓。窄带先将可见源时间窗向内映射到完整输出样本范围，避免用窗外输出凑够 FFT。不足时补零，保留原范围和 N；“扩展时间窗”仍可由用户显式调用。极窄频段超出单帧资源预算或整数映射范围时明确拒绝。

`SpectralFrame` 保留完整 N 点线性功率、提供器及源样本半开区间、整数帧中心和帧 ID。STFT 默认使用 50% 重叠，可独立配置；窄带不足 10 帧时均匀安排 10 个显示中心并补零。预算不足时在整个可见时段的帧序列中均匀选择实际帧。显示时间单元映射到最近实际帧中心，频率单元使用峰值抽取。瀑布图只是同一数据的坐标转置；像素尺寸不代替分析点数。源样本索引保持 uint64，先做整数原点减法再投影，覆盖超过 `2^53` 的小窗。

## 会话与交互

`Session` 按文件 ID 或通道 ID 保存 `LinkedCursorState`。波形单击更新时间，PSD 单击更新频率，热图单击更新两者；缺失的另一维采用当前范围中心。波形和热图单击选帧，PSD 单击保留帧。驻留帧模式暂用 STFT 的 N，平均谱 N 与范围设置保持原值。清除驻留后恢复平均谱。

窄带顶部与右侧栏的 FFT、RF/基带和网格控件双向同步，作用于当前通道；宽带文件的对应设置保留。驻留帧模式禁用平均谱点数控件，并说明有效点数随 STFT。

跟随游标由控件局部状态维护，不写 Session、不请求 DSP。数值读数使用原波形/谱数据，并注明分箱、帧或 bin；文字框在绘图区内换侧和限位。驻留和悬停使用各自线型，文字无背景，游标及字符由 GPU/软件覆盖层对底图逐像素取反；视图外驻留坐标隐藏，物理坐标保持原值。宽带辅助区切换模式后仍恢复同一驻留坐标。

单击与拖动使用 5 逻辑像素阈值。标记拖动、创建标记、框选和轴拖动不产生驻留。Esc 首先回滚未完成手势，其次清除驻留，再处理面板还原。时间/频率横轴范围由各上下文共享，纵轴独立；RF 标签切换不改变内部基带频率。相对时间零点为通道提取起点。

游标及运行中的选帧状态不写工程 JSON。新建/导入工程递增运行时代次并清除会话数据，即使文件/通道 ID 与原工程相同也不会接受旧请求。删除文件、源标记或通道释放其驻留与分析数据；参数修改取消旧请求并使旧谱失效。

## 调度、缓存与 GPU

窄带移除了旧的前 1,500,000 输出样本截断。波形桶覆盖完整可见时间；IQ/相位采样具有真实源坐标，RMS/包络在有界输出块中累积。逐样本模式显示每个实际采样位置。宽带包络也扫描完整桶以保留孤立脉冲，宽带 RMS 总览仍使用有预算的均匀探针。

窄带在停止交互 60 ms 后计算最终视图；新请求取消并 join 旧工作线程，回调核对请求代次及通道配置。宽带保留预览/60 ms 精细请求及可替换后台邮箱。频率、时间、N、源大小/修改时间、工程代次进入请求身份。色阶、动态范围、参考电平、网格及悬停重用分析数据。

通道 IQ LRU 为 128 MiB。Session 最近上下文矩阵 LRU 为 64 MiB，宽带显示载荷缓存另为 64 MiB，总分析缓存预算为 128 MiB；单次矩阵最多 800 万频点。窄带保存当前上下文的矩阵和标量显示栅格，回到较早视图可能重新计算分析，但可复用 IQ 块。当前仍为可替换请求调度，没有独立重叠请求合并/优先级队列。

曲线使用 QRhi 顶点缓冲，热图使用有界标量纹理与 GPU LUT 调色。完整 N 点保留在数值矩阵中，显示栅格先按像素预算抽取，不创建超过 QRhi 上限的纹理。游标、网格与文字使用 QPainter 覆盖层。悬停允许覆盖层上传及完成帧增加，但不得增加 FFT/DDC 次数、数据纹理上传或顶点上传。

`PlotWidget::renderStatistics()` 与 `NarrowbandWorkspace::renderStatistics()` 记录有效 N、Δf、真实帧时长、ENBW、实际帧数、缓存和 GPU 数据更新。星座、眼图、识别与解调仍为标明来源的合成演示；本改造不新增真实同步或解调。

## 验证入口

- CTest：`signal_studio_spectral_analysis` 验证直接 DFT、邻近双音、负频偏、噪声积分功率、边界、取消、整数映射和逐 bin 帧谱一致性。
- `scripts/verify-spectral-reference.py` 使用原生导出的同系数夹具，对照 SciPy 的 FIR 和 Zoom FFT。
- `scripts/verify-linked-cursors.ps1` 在第二块 4K/150% 屏以独立包验证实际鼠标事件、GPU 覆盖层复用、固定 N 频段缩放、宽带瀑布和全部窄带页面；可附加本机大 IQ 文件。
- 常规 `scripts/gpu_smoke.ps1` 分别验证 Debug/Release 的宽带、窄带四页及明确的软件回退。
