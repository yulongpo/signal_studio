# 窄带通道实现

## 数据与状态边界

`domain/` 中的 `Channel` 保存源文件/标记、创建时中心频率与时间范围、窄带中心/带宽/输出采样率、滤波档位、配置版本和各页视图参数。`Session` 执行创建、编辑、激活、删除、来源定位与每通道最多 40 条时间视图历史。配置编辑采用新旧快照替换；取消不会修改原通道。工程 JSON 使用版本 3，保存独立谱参数与可用前缀，样本索引以十进制字符串保存，版本 1/2 可导入；非法数据在当前工程替换前被拒绝。

`ChannelSampleCache` 是窄带 IQ 数据提供边界。它按 16,384 个输出复样本对可见请求分块处理，采用 128 MiB LRU；键包含源路径、长度/采样率/中心频率、文件大小与修改时间、通道 ID/配置版本、源区间、中心/带宽、输出采样率和滤波计划。修改活动通道配置或关闭工程时清除缓存；切换通道保留其它通道的可重用块。只有当前视图请求的块会进入缓存，不会因创建通道预扫描整个源文件。缓存对象由工作区单线程顺序访问；请求替换先取消并等待旧线程退出。

## DSP 路径

`infrastructure/channel_processor.cpp` 独立实现 int16 小端 IQ 映射读取、相对源样本索引的整数模 NCO、Kaiser 窗线性相位 FIR、多级二倍抽取、有理 L/M 重采样，以及源样本区间映射。DDC 将源中心频率与通道中心频率之差移至基带。输出首尾采用零延拓；`ChannelSampleData` 标记受边界影响的块。规划器返回过渡带、阻带目标、FIR 系数、L/M 和工作空间估算，并校验有效频带、输出采样率和资源上限。

窄带 PSD/STFT 采用共用的可见频段分析服务，N 表示当前可见频段内的点数；缩小频段增加实际帧时长。完整可见时段按需分箱与选帧，不再截断前 1,500,000 输出样本。帧谱直接复用选中的实际 STFT 帧。游标、数值归一化、时间映射和缓存边界详见 [游标联动与频段分析](linked-spectral-analysis.md)。

## Qt 显示和合成区域

`NarrowbandWorkspace` 提供信号观察、调制分析、深度学习识别、解调工作台四页。通道 IQ 波形、PSD 和 STFT 来自当前窄带 DSP；星座/眼图、识别分数/进度和解调比特均为合成演示，并在页面上标注未执行同步、未执行模型推理或示意定位。测试用的内置 IQ 是确定性多音夹具，不代表现场采集记录。

图谱通过 `AcceleratedSurface` 走 QRhi 纹理和 QPainter 覆盖层，Windows 目标为 Direct3D11；surface 不可用时图谱改由 QWidget/QPainter 绘制。色阶、坐标、覆盖层与通道样本处理相互分开，游标/覆盖层更新不重新执行 DDC。界面使用源文件时间和基带 Hz 保存视图坐标；工具栏可切换基带/RF 频率标签，RF 显示按 `Fc + fBB` 换算并随通道写入工程。

## 当前实现边界

- IQ LRU 为 128 MiB，分析缓存总预算为 128 MiB。窄带保留当前上下文矩阵，回到较早视图可能重新计算分析；IQ 块可重用。
- 当前使用可替换后台请求和 60 ms 交互停止计算，没有独立重叠请求合并/优先级队列。
- 对应波形、PSD、STFT 的游标和轴范围联动已实现，纵轴独立缩放/平移、包络及 75% 自动适配沿用共享规则。星座框选、全部专用图表手势和完整最大化流程仍需按各自验收记录判断。
- 新频段服务已进行直接 DFT 与 SciPy 同系数谱功率对照。本机大 IQ 的创建、缩放、配置修改和取消证据见新的游标验收报告；这不代表连续处理吞吐或通道 DDC 全部数值的 SciPy 对照。
- 真实模型、载波恢复、定时同步、实际调制分类、真实解调和位流仍未接入。
