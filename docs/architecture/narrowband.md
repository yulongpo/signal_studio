# 窄带通道实现

## 数据与状态边界

`domain/` 中的 `Channel` 保存源文件/标记、创建时的来源身份与不可变快照、实际提取时段、窄带中心/带宽/输出采样率、滤波档位、配置版本和各页视图参数。`Session` 执行创建、编辑、激活、删除、来源定位与每通道最多 40 条时间视图历史。配置编辑采用新旧快照替换；取消不会修改原通道。

图、表、左树使用统一通道入口，一次明确绑定一个对象。质量“待判断 / 已采纳 / 已忽略”不作为入口或执行门槛；物理来源、实际提取范围和 DSP 计划仍须通过校验。多选时要求在表单指定一个来源，不自动合并对象。

| 绑定方式 | 来源绑定 | 实际提取范围 |
|---|---|---|
| `LocatedSegment` | 保存当前段的完整物理时间/频率范围和 `segmentId` | 可以在绑定范围内裁剪；创建时裁剪本身不造成 Changed |
| `UserRange` | 保存时间未定位对象的频率观察及来源身份，不伪造 `segmentId` | 默认当前可见时段与可用前缀交集；人工时段独立保存，不回写算法活动段 |

无可读默认时段也打开表单并显示具体字段原因；用户按“显式使用可用前缀”后才扩大时段。`LocatedSegment` 的前缀操作仍限制在绑定段内。MHz 控件保留尚未编辑的精确 Hz，提交中心或带宽后才重新计算频率范围，避免显示舍入破坏合法默认值。参数提交沿用 Enter、Tab/Shift+Tab 或应用内切换焦点规则。

来源关系按绑定几何和物理身份判断：改名称、备注、质量或无关兄弟段仍为 Current；绑定几何/物理来源变化为 Changed，绑定对象/段删除为 Missing。撤销恢复相同绑定可回到 Current。关系变化只提示差异，不覆盖创建快照或自动重算已有通道。

工程 JSON 当前为 **v6**，保存独立谱参数、物理长度、可用前缀、来源修订和两类通道快照；样本索引以十进制字符串保存，继续导入 v1–v5。首次覆盖旧版工程前，`ProjectStore` 保留其原始字节，备份名包含原版本和 SHA-256，核验成功后通过 `QSaveFile` 原子发布。重复保存相同旧字节复用备份，不覆盖同名不同内容。旧通道按创建时参数迁移，不据当前标记重算；非法数据在当前工程替换前被拒绝。U3 的实现及证据见[通道与持久化](../implementation/annotation-interactions/U3/IMPLEMENTATION.md)和[验证记录](../implementation/annotation-interactions/U3/VALIDATION.md)。

`ChannelSampleCache` 是窄带 IQ 数据提供边界。它按 16,384 个输出复样本对可见请求分块处理，采用 128 MiB LRU；键包含源路径、样本格式、物理长度/采样率/中心频率、可用前缀及加载代次、文件大小与修改时间、通道 ID/配置版本、源区间、中心/带宽、输出采样率和滤波计划。修改活动通道配置或关闭工程时清除缓存；切换通道保留其它通道的可重用块。只有当前视图请求的块会进入缓存，不会因创建通道预扫描整个源文件。缓存对象由工作区顺序访问并有互斥保护；请求替换先取消并等待旧线程退出。

## DSP 路径

`infrastructure/channel_processor.cpp` 通过 `Int16IqFile` 的元数据入口复用 `SampleFormat` / `RawSampleReader`，读取实际复数 IQ；该类名不表示仅支持 int16。处理器独立实现相对源样本索引的整数模 NCO、Kaiser 窗线性相位 FIR、多级二倍抽取、有理 L/M 重采样，以及源样本区间映射。DDC 将源中心频率与通道中心频率之差移至基带。输出首尾采用零延拓；`ChannelSampleData` 标记受边界影响的块。规划器返回过渡带、阻带目标、FIR 系数、L/M 和工作空间估算，并校验有效频带、输出采样率和资源上限。

计划、直接处理及缓存入口都限制 `channel.sourceTime.end <= availableSamples(source)`。Loading/Partial 的非空已读前缀可以处理，空前缀、Failed、越界、实数来源及物理身份改变给出具体原因。FIR 边界补零只扩展计算上下文，不读取首个未加载样本；WAV 的 Fs/格式仍严格与容器核对。旧工程存在容器冲突时应重新导入修复元数据，不能覆盖来源身份绕过校验。

窄带 PSD/STFT 采用共用的可见频段分析服务，N 表示当前可见频段内的点数；缩小频段增加实际帧时长。完整可见时段按需分箱与选帧，不再截断前 1,500,000 输出样本。帧谱直接复用选中的实际 STFT 帧。游标、数值归一化、时间映射和缓存边界详见 [游标联动与频段分析](linked-spectral-analysis.md)。

## Qt 显示和合成区域

`NarrowbandWorkspace` 提供信号观察、调制分析、深度学习识别、解调工作台四页。通道 IQ 波形、PSD 和 STFT 来自当前窄带 DSP；星座/眼图、识别分数/进度和解调比特均为合成演示，并在页面上标注未执行同步、未执行模型推理或示意定位。测试用的内置 IQ 是确定性多音夹具，不代表现场采集记录。

图谱通过 `AcceleratedSurface` 走 QRhi 纹理和 QPainter 覆盖层，Windows 目标为 Direct3D11；surface 不可用时图谱改由 QWidget/QPainter 绘制。色阶、坐标、覆盖层与通道样本处理相互分开，游标/覆盖层更新不重新执行 DDC。界面使用源文件时间和基带 Hz 保存视图坐标；工具栏可切换基带/RF 频率标签，RF 显示按 `Fc + fBB` 换算并随通道写入工程。

## 当前实现边界

- IQ LRU 为 128 MiB，分析缓存总预算为 128 MiB。窄带保留当前上下文矩阵，回到较早视图可能重新计算分析；IQ 块可重用。
- 当前使用可替换后台请求和 60 ms 交互停止计算，没有独立重叠请求合并/优先级队列。
- 对应波形、PSD、STFT 的游标和轴范围联动已实现，纵轴独立缩放/平移、包络及 75% 自动适配沿用共享规则。星座框选、全部专用图表手势和完整最大化流程仍需按各自验收记录判断。
- 频段分析服务的直接 DFT / SciPy 同系数谱功率对照不等于全部通道 DDC 数值验证。U4 在两配置正式模型流程中分别得到 16384 个有限、非零能量的实际 DDC 样本，Release 标记 U3 另复验 8000/8192/8192 个样本及保存重开哈希。文件 meta 标为 TorchSig 合成基准样本，不是现场 RF 实采。原生 Partial 场景为受控可用前缀，真实 SourceLoader 停止和首个未读样本边界由处理器/Qt 回归单独覆盖。
- 窄带识别模型、载波恢复、定时同步、实际调制分类、真实解调和位流仍未接入。
