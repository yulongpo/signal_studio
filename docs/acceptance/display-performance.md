# 显示抽取与交互性能记录

2026-10-09，Windows x64 / Qt 6.11.1 / Release，实际连接显示器 2（Redmi 27 NU，原生 DISPLAY6）。屏幕 3840×2160、DPR 1.5；全屏客户区 2560×1440。QRhi D3D11 使用 AMD Radeon(TM) 880M Graphics。下面全部使用模拟图谱，不代表真实 IQ、FFT/STFT 或持续采集吞吐。

## 抽取与缓存

默认波形模拟源 22488 点，按 2811 个物理像素列抽取为 5622 点，实际批量绘制 5621 个相邻线段。抽取保留每桶极值及原索引次序；命中、标记、历史和存储继续使用完整业务坐标。显示抽取测试覆盖尖脉冲、窄峰、非有限值、非法尺寸和二维峰值保留。

主图本轮滚轮预览请求为 300×178（53400 像素），低于 54000 的预算；静止显示为 750×430（322500 像素）。60 ms 是停止操作后的细化请求延迟，完成时间还取决于后台计算、GUI 回调与图形提交。单工作线程只保留最新请求，行间取消旧代次，GUI 再次核验代次。已有细矩阵同视图降采样使用二维最大值抽取；游标/标记更新复用已有热图纹理。

## 实际绘制对照

分段计时发现密集 `QPainterPath` 描边是主要停顿来源。改为缓存相邻 `QLineF` 并使用 `QPainter::drawLines()`，保留抗锯齿、颜色、逻辑线宽、DPR、裁剪和点序；同尺寸覆盖层 QImage 复用，游标/悬停值相同时跳过重复失效。

| 测量项 | 批量线段优化前 | 最终版本 |
|---|---:|---:|
| 导航 QPainter 绘制，4 次操作观测范围 | 36.54–38.54 ms | 2.00–3.89 ms |
| 波形 QPainter 绘制，4 次操作观测范围 | 128.40–147.24 ms | 14.62–16.43 ms |
| 主图 QPainter 覆盖层绘制，4 次操作观测范围 | 3.72–4.67 ms | 4.01–5.32 ms |
| 普通滚轮事件后的完整事件循环，4 次观测范围 | 198.88–216.64 ms | 47.94–62.08 ms |

前后均通过实际主图 `QWheelEvent`，每次调用 `processEvents(AllEvents, 2)` 并测量真实耗时。2 ms 参数不是单次原生绘制的硬上限；该循环包括三图绘制、排队回调和 Qt/驱动处理，可能处理不止一帧。表中耗时属于本机这次小样本对照，不能转换成 FPS、输入到显示的端到端延迟或 GPU 时间戳。

计时字段 `cpuWallTimings` 提供每阶段 last/max/total/samples；`overlayPainter` 是 QPainter 构造、绘制及结束的 GUI 线程墙钟时间，`paintEventIncludingQtSubmit` 包含基类 QRhiWidget 的完整 paintEvent。最终普通操作中，导航完整 paintEvent 约 2.50–4.43 ms、辅助图约 15.44–18.35 ms、主图约 6.90–10.63 ms。并非只测上传命令入队来宣称绘制快。

优化前原始对照见 [分段计时基线](display-performance-before-line-batch.json)；此前尚无分段计时的观测另存于 [初始事件循环基线](display-performance-before-overlay-cache.json)。最终完整数据见 [原生场景报告](screenshots/4k-display2-release/scenes/native-capture-report.json)。

## 连续输入与显示正确性

12 次连续滚轮事件总投递时间 3.00 ms，最大事件起始间隔 1.31 ms；同步 UI 处理 p50 0.090 ms、p95/最大 1.160 ms。此项仅测 `sendEvent` 返回时间。预览请求 53400 像素；最后细化 requested/committed generation 都为 21，worker 空闲且无待上传资源；期间丢弃 11 个旧结果/任务。一次实际后退菜单触发恢复完整初始视图。连续投递期间 `acceptedPreviewObserved=false`，证明发出预览请求，不把尚未进入 GUI 的结果描述为已显示预览。

另行投递 4 次带事件循环的滚轮，最终同样细化至当前请求，并通过一次实际后退恢复初始快照；记录完整事件循环耗时而没有预设这些操作必须合为一组。视图历史依真实事件间隔工作。

辅助图和主图悬停通过 `QTest::mouseMove(QWindow*)` 向原生窗口注入 Qt QPA 事件，记录控件收到的 MouseMove 和主图 cursorChanged 信号。覆盖层与帧计数增长，曲线源缓存、主图功率缓存与热图纹理保持复用。该方式验证 Qt 输入路径，不作为物理鼠标递送或全部 OS 捕获生命周期的证明。

最终 12 个原生场景全部通过：默认布局、持续创建两个重叠标记、树 Ctrl 多选、悬停、PSD、瀑布、色阶条/基带频率、主图最大化/恢复、侧栏收起、空工程和 RAW 元数据对话框。默认波形与 PSD 另有实际颜色像素断言，PNG 已读回检查曲线、色阶、标记、最大化和对话框。对话框截图仅包含该对话框；其 native screen/DPR 与居中范围单独核验。

真实大文件显示、持续新增纹理行、GPU 曲线几何、真实谱矩阵抽取和 Ubuntu 平台仍需后续实现与实测。
