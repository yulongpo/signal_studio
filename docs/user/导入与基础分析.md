# 导入与基础分析

## 1. 新建工程

启动 Signal Studio 后，在项目首页选择“新建项目”。工程文件保存为
`.signal-workspace`，外部录制只以只读资源链接加入工程，不会复制或修改源文件。

## 2. 导入信号

打开“导入信号”后，按界面核对：

1. 选择 RAW/IQ、SC16 或 PCM WAV 文件。
2. 核对标量类型、实数/复数、I/Q 布局和字节序。
3. 输入采样率、中心频率和初始读取上限。
4. 查看文件名提示。文件名中的 `cf`、`sr` 和 `.sc16` 仅是候选提示；必须勾选
   确认后才会采用。
5. 等待有界预览完成，再选择“开始导入”。

导入由后台任务执行。大文件不会一次读入内存，界面只建立配置范围内的可浏览前缀。
进度窗口支持暂停、继续和取消；取消后只保留已经校验到完整样本帧的只读前缀。

## 3. 基础分析

导入完成后，P02 宽带浏览页显示同一代际的：

- 时域波形；
- PSD，单位为 `dB/Hz`；
- STFT/瀑布图。

三图来自实际读取样本和 DSP 计算。频率视口由 PSD 与 STFT 共享，旧视口的后台结果
不能覆盖当前视图。P03 检视器提供时域、频谱、STFT、星座和眼图容器；眼图缺少
符号率或同步来源时会明确显示不适用，不生成默认伪结果。

### 3.1 调整频谱与时频参数

在 P03 Inspector 打开“分析设置”。可以先选择快速预览、平衡分析、高分辨率、低噪声
PSD、突发信号或窄带精细分析，再按需调整 FFT、窗、Periodogram/Welch、平均/保持、
频谱平滑、STFT 帧/重叠和平滑。高级模式还提供补零、Kaiser Beta、Tukey Alpha、
单/双边、归一化和分析前滤波。

派生信息会在应用前显示 bin spacing、RBW、STFT 时间步长、矩阵规模、内存和预计
计算量。非法参数不会启动任务。应用后仍保留上一有效结果；取消或快速连续修改时，
只有最新请求可以更新图表。

参考电平、动态范围、色表、插值和频率轴显示只改变画面，不重新计算 DSP。分析前
滤波只作用于当前分析快照，不创建通道，也不修改源录制。结果中心记录参数 SHA-256、
实际 CPU/CUDA 后端、设备、源范围和任务；更改参数后旧结果显示为过期。

## 4. 结果与导出

分析结果进入 P05 结果中心。每个结果保存工程、数据源版本、Selection、Channel、
算法、参数版本、单位和校验和。切换当前数据源不会改变历史结果来源；上游版本改变后，
旧结果显示为过期。

结果包支持 CSV、JSON、PNG、RAW+JSON、WAV 及插件声明格式。写入使用暂存目录和原子
提交；同一结果 ID 不会静默覆盖，失败或取消不会留下被标记为成功的半成品。导出后可
通过结果中心定位来源或校验完整性。

## 5. 故障恢复

- 文件不可访问、描述符不一致或帧不完整时，导入会返回结构化错误，不修改源文件。
- 缓存损坏时会拒绝损坏内容并重新生成。
- 磁盘或权限错误不会把半成品登记为成功结果。
- 工程保存采用原子替换；重新打开工程后恢复数据源链接、任务历史和结果来源。
- MS-04 旧工程没有分析扩展字段时自动采用有界的平衡分析默认值；未来不兼容的参数
  主版本会明确拒绝，不覆盖上一有效工程。

测试资料未提供 D4 实体文件，因此软件不会把 D4 记为已验证。100 GB 边界使用批准的
X310 录制进行逻辑重复映射和有界访问，不创建物理 100 GB 文件。
