# Signal Studio UI design status

Production Qt Widgets UI is scoped to MS-03 and the branded application to MS-04. MS-00 creates only the reusable Visualization and Workbench binary/package boundaries, with Qt private to their implementation and no placeholder application.

The approved UI specification, chart conventions, color-scale conventions, assets, screenshots, and reviewed prototype are immutable under `docs/baseline/Signal-Studio-Dev-Docs/02_原型设计` and `03_UI规范`. Later UI work must use those sources and produce real Qt Designer/Qt Widgets artifacts; the retained HTML prototype is a reference and is not a runtime dependency.
