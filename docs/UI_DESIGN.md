# Signal Studio UI/UX 设计

## 1. 设计目标

专业、清晰、高信息密度、易于操作；宽窄带分析流程一致；大文件计算状态明确；错误状态可理解。状态：持续演进。关联基线：SS-SRS-BL-1.0。

## 2. 主界面布局

规划为顶部菜单和工具栏、左侧项目树、中央主视图、右侧参数与处理链、底部任务/结果/日志和状态栏。具体控件与尺寸待设计。

## 3. 宽带分析工作区

页面目标是浏览大范围 IQ 数据并发现目标信号。主视图包含时域、频谱或 STFT 图谱，支持缩放、平移、游标、选区、信号区域和窄带通道覆盖层；加载、计算、缓存、错误和取消状态必须可理解。关联需求：`SS-WB-*`、`SS-NFR-001`、`SS-NFR-004`。

## 4. 窄带分析工作区

展示选定通道的精细时域/频谱/STFT、处理链参数、测量和结果。通道来源、时间频率范围和处理状态应可回溯；详细布局待设计。

## 5. 多通道比较

支持多个窄带通道的选择、同步坐标、图表对比和状态区分。比较规则和数量上限待设计。

## 6. RAW IQ 导入对话框

应采集文件、数据类型、IQ/QI、大小端、采样率、中心频率和校验信息，并在确认前显示解析摘要。非法配置必须阻止导入并给出中文原因。

## 7. 窄带通道创建流程

从宽带信号区域进入，确认时间范围、中心频率、带宽、抽取/重采样和命名，再创建通道。创建后的双向定位和处理链状态待验证。

## 8. DSP 处理链面板

以有序节点展示去直流、IQ 校正、DDC、滤波、抽取、重采样及后续分析步骤；参数修改需说明影响并触发可取消任务。节点状态和错误证据待设计。

## 9. 项目保存与恢复

保存数据源引用、区域、通道、处理链、结果引用和布局；恢复时显示缺失文件、插件或模型并支持重新定位或只读降级。关联需求：`SS-PRJ-001` 至 `SS-PRJ-007`。

## 10. 模型管理

提供模型导入、启停、删除、兼容性检查、自检、超时和失败隔离入口；原始推理结果和人工确认结果分开保存。具体页面待设计。

## 11. 任务、日志和诊断

底部区域显示任务队列、进度、取消、失败原因、日志级别和诊断包导出。后台任务不得阻塞主窗口。

## 12. 视觉规范

当前只确定：中文界面；图表需显示单位、坐标和图例；加载、空态、警告、错误和完成状态需有清晰区别；颜色不得成为唯一信息载体。字体层级、间距、主题和完整颜色表待设计。

## 15. M1 HTML5 交互原型

本轮交付位于 [`prototype/m1-interactive/`](../prototype/m1-interactive/)，用于 M1 UI/UX 评审和流程演示，不替代最终 Qt Widgets 实现。原型使用本地系统字体、CSS token 和真实 HTML 控件；时域、频谱和 STFT 使用 Canvas 绘制确定性模拟数据。

已覆盖的六个界面部分：空状态主窗口、RAW IQ 四步导入向导、宽带时域/频谱/STFT 工作区、图谱交互与错误恢复、项目树与属性编辑、任务/日志/动态状态栏。导入流程包含字段级校验、数据预览、低分辨率优先、后台模拟任务、错误重试和恢复。

交互入口包括面板折叠、节点选择与属性同步、属性编辑/应用/重置、任务暂停/继续/取消/重试、日志筛选/搜索/清空、图谱滚轮缩放、框选缩放、平移、游标和时频选区。窄带通道、调制识别、星座图、眼图和多通道比较仅保留 M2/M3 禁用入口。

原型不读取真实 IQ 文件，不执行真实 FFT、STFT、缓存、GPU 渲染或模型推理；正式性能、数值和业务验收仍须在 Qt/C++ 实现阶段执行。视觉验收基准为 1600×900，并已检查 1366×768 与 1280×720。
