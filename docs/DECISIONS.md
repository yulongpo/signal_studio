# Signal Studio 技术决策记录

> 关联需求基线：SS-SRS-BL-1.0。证据不足的条目保持“待验证”。

## DEC-DATA-001 RAW IQ 内部样本类型

- 状态：待验证
- 日期：2026-07-15
- 关联需求：SS-BIZ-007、SS-ACC-005、SS-ACC-006
- 背景：读取核心需要统一内部样本表示。
- 候选方案：`std::complex<float>`、分离的 float I/Q、保持原始类型、模板化样本容器。
- 当前决策：优先评估 `std::complex<float>`，尚未确定。
- 决策原因：有利于统一 DSP 输入，但尚无源码和性能证据。
- 影响：影响数据访问、DSP 和测试数据转换。
- 风险：精度、缩放和分配开销。
- 验证方式：类型转换、数值误差和内存基准。

## DEC-DATA-002 文件访问方式

- 状态：待验证
- 日期：2026-07-15
- 关联需求：SS-BIZ-007、SS-NFR-002、SS-NFR-006

- 影响：影响 `core/data` 和后续异步接入。
- 风险：随机访问性能、平台抽象和资源回收。
- 验证方式：读取吞吐、首帧、边界、取消和内存测试。

## DEC-DATA-004 缓冲区策略

- 状态：待验证
- 日期：2026-07-15
- 关联需求：SS-NFR-006
- 背景：读取结果需要平衡接口简单性和内存控制。
- 候选方案：每次返回 vector、调用方提供缓冲区、Reader 复用内部缓冲区。
- 当前决策：同步核心接口先以可测试性为优先，缓冲区复用待验证。
- 决策原因：尚无调用方和性能数据。
- 影响：影响分配次数、并发安全和后续 UI 接入。
- 风险：不必要复制或内部状态竞争。
- 验证方式：重复随机访问和内存峰值测试。
