# Signal Studio A1.4.3 交互规范

## 本轮范围

原会话：<https://chatgpt.com/share/6ac79e36-1934-83ee-9005-1cb485291880>。本轮同时采用用户补充截图中的最新要求：持续标记开关移入右键菜单；工程树批量选择删除；图中选中标记支持移动、边线和顶点调整。该要求替换 A1.4.2 的悬浮按钮、一次性创建、右键立即取消的规则。

不增加新的工作区域，保留现有工程树、三图谱、右侧参数区和底部结果栏。底部默认收起，色阶条默认隐藏，顶部不恢复 IQ 文件标签行。

## 持续选择与标记编辑

| 操作 | 结果 |
|---|---|
| 主图右键 → 选择信号 | 开启或关闭持续创建模式，菜单显示勾选状态 |
| 创建模式中拖动 | 创建当前文件的标记；完成后继续保持模式 |
| 创建模式中右键 | 取消未完成框选并打开菜单，可从菜单关闭模式 |
| Esc | 取消当前拖动、释放捕获、回滚，并退出创建模式 |
| 普通模式单击图内或树中标记 | 仅选择，不改变可视范围 |
| 双击树中标记 / 定位按钮 | 当前标记范围外加约 20% 留白，受文件边界约束 |
| 选中框内拖动 | 移动该标记，时间与频率跨度保持不变 |
| 选中框边线 / 八个控制点拖动 | 调整对应边界；保持范围有序，限制在文件内 |
| 空白绘图区拖动 | 矩形区域放大 |
| 右键重叠标记列表 | 可选择被其他区域遮盖的标记，视图不变 |

八控制点及边线的命中容差为 6 CSS px。编辑拖动超过 5 CSS px 后开始修改；很小的鼠标抖动仍按单击处理。普通框选的有效宽、高至少为 8 CSS px。

单击选择时不使用悬停状态代替业务选择。多选区域显示选中边框和控制点，活动区域的属性显示在右侧。实际拖动哪个已选区域，就以该区域作为当前属性对象；一次拖动只修改命中的区域。

命中优先处理已选区域的控制点、真实边线和内部；其他标记内部按绘制顺序倒序命中。对可视窗口剪裁后形成的临时边界不显示控制点，也不允许将其作为真实边线调整。

## 批量选择与删除

Ctrl 单击添加或取消单个标记，Shift 单击按当前文件工程树顺序连续选择；Ctrl+Shift 将连续范围加入已有选择。全选、删除及键盘 Delete 只作用于当前 IQ 文件。

删除会清除所选标记，以及引用这些标记的演示窄带通道，并通过提示列明连带移除数量。删除不属于视图后退/前进；本原型没有业务撤销栈。演示通道的中心频率和带宽在创建时确定，之后修改源标记不重新执行提取或 DDC。

重命名支持最多 80 个字符，名称以文本节点显示。删除后若 PSD 统计来源已失去活动标记，则回到当前可见时间窗。

## 坐标方向与鼠标指针

内部始终用 `t0/t1` 秒、`f0/f1` MHz 存储业务范围。

| 图谱 | X | Y | 图内或底部滚轮 | 左侧滚轮 |
|---|---|---|---|---|
| 时频图 | 时间 | 频率向上 | 时间 | 频率 |
| 瀑布图 | 频率 | 时间向下 | 频率 | 时间 |
| 辅助波形 | 时间 | 幅度 | 时间 | 幅度 |
| 辅助 PSD | 频率 | 功率 | 频率 | 功率 |

图谱内不恢复双轴整体滚轮缩放。轴拖动仅平移对应轴，波形时间与主图时间联动，PSD 显示频带与主图频带联动。

## 取消、边界与视图历史

主图、辅助图、全局导航与分隔条采用共同的拖动生命周期。每个手势记录起始文件、pointerId、视图或标记/面板原值。只有对应指针可以更新或提交；迟到的 pointerup 不会提交另一手势。

Esc、pointercancel、lostpointercapture、窗口失焦、隐藏文档，以及文件/模式/窗口尺寸切换会释放鼠标捕获，清理临时框并回滚未完成操作。窗口失焦和 Esc 同时退出持续创建模式。捕获取消只取消当前手势，持续模式仍由其开关控制。

所有时间与频带变化都夹取在当前文件有效范围内。标记边界不交叉，移动不改变宽高。最小可视时间窗由 `2 × hop / Fs` 推导，默认 hop 为 STFT FFT 点数的一半；最小频带为 `Fs / FFT`。默认 2048 点、40 MS/s 对应 51.2 us 与 19.53125 kHz。更换 STFT 点数会更新缩放限制。已存在且小于新分辨率或来自旧工程的标记可保留，调整时不能反向翻转或缩成零。

滚轮按 pixel / line / page 归一化：line 按 16 CSS px、page 按所在画布高度折算，连续增量采用指数倍率。相同文件、画布与轴在 220 ms 内的连续滚轮仅提交一条视图历史；切换轴、文件或开始其他手势时提交该组。每个文件独立保存最多 40 条历史。

坐标显示根据跨度选择 s/ms/us、MHz/kHz/Hz。大绝对坐标的小窗口采用原点加相对偏移，刻度精度依据步长计算，并过滤视觉碰撞；状态与属性显示相应的有效精度。

## 面板与显示更新

导航默认 82 px，允许范围通常为 62–128 px；辅助图默认 205 px，小屏自动压缩。分隔条同时受上下界与中央可用高度限制。主图优先保留预算，在验收的 1366×768 下有效绘图区约 248 px；更小窗口自动缩减辅助区。双击分隔条恢复默认高度，聚焦分隔条时上下方向键每次调整 10 px。

右侧只读属性使用普通值显示；选中标记或切换 PSD 时，将对应属性分组移到前面。其余参数可折叠，手动打开的非当前参数不会因游标刷新反复收起。

模拟功率矩阵与颜色映射分别缓存。标记高亮、游标和选择覆盖层不重新采样功率；更换颜色、动态范围或参考电平复用功率矩阵。视图、方向、文件或采样尺寸变化才更新模拟功率。此规则是 UI 原型实现，不能替代真实 STFT 性能测试。

## 文件独立状态与工程 JSON

每个文件独立保存可视时间/频带、辅助图与主图模式、辅助 Y 范围、标记及多选/活动状态、窄带通道、颜色、动态范围、参考电平、频率坐标、网格、色阶条、PSD FFT/统计来源和 STFT FFT。文件切换清理临时交互，并恢复对应文件参数。

新工程允许真正为空，也可移除最后一个文件。空工程显示添加入口，禁用文件分析操作。工程结构导出使用 `signal-studio-a1.4.3-prototype`；保留旧 A1.4 工程常用字段的导入兼容。导入先完整校验，再替换当前工程；错误输入不破坏原状态。保留标记 id 与通道引用关系，恢复活动文件和多选集合。视图历史不序列化。

工程只包含模拟元数据及 UI 状态，不包含 IQ 样本，也不读取磁盘原始数据。
