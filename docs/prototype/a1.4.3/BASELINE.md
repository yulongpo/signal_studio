# A1.4.3 冻结依据

本目录保存 A1.4.3 的原始 README、交互规范、自包含 HTML 与演示工程 JSON。四份文件均按原样复制，来源、大小及 SHA-256 见 `source_manifest.json`。

原型规定了工程树、三图谱、参数区、底部结果栏、文件独立状态、标记与物理坐标语义。HTML 可用于查看设计，演示 JSON 可用于工程导入互操作检查。新 Qt 工程只引用本仓库内的依据，不读取源原型目录，也不运行其中的脚本。

原始 README 中的回归数量和截图结论属于浏览器原型；该 README 提到的原型 `tests/`、`screenshots/` 与验证记录未纳入本目录。Qt 实现的完成范围与验证结果以新工程 README 和本仓库运行证据为准。
