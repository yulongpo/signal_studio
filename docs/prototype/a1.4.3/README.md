# Signal Studio A1.4.3

本版以 A1.4.2 为基础，完成原会话中的 P0 可靠性修复、P1 一致性优化，以及补充截图要求的持续标记、标记移动与边角调整、工程树批量选择删除。保留全局时间导航、辅助图谱、主图谱的既定布局。

## 使用

直接用 Chrome 或 Edge 打开 `Signal_Studio_A1.4.3_交互可靠性优化原型.html`。HTML 内含全部样式和脚本，运行不依赖其他版本文件夹、网络资源或 Node。

- 主图内右键 →「选择信号（持续模式）」：打开后可连续拖动创建标记，再从右键菜单关闭；Esc 退出。
- 普通模式单击标记选中；选中框内拖动移动，四边和四角拖动调整。
- 工程树单击选中，Ctrl 多选、Shift 连选；双击定位。Delete、右侧「删除所选」或树中的同名按钮批量删除当前文件内的标记。
- 空白绘图区仍可框选放大；滚轮按当前物理 X/Y 轴缩放，坐标轴拖动平移。
- Esc、捕获丢失或窗口失焦会取消未完成拖动并回滚。分隔条双击恢复默认高度。
- 文件菜单可新建空工程、导出和打开工程 JSON。`Signal_Studio_A1.4.3_演示工程.json` 包含重叠标记及两套独立文件参数。

## 验证与交付

状态、数学、事件与缓存回归 **59 项通过，0 项失败**。真实 Chrome 检查了 1920×1080、1366×768、150% DPI 的布局与主要操作；1366×768 下主图有效绘图区约 248 px。详细证据和文件操作验证边界见 `Signal_Studio_A1.4.3_验证记录.md`。

复跑回归：

```powershell
node ".\tests\interaction_regression.cjs"
```

`screenshots/` 保存实际界面截图；`tests/` 保存可复跑的测试及执行记录。交互约定见 `Signal_Studio_A1.4.3_交互规范.md`。

当前交付仍为模拟数据 UI 原型，未接入真实 IQ 读取、FFT、STFT 或 DDC，不能据此判定 Qt/DSP 性能。
