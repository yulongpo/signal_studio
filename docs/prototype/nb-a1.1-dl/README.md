# Signal Studio · 窄带分析 + 深度学习调制识别（NB-A1.1）

基于 NB-A1.0 窄带交互原型增量设计，新增独立的 **深度学习识别** 工作页。对齐 `rebuild/a143-native` 仓库的现有深蓝主题、宽带标记、通道创建和来源定位流程；本交付物不更改 GitHub 仓库源码。

## 查看方法

打开 `Signal_Studio_Narrowband_Prototype_A1.1_DL.html`（Chrome/Edge）；默认进入信号观察页。点击「深度学习识别」 → 调整模型配置/时间范围/窗口及阈值 → 「模拟执行推理」 → 点击彩色时间轴片段查看 Top-5 分数 → 「定位片段」或「查看星座图」。也可在「调制分析」点击「打开深度学习识别」。

## 本次新增

- 模型管理（ResNet18 / CLDNN / Transformer 的**UI 示例配置**），模型输入 shape、期望采样率、模型元数据与文件选择占位。
- 参数校验：帧长、采样率和可选重采样；当前视图/源标记/通道完整时间范围；归一化、重叠率、目标设备与低分拒识阈值。
- 推理任务演示：模拟进度、运行/停止、分类分数 Top-5、低分输出「未知/需复核」、可点击的分段时间轴、与窄带时频/星座图联动、结果过期提示与 synthetic=true JSON 示例导出。
- 窄带工作区右侧参数栏的智能识别概要；不影响原有宽带与窄带交互。

## 真实性边界

**所有图谱、类别分数、预测结果和任务进度都为前端 UI 演示，未加载真实模型权重、未读取 IQ 文件、未执行真实 DDC 或 GPU/CPU 深度学习推理。** 内置模型名字用于原型展示，不提供真实精度或速度主张。真实推理方案见 Markdown 规范第 11 节。

## 评审及测试

浏览器自动回归覆盖：1600×960、1280×800、2560×1440（DPR=1.5）三个视口；创建窄带通道、参数校验、分析模式切换、推理演示、选择片段、模型管理、低分拒识、导出、任务取消与来源定位；浏览器 JavaScript 页面错误数为 0。此结果不代表 Qt 原生 4K 硬件渲染或真实 IQ/模型的性能验证。
