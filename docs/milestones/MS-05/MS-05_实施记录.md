## 1. 交付内容

### 1.1 窄带信道提取（`apps/signal_studio/wideband_narrowband.hpp/cpp`，Qt-free）

- `extract_narrowband_channel`：复信号数字下变频（频移 `e^{-j*2*pi*fc*n/fs}` -> 双路实 FIR 低通截止=bandwidth/2 -> 多相重采样 gcd 约简 L/M）。
- `WidebandNarrowbandController`：宽带选区 -> 信道 spec（center=中点、bandwidth=跨度、output_rate=2*bandwidth），反转/越界校验，`WidebandNarrowbandLink` 联动状态。
- `Application::extract_narrowband` 暴露提取能力。

### 1.2 重采样器增益修复（`src/platform/dsp/resample.cpp`）

MS-05 暴露 MS-02 bug：原 `h[i]=v*L` 未归一化，下采样时幅度被缩放 L/M。修复为设计后归一化 `sum(h)=L`，每 polyphase 分支 DC 增益=1，上/下采样幅度均保持。MS-02 resample 回归全通过。

### 1.3 下变频符号修复

频移符号原为 `phase=-2*pi*fc*n/fs` 配合 `(I+jQ)*(c-j*s)` 实为上变频（移到 2fc）。修复为 `theta=+2*pi*fc*n/fs`，`(I+jQ)*(cos-j*sin)` 正确下变频到基带。
