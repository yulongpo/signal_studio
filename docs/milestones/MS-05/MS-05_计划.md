# MS-05 计划

## 1. 目标

实现宽带浏览、窄带分析与宽窄带联动：宽带选区驱动窄带信道提取（数字下变频：频移+低通滤波+重采样），参数继承，多图共享视口与游标，请求优先级与取消。

## 2. 批准范围

覆盖任务文档 §9.4 宽带分析/窄带分析/宽窄带联动与 §7.3 联动要点（宽带选区->窄带处理、参数继承、视图联动）。

## 3. 实施切片

1. **窄带信道提取**（`wideband_narrowband.hpp/cpp`，Qt-free）：`extract_narrowband_channel`--复信号频移（下变频 `e^{-j*2*pi*fc*n/fs}`）、双路实 FIR 低通（截止=bandwidth/2）、多相重采样（gcd 约简 L/M）。
2. **联动控制器**：`WidebandNarrowbandController`--宽带选区 -> 信道 spec（center=中点、bandwidth=跨度、output_rate=2*bandwidth），越界/反转校验，`WidebandNarrowbandLink` 联动状态。
3. **Application 集成**：`Application::extract_narrowband` 暴露窄带提取。
4. **测试**：联动 spec 派生、反转/越界拒绝、窄带提取包络稳定性（解析单音下变频到基带）。

## 4. 验证门禁

- 四配置全量 CTest；
- 宽窄带用例（link + extraction）在 UI 配置运行；
- 重采样器增益修复回归（MS-02 resample-sine-amplitude 仍通过）；
- 依赖 DAG 不变；应用仅链接公共库；
- `clang-format`/`clang-tidy`/高警告级别通过；完成提交后工作树干净。

## 5. 边界
