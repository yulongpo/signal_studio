## 3. 重采样器增益修复回归

MS-05 暴露 MS-02 `PolyphaseResampler` 增益归一化 bug：原 `h[i]=v*L` 未归一化，下采样（L<M）时单分支 DC 增益=sum(window)/M≠1，幅度被缩放 L/M。修复为设计后归一化 `sum(h)=L`（每 polyphase 分支 DC 增益=1），上/下采样幅度均保持。MS-02 的 4 个 resample 用例回归全通过。

## 4. 算法正确性

- 下变频：`(I+jQ)*e^{-j*2*pi*fc*n/fs}` 将 fc 移到基带。解析单音 1kHz@64kHz 经 fc=1kHz 下变频后应得 DC，提取后包络恒定（mag_var/mean²<0.5）。
- 低通滤波：FIR 窗 sinc，截止=bandwidth/2，DC 增益=1。
- 重采样：gcd 约简 L/M（64000:400=160:1），polyphase 16 taps/phase，DC 增益=1。
