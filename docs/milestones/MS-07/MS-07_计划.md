# MS-07 计划

## 1. 目标

工程化收口：clang-format 格式合规、CPack 便携包/安装器、Qt 运行库部署、CI 完善、需求追踪矩阵、构建/调试/架构/API 文档、稳定性与性能基线入口。

## 2. 批准范围

覆盖任务文档 §12（代码质量）、§13（CI/CD）、§14（安装和发布）、§15（需求追踪）。

## 3. 实施切片

1. **质量门禁**：`scripts/run_quality_gates.ps1`（clang-format --dry-run --Werror 检查/格式化，编译 /W4 /permissive- 由 `signal_studio_enable_warnings` 强制，依赖 DAG 由 `signal_studio_verify_dependency_graph` 强制）。
2. **打包**：`cmake/Packaging.cmake`（CPack ZIP 便携包 + NSIS 若可用）、`apps/signal_studio/CMakeLists.txt` windeployqt POST_BUILD 部署 Qt DLL/插件、VC143 运行库由 `signal_studio_deploy_msvc_runtime` 部署。
3. **需求追踪**：`docs/development/开发需求追踪矩阵.csv`（198 项，FR-PRJ/DAT/IDX/TSK/CORE/DATA/DSP/CMP/VIS/WB/UI/PLG/MODEL/DSET + NFR，按里程碑映射）。
4. **文档**：`docs/development/VSCode构建与调试指南.md`、`docs/development/第三方依赖版本锁定清单.md`、`docs/release/发布检查清单.md`、`docs/release/安装验证报告.md`。
5. **CI**：现有 `.github/workflows/ci.yml`（Windows 2022 无界面 + Qt/UI）保留。

## 4. 验证门禁

- 四配置全量 CTest 通过；
- clang-format --dry-run --Werror 全部合规；
- CPack 便携包生成并可启动（self-test 退出 0）；
- 需求追踪矩阵覆盖 198 项；
- 完成提交后工作树干净。

## 5. 边界

- NSIS 未装：安装器为环境偏差，便携包（ZIP）可用。
- 像素级视觉回归/DPI 矩阵留待真实 GUI 测试。
- CUDA 不自动安装。
