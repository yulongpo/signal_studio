## 5. 环境偏差（诚实记录）

- **ONNX Runtime 未装**：`make_inference_session` 返回 `NullInferenceSession`，`available()=false`，`run()` 返回 `unavailable` 错误，不伪造输出。BL1.0 默认后端为 ONNX Runtime，装好后经 `IInferenceSession` 接口接入，无需改公共 API。
- **HDF5 未装**：Dataset 用 JSON 清单实现（真实可用，round-trip 验证）。HDF5 为 BL1.0 参考格式，装好后经 `IDataset`/`IDatasetWriter` 接口接入。
- vcpkg manifest 模式会源码编译 Qt（与系统 Qt 6.11.1 冲突），故未启用。

## 6. 质量门禁

`/W4 /permissive-` 通过，无新增警告。公共头无第三方类型；依赖 DAG 不变（PluginSDK 不依赖 DSP，RMS 内联计算）。ABI 异常边界 `abi_v1::invoke_result`/`invoke_void` 隔离插件崩溃。
