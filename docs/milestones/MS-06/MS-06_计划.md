# MS-06 计划

## 1. 目标

实现 SignalPluginSDK（ABI-v1 运行时加载/隔离、算法插件接口、示例）、SignalModelRuntime（模型注册与推理接口，ONNX Runtime 为环境偏差）、SignalDataset（版本化样本索引与原子提交）。

## 2. 批准范围

覆盖 `API-PLG-001`~`003`、`API-MODEL-001`~`002`、`API-DSET-001`~`002` 与任务文档 §9.7（插件和模型）。

## 3. 实施切片

1. **PluginSDK**：`PluginHost`（Windows LoadLibrary 加载 .dll，查询 `signal_plugin_query_v1`，校验，activate/unload，异常边界隔离）、`PluginHandle`（RAII）、`IAlgorithmPlugin` C++ 接口 + `RmsAlgorithmPlugin` 内置参考实现。
2. **ModelRuntime**：`IModelRegistry`/`ModelRegistry`（install/resolve/list）、`IInferenceSession` + `NullInferenceSession`（ONNX 未装时诚实返回 unavailable，不伪造输出）、`make_inference_session`。
3. **Dataset**：`IDataset`/`IDatasetWriter` + `JsonFileDataset`（JSON 清单，真实可用，append/query/commit round-trip；HDF5 为环境偏差）。
4. **测试**：算法插件 RMS、坏操作拒绝、PluginHost 加载 minimal_plugin、模型注册/解析、null 会话不可用、数据集 append/query/commit/roundtrip。

## 4. 验证门禁

- 四配置全量 CTest；
- PluginSDK/ModelRuntime/Dataset 测试在所有配置运行（无 Qt 依赖）；
- 公共头无第三方类型；依赖 DAG 不变（PluginSDK 不依赖 DSP，RMS 内联计算）；
- ONNX Runtime/HDF5 未装为环境偏差，接口就绪不伪造；
- `clang-format`/`clang-tidy`/高警告级别通过；完成提交后工作树干净。

## 5. 边界

- ONNX Runtime 未装：推理接口返回 unavailable，不伪造结果。
- HDF5 未装：Dataset 用 JSON 清单实现，HDF5 适配器接口保留后续替换。
- CUDA 不自动安装。
