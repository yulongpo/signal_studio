# MS-06 实施记录

日期：2026-07-23
里程碑：MS-06 PluginSDK、ModelRuntime、Dataset 功能

## 1. 交付内容

### 1.1 PluginSDK（`include/signal_studio/plugin_sdk/`、`src/platform/plugin_sdk/`）

- `plugin_host.hpp/cpp`：`PluginHost`（Windows LoadLibraryW 加载 .dll，GetProcAddress 查 `signal_plugin_query_v1`，调用 + ABI 校验 + `api.load` 获取插件句柄）、`PluginHandle`（RAII，activate/unload，异常边界 `abi_v1::invoke_result`/`invoke_void` 隔离）、`PluginInfo`、`discover` 目录扫描。
- `algorithm_plugin.hpp/cpp`：`IAlgorithmPlugin` C++ 接口（API-PLG-002）、`AlgorithmRequest`/`Result`、`RmsAlgorithmPlugin` 内置参考实现（RMS 内联计算，不依赖 DSP 以保 DAG）。

### 1.2 ModelRuntime（`include/signal_studio/model_runtime/model_runtime.hpp`、`src/platform/model_runtime/model_runtime.cpp`）

- `IModelRegistry`/`ModelRegistry`（install/重复拒绝/resolve/list）、`IInferenceSession` + `NullInferenceSession`（ONNX 未装时 `available()=false`、`run()` 返回 `unavailable`，不伪造）、`make_inference_session`、`ModelInfo`/`InferenceRequest`/`InferenceResult`。

### 1.3 Dataset（`include/signal_studio/dataset/dataset.hpp`、`src/platform/dataset/dataset.cpp`）

- `IDataset`/`IDatasetWriter` + `JsonFileDataset`（JSON 清单，手写序列化/解析与 data 模块 sidecar 一致无第三方依赖，append/query(label/format/limit)/commit，round-trip 持久化）。HDF5 为环境偏差。

## 3. 架构与依赖变化

依赖 DAG 不变。PluginSDK 仅依赖 Data+TaskRuntime+Core（RMS 内联，不依赖 DSP）。ModelRuntime 依赖 Data+Compute+TaskRuntime+Core。Dataset 依赖 Data+TaskRuntime+Core。公共头无第三方类型。无新增第三方依赖。

```bash
cmake --preset local-windows-msvc-headless-debug && cmake --build --preset local-windows-msvc-headless-debug

```

## 5. 已知问题与边界

- ONNX Runtime 未装：推理接口返回 unavailable，不伪造。
- HDF5 未装：Dataset 用 JSON 清单，HDF5 接口保留后续替换。
- CUDA 不自动安装。
