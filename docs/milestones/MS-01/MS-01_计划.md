# MS-01 计划

## 1. 目标

在 MS-00 已验收的平台骨架上实现可独立安装和消费的 SignalCore、SignalData 与 SignalTaskRuntime 生产契约，形成工程持久化、真实 IQ 数据访问、多分辨率索引缓存和统一后台任务运行时。里程碑不实现 Qt 页面、完整 DSP 算法库或应用品牌逻辑。

## 2. 批准范围

本里程碑覆盖 54 项需求：

- 工程与当前上下文：`FR-PRJ-001`～`FR-PRJ-010`；
- 数据导入与读取：`FR-DAT-001`～`FR-DAT-019`；
- 索引与缓存：`FR-IDX-001`～`FR-IDX-012`；
- 任务运行时：`FR-TSK-001`～`FR-TSK-010`；
- 平台能力：`FR-CORE-101`、`FR-DATA-101`、`FR-TASK-101`。

对应稳定公共接口为 `IWorkspaceStore::load/save`、`IDataSource::read(ReadRequest)`、`IMultiResolutionStore::get/put` 和 `ITaskService::submit(TaskSpec)`。

## 3. 实施切片

1. SignalCore：统一 `Result`、单位、日志、配置、路径、SHA-256、源版本指纹、原子文件、Workspace 全图、自动保存、最近工程和原子当前上下文。
2. SignalData：实数/复数容器与零拷贝切片、全部批准 RAW 标量与布局、WAV、侧车、格式适配、分块/映射读取、有界预览、部分读取、选区导出闭环。
3. 索引缓存：时域 min/max/RMS 金字塔、真实频谱概要/STFT 瓦片、多分辨率键、内存/磁盘 LRU、锁定、损坏恢复、诊断和可取消预取。
4. SignalTaskRuntime：有界资源池、优先级、DAG、暂停/恢复/取消、进度、超时、重试、幂等、视图过期、结构化失败、来源过滤、历史和制品崩溃恢复。
5. 集成：数据模块保持只依赖 Core；耗时数据读取由 TaskRuntime 的唯一任务状态源驱动，后台任务不引入 Qt，也不触碰 `QWidget`。

## 4. 验证门禁

- Windows MSVC 2022 x64 的 UI/无界面 Debug 与 Release 均完成全新配置、编译和全量 CTest；
- CPU 预设通过；按批准策略不执行 Ubuntu 24.04 无界面构建；
- 外部 WAV 与 SC16 仅以有界窗口读取，外部大文件不写入仓库；
- UI 与无 Qt 安装树消费者均编译、链接并调用 MS-01 公共 API；
- 公共头无 Qt/第三方类型，依赖 DAG 不变；
- `clang-format`、`clang-tidy` 和高警告级别检查通过；
- 独立规格复审与代码质量复审无剩余阻断项；
- 文档基线、外部测试数据与原始参考材料保持不变；
- 完成里程碑提交后工作树干净，并由 Windows GitHub Actions 验证。

## 5. 明确边界

- CUDA 不自动安装；GPU 数值实现属于后续 SignalCompute/SignalDSP 里程碑。
- MAT、NPY/NPZ 和厂商格式通过标准描述符适配接口接入，本里程碑不伪造未安装第三方解析器。
- 预览频谱明确标识为限定长度结果；不得冒充全文件 PSD。
- Signal Studio Qt 应用与 Designer 页面从 MS-03/MS-04 开始实现，本里程碑不提前声明 UI 完成。
