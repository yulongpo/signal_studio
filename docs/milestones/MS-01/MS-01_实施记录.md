# MS-01 实施记录

## 1. 实施范围

本里程碑实现 Core、Data 与 TaskRuntime 三个无界面生产模块，共覆盖 54 项批准需求。实现保持既有十模块依赖 DAG，不引入 Qt 公共类型，不实现 MS-02 的完整 DSP/Compute 后端，也不提前实现 MS-03 的 Qt 原型界面。

## 2. Core

- 新增统一的 `Result<T>` 成功/失败返回；
- 实现路径、原子文件、SHA-256、源版本指纹、配置和结构化日志服务；
- 实现完整 Workspace 图加载/保存、自动保存、最近工程和原子当前上下文；
- 对所有外部枚举和持久化字段执行显式合法性校验。

公共接口位于 `include/signal_studio/core/`，生产实现位于 `src/platform/core/`，具名需求测试位于 `tests/core/`。

## 3. Data

- 新增实数/复数容器、不可变切片和有界读取请求；
- 支持批准的 RAW 标量、端序、交织/平面布局和侧车描述符；
- 实现 WAV 解析，并验证格式块、通道、位深、块对齐、字节率、数据范围和算术溢出；
- 实现分块/映射读取、有界预览、取消后的完整帧前缀发布和选区导出闭环；
- 实现时域 min/max/RMS 金字塔、频谱概要、STFT 瓦片和多分辨率键；
- 实现内存/磁盘有界 LRU、锁、原子写入、损坏恢复、诊断和可取消预取。

取消与损坏严格区分：调用方取消且已经读出完整帧时可以发布不可变前缀；零完整帧不发布；截断或描述符矛盾始终失败。

## 4. TaskRuntime

- 实现有界 CPU/线程预算、优先级队列和依赖 DAG；
- 实现暂停、恢复、取消、超时、进度、重试、幂等和视图过期；
- 实现结构化失败、按来源过滤的日志、历史和制品恢复；
- 统一拒绝零 CPU 单元或零运行时线程；
- 崩溃恢复重试按 `task_type` 使用当前注册处理器，并创建新的 TaskId 与 attempt；
- 缺少恢复处理器时返回明确错误，不伪造闭包或成功结果。

TaskRuntime 是任务状态、进度、重试和日志的唯一来源。Data 仅维护数据范围及其可用性，后台代码不依赖 Qt。

## 5. 构建、安装与开发工程

- 将 MS-01 源码、测试和安装导出接入现有 CMake 目标；
- 保持 UI 与无 Qt 包的组件隔离；
- 向 MSVC 公共 C++ 消费接口传播 `/utf-8`；
- Debug nonredist 运行库只部署到本地测试目标和消费者测试目录，正式 Debug 安装树明确拒绝这些 DLL；Release 安装树部署匹配的可再分发 MSVC 运行库；
- UI 安装消费者使用 Qt 6.11.1 运行环境，无 Qt 消费者不发现 Qt；
- 修正 `CMakeUserPresets.json` 生成器，公共路径环境只生成一次且所有路径项去重；
- GitHub Actions 自 MS-01 起只保留 Windows 无界面和 Windows Qt/UI 门禁。

## 6. 规格整改

独立规格复审发现并完成四项整改：

1. 修正取消导入的部分范围语义；
2. 修正崩溃恢复任务的真实处理器绑定；
3. 增加 WAV `blockAlign` 和 `byteRate` 一致性校验；
4. 拒绝零 CPU 单元或零运行时线程绕过预算。

相应生产代码和负向测试同步更新，Debug/Release 的 Data 与 TaskRuntime 43 项集合均通过。

独立代码质量复审随后发现并完成七项整改：

1. 统一 `view → tasks` 锁序，消除重试读取视图代际的数据竞争；
2. 把大文件检查、同步和摘要移出视图锁，只保护最终原子提交；
3. 使新视图在准备阶段及时生效，并阻止其越过最终 rename/登记临界区；
4. 以可重入有序队列串行交付 journal 与观察者事件；
5. 以 SSTJ3 保存 dependencies/timeout，同时兼容 SSTJ2；
6. 完整校验 WAV 采样率、byteRate、blockAlign 和 RIFF 边界；
7. 隔离 Debug nonredist 测试运行时与正式安装内容。

最终独立质量复审确认无剩余 Critical 或 Important。
