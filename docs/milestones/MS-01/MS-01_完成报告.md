## 1. 目标

在 MS-00 平台骨架上交付 SignalCore、SignalData、SignalTaskRuntime 生产契约，覆盖 54 项批准需求，形成工程持久化、真实 IQ 数据访问、多分辨率索引缓存与统一后台任务运行时。

## 2. 完成功能

- **SignalCore**：统一 `Result<T>`/`Result<void>` 类型化结果与 `Status` 错误模型；核心服务入口与能力注册。
- **SignalData**：实/复数容器与零拷贝切片；全部批准 RAW 标量与布局（int8~float64、交叠/平面、IQ/QI、大小端、字节偏移、缩放）；WAV 头解析与文件名参数提示；分块/有界读取；有界预览（限定长度结果）；选区导出闭环；多分辨率索引缓存（键、LRU、锁定、损坏恢复、诊断）；标准描述符适配接口。
- **SignalTaskRuntime**：有界资源池、优先级、DAG 依赖、暂停/恢复/取消、进度、超时、重试、幂等、视图过期、结构化失败、来源过滤、历史与制品崩溃恢复、观察者。
- **集成**：UI 与无 Qt 消费者均调用 MS-01 公共 API；依赖 DAG 不变；公共头无 Qt/第三方类型。

## 3. 修改文件

新增 8 个公共头、8 个实现源、3 个测试目录（core/data/task_runtime，含 CMakeLists 与用例）、平台消费者扩展、`.clang-format`/`.clang-tidy`、MS-01 计划文档。收口新增 3 份证据文档与 `scripts/common.ps1` 构建修复。完整清单见 `MS-01_实施记录.md` 第 3 节。

## 4. 架构变化

十模块依赖 DAG 不变（Core->∅、Compute->Core、Data->Core、TaskRuntime->Compute+Core、DSP->Data+Compute+Core，校验器强制精确匹配）。Core/Data/TaskRuntime 从 MS-00 骨架升级为生产实现；DSP/Compute/Visualization/Workbench/PluginSDK/ModelRuntime/Dataset 仍为骨架，留待后续里程碑。Qt 仍私有于 Visualization/Workbench。

## 5. 依赖变化

无新增第三方依赖。oneMKL/Eigen/FFTW/cuFFT 仍为 MS-02 候选。vcpkg manifest 保持 MS-00 声明，但本里程碑构建未引入第三方库（纯 C++20 标准库实现）。
