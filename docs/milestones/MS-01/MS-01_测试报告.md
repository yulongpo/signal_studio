## 4. 重点边界验证

- 取消前零完整帧：不发布范围；
- 取消前存在完整帧：只发布请求起点至最后完整帧，Data 状态为部分可用，Task 状态为取消；
- 截断、描述符不一致、WAV 块对齐或字节率错误：解析失败；
- 零 CPU 单元或零运行时线程：提交、历史追加和恢复均拒绝；
- 恢复任务缺少处理器：重试失败；注册处理器后以新 TaskId、新 attempt 真实执行；
- 非有限或回退进度、未知枚举、非法缓存形状、损坏缓存：均按契约拒绝或恢复。
