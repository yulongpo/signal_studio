## Compute

- 生产 `IComputeBackend` 实例返回 CPU 标量、SIMD、多线程和 CUDA 实机能力。
- CUDA 能力包含运行时版本、设备名称、设备内存和编译/可用状态；探测、cuFFT 计划和分配器均绑定实际设备并在结束后恢复调用线程原设备。
- `ComputeRuntime` 通过第三方无关的操作契约实际承载 FFT、滤波和重采样执行，完成规模感知选择、强制 CUDA 拒绝静默降级、自动模式显式降级和 provenance。只有由独立参考结果计算的最大绝对误差/均方根误差才能标记一致性已验证；没有独立参考的固定零指标明确记录为“未验证”。
- 默认保留至少一个逻辑核；预算池统一管理 host、pinned host 和 device。
- 选择和降级均检查后端 Working Set 容量；租约创建具备异常安全回滚，CUDA 分配校验实际地址对齐。

## DSP

- DFTI 复数正逆 FFT 及线程安全计划缓存。
- VSL 复数 FIR 卷积。
- LAPACKE `ztbtrs` 带状下三角 IIR，包含稳定性、有限值和尺寸校验。
- libsamplerate `SRC_SINC_BEST_QUALITY` 两通道复数 IQ 有理重采样，显式 `end_of_input` 冲刷成熟内核延迟。
- Hilbert 解析信号、去直流、增益、IQ 校正、频移和 FIR/IIR。
- FIR/IIR/重采样状态跨块延续；`processed_samples` 按原始输入计数。
- cuFFT 端到端实机执行和计划缓存；CUDA/cuFFT 版本由运行时查询。
- 节点预览、频响、群时延、不可变处理链快照、取消、下游失效、完整模板和位精确旁路导出。
- 旁路在不适用的输入契约校验前直接返回位一致样本；节点的 `produces_complex` 描述真实输出类型。
- 简单节点循环每 4,096 样本检查取消，第三方内核返回后及最终发布前再次检查；PSD/频谱拒绝错误 bin 数和非有限输出，频率映射拒绝非有限采样率及不能精确映射的超大 FFT 长度。

## 测试资产

- `tests/compute/`：11 项性能需求、`FR-COMPUTE-101`、Qt 实际 `paintEvent` 专项，以及清空三项 Qt 插件环境变量后的默认 Windows 平台启动回归。
- `tests/dsp/`：12 项 DSP、5 项数值和 `FR-DSP-101`。
- `tests/integration/ms02/`：批准 WAV/SC16 的 Data→DSP→Cache。
- 用户指定 `x310_capture_cf1425MHz_sr50MSps_20260521_144220.sc16` 为 4,004,031,888 字节，SHA-256 为 `74d0ace877568a1c26505c773f249a02e411546254e67c63c4613bb508f2d605`。配置期实际计算并核对大小/哈希；浏览路径使用完整描述符摘要、文件大小/修改时间/采样哈希组成源身份；十进制 100 GB 只由逻辑重复映射表示，没有创建物理 100 GB 文件。测试覆盖物理文件尾重复拼接、逻辑最后一帧、精确 EOF、显式读取上限，以及 8 GB/100 GB 逻辑空间各 48 个远距离三图视窗的 Windows `PeakWorkingSetSize`，从而覆盖同步构建内部临时缓冲峰值。
- `build_full_sc16_index()` 是产品 Data API，以 64 MiB 有界块完整扫描上述文件；测试不再使用测试内自建索引替代产品实现。
- `benchmarks/`：Google Benchmark 的 FFT、STFT、重采样、真实 X310 全文件索引和 GPU 矩阵；同盘顺序读取只抽样每块首尾字节，不以全字节 CPU 校验降低基线；`SkipWithError` 会使进程返回非零，单 GPU 环境的多设备切换使用明确环境跳过。
- `scripts/verify-ms02-runtime-closure.ps1`：分别验证纯 CPU 与强制 CUDA 的显式闭包和洁净 PATH 运行。
- UI 与无 Qt 包消费者在 CPU Debug、CPU Release 和 CUDA Release 路径均实际配置、构建、安装、链接和运行；无 Qt 嵌套构建显式继承 MSVC、Windows SDK、`VCToolsRedistDir` 与 UCRT 环境，避免普通 CTest 子进程丢失开发环境。
