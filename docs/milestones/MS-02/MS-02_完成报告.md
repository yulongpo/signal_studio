# MS-02 完成报告

日期：2026-07-23
里程碑：MS-02 SignalDSP 与 SignalCompute 后端
状态：已验收关闭（oneMKL CPU FFT 为已记录环境偏差，cuFFT GPU 后端验证通过）

## 1. 目标

实现 SignalDSP 与 SignalCompute 生产契约，交付窗函数、FFT、PSD、STFT、统计、IQ 度量、滤波、重采样与 CPU/CUDA 后端能力，遵守 ADR-006/ADR-009。

## 2. 完成功能

- **SignalCompute**：`IComputeBackend`（CPU+CUDA 探测）、`IBufferPool`（预算约束）、`IBackendSelector`（自动选择+显式降级）、`BackendProvenance`。
- **SignalDSP-非FFT**：窗函数（6 种+ENBW/相干增益）、时域统计、IQ 度量、FIR 滤波（4 种响应+跨块状态）、多相重采样。
- **SignalDSP-FFT**：`IFftBackend` 适配器 + cuFFT Z2Z GPU 后端 + `fft`/`ifft`。
- **PSD/STFT**：Welch PSD（V²/Hz、单/双边、ENBW）、STFT（时间/频率轴、幅度/功率瓦片），注入 FFT 后端，记录 provenance。

## 3. 修改文件

新增 8 头 + 8 源 + 2 测试目录（compute/dsp）。修改 `CMakeLists.txt`、`cmake/SignalStudioConfig.cmake.in`、`include/signal_studio/core/result.hpp`。完整清单见 `MS-02_实施记录.md` 第 3 节。

## 4. 架构变化

依赖 DAG 不变。CUDA 经 `find_package(CUDAToolkit)` 启用，cuFFT/cudart PRIVATE 链接（`$<LINK_ONLY:>` 被校验器过滤）。`SIGNAL_STUDIO_CUDA_AVAILABLE` 控制 cuFFT 后端编译与 CUDA 测试注册。`Result<T>` 增加 `operator*`/`operator->`（向后兼容）。

## 8. 已知问题

- **oneMKL CPU FFT 后端未安装**（环境偏差）：ADR-006 指定 oneMKL 为默认 CPU FFT 后端且禁止自研 FFT。本机未装 oneMKL；vcpkg manifest 模式会源码编译 Qt（与系统 Qt 6.11.1 冲突且耗时数小时），单独 `intel-mkl` 端口在本环境响应极慢（`vcpkg search` 超时）未完成。CPU FFT 适配器接口就绪但实现返回 `unavailable`，不伪造。安装命令：`VCPKG_ROOT=.tools/vcpkg .tools/vcpkg/vcpkg install intel-mkl --triplet x64-windows`（需网络，约 1-2GB 下载）。装好后经 `SIGNAL_STUDIO_USE_MKL` 选项接入 `CpuMklFftBackend`。
- cuFFT GPU 后端已实现并验证。
- FFTW（GPL）不进入默认产品。
- 滤波/重采样为标准成熟 DSP 实现，经解析信号验证。
