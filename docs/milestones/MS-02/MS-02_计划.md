# MS-02 计划

## 目标

在不改变 BL1.0 公共模块 DAG 的前提下，完成可复用 Compute 与 DSP 平台：生产后端探测/选择/降级、预算内存、oneMKL CPU 数值适配器、libsamplerate 成熟重采样适配器、可选 CUDA/cuFFT、处理链、Google Benchmark 性能基准、安装消费和外部数据证据。

## 范围

- `FR-DSP-001`～`FR-DSP-012`
- `NFR-NUM-001`～`NFR-NUM-005`
- `NFR-PERF-001`～`NFR-PERF-011`
- `FR-DSP-101`
- `FR-COMPUTE-101`

## 执行顺序

1. 核验已批准基线、外部测试数据和本机 Qt/CUDA/MSVC。
2. 用锁定 vcpkg baseline 最小安装 oneMKL、libsamplerate 和 Google Benchmark，验证脚本幂等与环境恢复。
3. 实现第三方无泄漏的 Compute/DSP 公共契约和私有适配器。
4. 实现处理链、状态、预览、模板、provenance、取消和下游失效。
5. 增加 30 项需求测试、用户指定 X310 录制数据集成测试及独立 Google Benchmark 性能基准；大文件验收使用真实录制文件的逻辑重复映射模拟 100 GB（100,000,000,000 字节），不创建物理 100 GB 文件。
6. 执行 Debug/Release、CPU/CUDA、安装消费者和洁净 PATH 闭包验证。
7. 更新中文核心文档，审计差异，由主代理创建里程碑提交。

## 非目标

- 不实现 Qt 原型界面；原型界面属于 MS-03。
- 不引入 cuDNN、FFTW、自研 FFT 或 MATLAB 运行依赖。
- 不执行 Ubuntu 24.04 无界面构建测试。
- 不修改不可变基线、`../test_data` 或 `references_rep/`。
