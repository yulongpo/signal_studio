# MS-02 计划

## 1. 目标

在 MS-01 的 Core/Data/TaskRuntime 之上实现 SignalDSP 与 SignalCompute 生产契约，交付窗函数、FFT、PSD（dB/Hz）、STFT、时域统计、IQ 度量、信道滤波、重采样、CPU 确定性调度、后端能力注册与可选 cuFFT GPU 后端。里程碑不实现 Qt 可视化页面或应用品牌逻辑。

## 2. 批准范围

覆盖 BL1.0 接口契约 `API-COMPUTE-001`~`003` 与 `API-DSP-001`~`005`，以及 ADR-006（FFT/矩阵后端适配：oneMKL 默认 CPU、cuFFT 可选、FFTW 仅许可兼容、Eigen 不出公共 API、自研 FFT 禁止）与 ADR-009（计算后端自动选择与显式降级：CPU/SIMD/CUDA 经 SignalCompute，provenance 记录实际后端）。

## 3. 实施切片

1. **SignalCompute**：`IComputeBackend::capabilities()`（CPU/SIMD/CUDA 探测）、`IBufferPool::acquire(BufferSpec)`（受预算约束的主机/设备内存）、`IBackendSelector::select(Workload)`（Auto 选择与可审计降级）。CPU 后端始终可用；CUDA 后端经 `cudaGetDeviceCount`/`cudaGetDeviceProperties` 探测，不可用时构造失败。
2. **SignalDSP-非FFT**：窗函数（rectangular/hann/hamming/blackman/blackman-harris/flattop，对称/周期、相干增益、ENBW）、时域统计（mean/variance/rms/peak/min/max/dc）、IQ 度量（幅度 mean/rms/peak、相位均值、DC）、FIR 滤波（窗 sinc 法，低通/高通/带通/带阻，跨块状态）、多相重采样（抗混叠窗 sinc 低通，L/M 有理比）。
3. **SignalDSP-FFT**：`IFftBackend::create_plan(FftSpec)` 抽象适配器；cuFFT Z2Z 双精度 GPU 后端（私有链接 `CUDA::cufft`，设备缓冲分配/拷贝/同步）；`make_fft_backend(device)` 工厂；`fft`/`ifft` 便捷函数（逆变换 1/N 缩放）。
4. **PSD/STFT**：`IPsdEstimator::process`（Welch 法，窗+ENBW+密度/谱缩放+单/双边+V²/Hz）、`IStftProcessor::process`（分帧 STFT，时间/频率轴，幅度/功率瓦片）。均注入 `IFftBackend`，结果记录后端 provenance。
5. **缓存键**：所有数值参数、后端与来源 provenance 记录于结果，供后续多分辨率缓存键使用。

## 4. 验证门禁

- 无界面 Debug/Release（CPU，CUDA OFF）与 UI Debug/Release（CUDA AUTO→ON）四个配置全新配置、编译与全量 CTest；
- CPU 测试（窗函数/统计/滤波/重采样/计算后端/选择器）在所有配置运行；
- CUDA 测试（cuFFT 后端探测、FFT 单音 bin、Parseval、IFFT 往返、PSD 频率、STFT 时频）仅在 CUDA 构建中注册并运行；
- 公共头无 Qt/第三方类型；依赖 DAG 不变；cuFFT/cudart 私有链接（`$<LINK_ONLY:>` 被校验器过滤）；
- 安装包消费者在 CUDA 构建中经 `find_dependency(CUDAToolkit)` 解析 `CUDA::` 目标；
- `clang-format`/`clang-tidy`/高警告级别通过；
- 文档基线、外部测试数据与原始参考材料保持不变；
- 完成里程碑提交后工作树干净。

## 5. 明确边界与环境偏差

- **oneMKL CPU FFT 后端**：ADR-006 指定 oneMKL 为默认 CPU FFT 后端，且禁止自研 FFT。本机未安装 oneMKL；vcpkg manifest 模式会从源码编译 Qt（与系统 Qt 6.11.1 冲突），单独 `intel-mkl` 端口在本环境响应极慢且未完成。故 CPU FFT 适配器接口就绪但实现标记为不可用（返回 `unavailable` 状态），不伪造结果。oneMKL 安装脚本与偏差记录见完成报告。
- **cuFFT GPU FFT 后端**：CUDA 12.4 可用，cuFFT Z2Z 后端已实现并通过解析信号验证（单音 bin、Parseval、IFFT 往返、PSD、STFT）。
- **FFTW**：GPL，按 ADR-006/验证方案不进入默认产品。
- **滤波/重采样**：FIR 窗 sinc 与多相重采样为标准成熟 DSP 实现（非 FFT/矩阵），黄金值来自解析信号。
- CUDA 不自动安装；GPU 数值仅经 cuFFT 适配器。
