## 3. 算法正确性依据

按 BL1.0《算法正确性验证方案》：黄金值来自解析信号（单音正弦/余弦、单位圆复信号），不依赖自写 FFT 参考。FFT 频率/幅值经整数 bin 单音验证；Parseval 经能量守恒验证；PSD 单位 V²/Hz 经峰值频率与 dB/Hz 有限性验证；STFT 经时间/频率轴验证。CPU/GPU 一致性经 cuFFT 直接验证（CUDA 构建注册运行）。MATLAB 参考留待后续真实数据对照（MS-04/MS-05 接入外部 WAV/SC16）。

## 4. 环境偏差

- oneMKL CPU FFT 后端未安装：CPU FFT 适配器返回 `unavailable`，CPU 构建不注册 FFT/PSD/STFT 用例（不伪造跳过为通过）。cuFFT GPU 后端经 CUDA 12.4 验证。
- 滤波/重采样为标准成熟 DSP 实现（非 FFT/矩阵），经解析信号验证。
- FFTW（GPL）不进入默认产品。
