# MS-08 计划

## 1. 目标

构建第二个薄壳应用 Signal Review，仅链接十个公共模块（无 Qt、无私有头、无 apps/signal_studio 依赖），证明平台可复用于信号分析/审查/导出等工具，独立于 Signal Studio GUI 应用。

## 2. 批准范围

覆盖任务文档 §6（平台化架构复用）与 superpowers 计划 MS-08（公共模块复用证明、公共-only include/link 审计）。

## 3. 实施切片

1. **signal_review 应用**（`apps/signal_review/main.cpp`）：无头 CLI，链接 `SignalStudio::Data/DSP/Compute/Core`，不链接 Qt/Visualization/Workbench/app-core。
   - WAV 导入（`read_wav_descriptor`+`open_wav`）、SC16 文件名提示导入（`calculate_data_facts`+`open_raw`）。
   - 有界窗口读取（8192 样本），实/复统计（`compute_real_stats`/`compute_complex_stats`）。
   - JSON 审查报告输出（手写，无第三方依赖）。
   - `--version` 经 `core::build_info()`。
2. **复用审计**：`tests/review/` 直接运行 `signal_review`，`PASS_REGULAR_EXPRESSION` 校验 JSON 输出（format/complex/magnitudeMean/error/version）。
3. **真实数据**：signal_review 在外部 1GB SC16 上有界读取 8192 样本并输出统计。

## 4. 验证门禁

- 四配置全量 CTest（review 测试在所有配置运行，因 signal_review 无 Qt）；
- signal_review 仅链接公共模块（CMake target_link_libraries 审计）；
- clang-format 合规；
- 完成提交后工作树干净。

## 5. 边界

- signal_review 无 GUI（无头 CLI），证明非 GUI 复用。
- CUDA 不自动安装。
