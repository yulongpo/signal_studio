# MS-04 UI 差异报告

## 1. 比较基准

比较以不可变目录
`docs/baseline/Signal-Studio-Dev-Docs/02_原型设计/原型源文件/Signal Studio交互原型_基线归档.html`
的标准渲染归档和 `页面截图/标准截图` 为准。Qt 端实际编译、运行并截图，不嵌入 HTML，
不使用 QML，不按物理像素绝对定位。

比较页面为 P01、W01、W05、P02、P03 和 P05。并排证据位于
`docs/milestones/MS-04/evidence/ui/comparison`。

## 2. 修复清单

| 优先级 | 初始差异 | 修复 |
|---|---|---|
| P0 | W01/W05 自动化只截顶层对话框，丢失完整工作台上下文 | 增加 DPR 感知合成截图，保留主窗口、遮罩和工作流窗口 |
| P0 | 最终应用缺少 P01/P03/P05 宿主页安装能力 | Workbench 增加动态页面安装/切换，最终应用安装真实产品页面 |
| P0 | Inspector 与任务中心默认折叠，P05 只有单表格，均与标准工作台结构不一致 | 默认显示右侧 Inspector 和底部任务中心；P05 改为分类、结果列表、来源详情三栏 |
| P1 | W01 把格式与采样参数隐藏在多个标签页，与标准截图双列结构不一致 | 改为同屏双列文件/格式与采样/范围布局，保留四阶段状态条 |
| P1 | W05 缺少文件路径、大小、格式和采样率，进度窗口信息密度不足 | 增加源文件事实、进度、任务状态、资源指标和完整取消说明 |
| P1 | P01/P02/P03/P05 未统一使用实际工程、数据源和结果状态 | 由 `ApplicationController` 单一状态源刷新导航、Dock、页面和状态栏 |
| P1 | P03 星座图沿用频率/时间坐标标注，不能表达 I/Q 参考关系 | 改为独立 I/Q 坐标、零轴和单位参考圆，图号按 04 顺序显示 |
| P1 | 4K、150%、200% 未覆盖最终应用页面 | 增加五档尺寸/DPI CTest 和截图脚本 |
| P2 | 对话框标题、分组边框、按钮和状态颜色与平台 QSS 不一致 | 统一深色 QSS、青色编码标题、分组边框和最小命中高度 |

修改后，基础应用范围内未发现页面缺失、工作流位置错误、明显裁剪、重叠或不可操作的
P0/P1 问题。W01/W05 的整体上下文和信息层级已与标准截图一致。

## 3. 范围差异

批准 P03 截图还展示完整窄带处理链、分类模型、算法工作区和高级星座布局；批准 P05
截图还展示多类插件结果和报告编排。这些内容分别属于 MS-05 的宽窄带处理闭环和
MS-06 的插件/模型能力。MS-04 没有伪造对应任务或结果，只交付：

- P03 的真实时域、频谱、STFT、星座和眼图容器、适用性及版本状态；
- P05 的三栏真实结果分类、索引、当前/过期、搜索、来源详情、定位和结果包导出。

因此并排图仍可看到后续里程碑能力密度差异。该差异在本文明确保留为后续范围，不把
不存在的插件、模型或解调结果伪装成 MS-04 已完成；基础应用结构、工作台外壳和真实
业务状态已对齐。

## 4. DPI 与截图结果

| 场景 | 结果 |
|---|---|
| 1280×720 | 无重叠、无关键控件裁剪 |
| 1920×1080 | 工作台、Dock、页签和图谱比例正常 |
| 3840×2160 | Windows 平台隐藏窗口按完整逻辑尺寸绘制，Canvas 和文字清晰 |
| 150% DPI | Windows 平台目标 DPR 1.5，输出 2880×1620，命中区、对话框和表格无裁剪 |
| 200% DPI | Windows 平台目标 DPR 2.0，输出 3840×2160，布局可用 |
| 默认 Windows 平台 | 清空 Qt 插件环境变量后启动通过 |

本机原生 DPR 为 1.5。证据脚本先通过默认 Windows 平台探测原生 DPR，再设置相对
`QT_SCALE_FACTOR`，使目标 DPR 与 PNG 物理尺寸可机器校验；因此最终证据保留
qwindows 的真实中文字体渲染，不使用 offscreen 字形替代。CTest 仍用 offscreen
执行不依赖桌面的布局断言，并另设默认 Windows 平台启动门禁。
