# MS-04 完成报告

日期：2026-07-23
里程碑：MS-04 Signal Studio 基础应用
状态：已验收关闭

## 1. 目标

组装 MS-01~03 公共模块为可运行、可交互的 Signal Studio 桌面应用，实现数据导入、有界加载、时间导航、基础谱图与隐藏视图停止计算。应用为薄壳，仅消费公共 API。

## 2. 完成功能

- **应用核心**（Qt-free）：`Application` 组合 TaskRuntime+FFT 后端；`parse_capture_filename`（cf/sr 单位解析）；`import_wav`/`import_raw`/`import_sc16`（设置 `requested_sample_range` 至可用帧）；`read_samples`（有界窗口）；`analyze_psd`/`analyze_stft`。
- **GUI**：`--self-test` 无头路径不构造 QApplication；QMainWindow + 菜单（File/View/Help）+ 时域/功率谱/瀑布图控件 + 状态栏；SC16 导入向导 QDialog；隐藏视图切换停止计算。
- **Designer .ui**：`main_window.ui`（Designer 可打开）。
- **真实数据**：外部 WAV（20MB）与 SC16（1GB）有界窗口读取验证。

## 3. 修改文件

新增 `apps/signal_studio/`（application/gui/main/import_wizard/main_window + .ui + CMakeLists）、`tests/app/`。修改 `CMakeLists.txt`（apps 在 tests 之前，UI 构建加 apps/与 tests/app）。完整清单见实施记录。

## 4. 架构变化
