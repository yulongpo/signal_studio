## 4. 架构与依赖变化

新增应用编排层，但十模块公共 DAG 不变。`ApplicationController` 只消费公共 C++20
契约；Qt 保持在 Visualization、Workbench 和最终应用私有实现中。后台导入和分析不
访问 `QWidget`，图形线程只消费不可变结果。

Core 新增第三方无关 Artifact 公共契约，Workbench 新增第三方无关 Inspector 状态
契约。没有新增第三方包。Qt 使用本机 6.11.1，CUDA 使用本机 Toolkit 12.4.131；
MS-04 不需要 cuDNN，未自动安装或修改 NVIDIA 组件。
