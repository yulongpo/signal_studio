# MS-04 实施记录

日期：2026-07-23
里程碑：MS-04 Signal Studio 基础应用

## 1. 交付内容

### 1.1 应用核心（`apps/signal_studio/application.hpp/cpp`，Qt-free）

- `Application`：组合 `task::TaskRuntime` + `dsp::IFftBackend`（CUDA 构造）+ `WelchPsdEstimator`/`StftProcessor`。
- `parse_capture_filename`：正则解析 `cf<数><GHz|MHz|kHz|Hz>` 与 `sr<数><GSps|MSps|kSps|Sps>`，单位换算。
- `import_wav`：`read_wav_descriptor` + `open_wav`，自动解析参数。
- `import_raw`：validate → `calculate_data_facts` 算 available_frames → 设 `requested_sample_range=(0,available_frames)` → `open_raw`（修复 RAW 路径 requested_sample_range 缺失导致 read 被拒）。
- `import_sc16`：从文件名提示 + 可选覆盖构造 int16 交错 IQ descriptor，调 `import_raw`。
- `read_samples`：有界窗口 `SampleRange::from_count` + `maximum_read_bytes` + 可取消。
- `analyze_psd`/`analyze_stft`：注入 FFT 后端，无后端时返回 `unavailable`。

### 1.2 GUI（`main.cpp`/`gui.cpp`/`main_window.cpp`/`import_wizard.cpp`）

- `main.cpp`：先扫 `--self-test`，若有则跑 `runSelfTest`（无 QApplication），否则 `signal::studio::runGui`。
- `gui.cpp`：`runGui` 构造 QApplication + `MainWindow`。
- `main_window.cpp`：QMainWindow + 菜单（File/View/Help）+ 三控件（时域/功率谱/瀑布图）+ 状态栏；`loadAndAnalyze` 导入→有界读取→`bindAnalysis`（时域系列 + PSD dB/Hz + STFT 瓦片）；`toggleSpectrum/SpectrogramVisible` 隐藏停止计算。
- `import_wizard.cpp`：QDialog 确认 SC16 cf/sr，`applyFilenameHint` 预填。
- `main_window.ui`：Designer 可打开的主窗口布局。

### 1.3 测试（`tests/app/`）

- `application_tests.cpp`：filename-parse、import-wav、import-sc16-override、import-sc16-no-sr-fails、analyze-psd、external-wav、external-sc16。
- `app.self-test`：`signal_studio --self-test` ctest 用例。
