## 5. Qt UI、截图与高 DPI

MS-04 Qt 回归实际构造最终 `SignalStudio.exe`，覆盖 P01、W01、W05、P02、P03、P05。
CTest 的布局断言覆盖 1280×720、1920×1080、3840×2160、150% 和 200% DPI，
另有默认 Windows 平台启动测试。最终证据使用 `qwindows` 和本机原生 DPR 1.5，
脚本按目标 DPR 归一化，PNG 物理尺寸均等于逻辑尺寸乘 DPR。

| 场景 | 物理截图 | 结果 |
|---|---:|---:|
| 1280×720，100% | 1280×720 | 通过 |
| 1920×1080，100% | 1920×1080 | 通过 |
| 3840×2160，100% | 3840×2160 | 通过 |
| 1920×1080，150% | 2880×1620 | 通过 |
| 1920×1080，200% | 3840×2160 | 通过 |

截图进程在 Debug 和 Release 下均正常退出；清空 Qt 插件环境变量后，构建树和安装树
均报告 `platform=windows dpr=1.5`。星座 I/Q 坐标修正后，既有 MS-03 集合在 CPU
Debug/Release 各 63/63 通过。P0/P1 视觉差异结论及后续里程碑范围差异见
`MS-04_UI差异报告.md`。
