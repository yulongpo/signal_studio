# MS-04 计划

## 1. 目标

在 MS-01～MS-03 公共平台和原生 Qt Widgets 工作台基础上，交付可运行的 Signal Studio
基础产品闭环：工程新建/打开/保存/关闭、RAW/IQ 与 WAV 导入、文件名提示显式确认、
有界异步读取、暂停/继续/取消、P01 项目首页、P02 宽带浏览、P03 检视器、P05
结果中心、基础 PSD/STFT 分析、来源可追溯结果提交和无覆盖导出。

本里程碑覆盖批准基线中直接标记为 MS-04 的 `FR-INS-001`～`FR-INS-007`、
`FR-EXP-001`～`FR-EXP-009`、`NFR-REL-001`～`NFR-REL-004`，并完成
P01、W01、W05、P02、P03、P05 所需的 MS-01～MS-03 公共契约集成。

## 2. 实施边界

- 应用层只编排公共 `SignalCore`、`SignalData`、`SignalDSP`、`SignalCompute`、
  `SignalTaskRuntime`、`SignalVisualization` 和 `SignalWorkbench` 契约。
- 导入和分析在任务运行时工作线程执行；后台任务不直接访问 `QWidget`。
- 大文件只按用户配置的有界范围和块大小读取，工程仅保存相对资源链接及源版本指纹，
  不复制或修改外部录制。
- 文件名中的 `cf`、`sr`、`.sc16` 仅作为待确认提示；未经用户确认不得生成解释描述符。
- P02/P03 图谱绑定真实读取和 DSP 结果；眼图在缺少符号率与同步来源时明确显示不可用，
  不生成伪结果。
- 结果包包含来源、工程、算法、参数、通道版本和单位，写入采用暂存目录后原子提交，
  禁止静默覆盖。
- Qt 仍只存在于 Visualization、Workbench 和最终应用私有实现中，公共平台头保持无
  Qt/第三方类型。
- 本里程碑不实现 MS-05 的宽窄带联动、高级 DDC/滤波/重采样工作流，也不进入 MS-05。

## 3. 需求与验证映射

| 需求组 | 实现 | 主要验证 |
|---|---|---|
| FR-INS-001～007 | 检视器视图、适用性、单位、预处理、参数版本、布局降级、通道状态 | 具名契约测试、P03 UI 回归 |
| FR-EXP-001～009 | CSV/JSON/PNG/RAW/WAV/插件格式、元数据、无覆盖、批量清单 | 结果包单元与集成测试、P05 UI 回归 |
| NFR-REL-001 | 混合工程/导入/分析/结果操作的长稳态运行 | 可配置稳态测试及资源趋势记录 |
| NFR-REL-002 | 100 次工程打开/关闭和资源释放 | 循环恢复测试、句柄/内存检查 |
| NFR-REL-003 | 无权限、满盘等价失败、损坏缓存/暂存恢复 | 故障注入测试、源文件哈希复核 |
| NFR-REL-004 | 结果校验和与损坏检测 | SHA-256 篡改检测测试 |
| P01/W01/W05/P02/P03/P05 | 原生 Qt Designer 页面和真实业务编排 | 启动、交互、截图、高 DPI、平台插件测试 |
| 外部数据 | WAV、约 1 GB 和约 4 GB 录制的有界读取 | 外部数据 E2E；缺失时准确跳过 |

批准测试资料未提供 D4，验证中必须记录“基线未提供”，不得制造或将其记为通过。
100 GB 场景按用户指令不创建物理大文件，使用指定约 1 GB 录制的有界重复访问验证
逻辑大范围调度。

## 4. 交付步骤

1. 完成应用核心、结果包和检视器公共契约，实现工程、导入、分析和结果闭环。
2. 用 Qt Designer `.ui` 实现 P01、W01、W05、P03、P05，并安装到现有工作台。
3. 提供 Qt 创建前运行的 `--self-test`、可自动化截图入口和 VS Code 调试入口。
4. 增加 20 项直接需求测试以及工程恢复、取消/重试、外部数据、UI、高 DPI 和来源安全测试。
5. 执行 CPU/CUDA Debug/Release 构建测试、安装消费测试和 Windows 启动验证。
6. 生成 P01、W01、W05、P02、P03、P05 预览截图并核对批准原型结构。
7. 更新中文架构、UI、测试、决策、用户说明、需求追踪和变更日志。
8. 审计基线与测试数据未变化、清理废弃生成内容、提交并推送 MS-04。

## 5. 完成门禁

- 20/20 项直接 MS-04 需求均有真实实现、自动测试和验收记录。
- 工程、导入、P01/P02/P03/P05、基础 PSD/STFT、结果提交/查询/导出闭环可运行。
- 导入/分析不阻塞 UI 主线程；暂停、继续、取消和有效只读前缀行为可复现。
- supplied WAV、约 1 GB 和约 4 GB 数据均完成有界验证，原文件校验值不变。
- CPU Debug/Release、CUDA 12.4 Debug/Release（可用时）、全量 CTest、安装消费与
  默认 Windows Qt 平台启动通过。
- 1280×720、1920×1080、3840×2160、150% 和 200% DPI 页面无明显裁剪或重叠。
- 稳定性、100 次恢复、故障注入和校验和损坏检测完成并记录真实结果。
- `CMakeUserPresets.json` 路径无重复项，废弃生成目录清理，提交后工作树干净。
- 按用户指令，MS-04 完成后停止，获得确认前不执行 MS-05。
