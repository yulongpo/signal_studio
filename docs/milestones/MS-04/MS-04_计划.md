# MS-04 计划

## 1. 目标

实现 Signal Studio 桌面应用，组装 MS-01~03 公共模块为可运行、可交互的 Windows Qt 应用：数据导入向导（WAV 自动解析/SC16 文件名提示）、有界加载与读取、时间导航、基础谱图（时域/功率谱/瀑布图）、Inspector/状态栏、工程管理基础、隐藏视图停止计算。应用为薄壳，仅消费公共 API。

## 2. 批准范围

覆盖任务文档 §9.1（应用工作台基础）、§9.2（数据导入：WAV/RAW、实/复、IQ 交错、位宽、采样率/中心频率、参数校验、文件名提示、有界读取）、§9.3（大文件有界窗口）、§9.4（时域/FFT/PSD/STFT/瀑布图基础）的 P0/P1 闭环；§7.1 主要页面（主窗口、导入向导、关于）以 Qt Designer `.ui` + 程序化构建提供。

## 3. 实施切片

1. **应用核心**（`apps/signal_studio/application.hpp/cpp`，Qt-free）：`Application` 组合 TaskRuntime + FFT 后端 + 适配器；`parse_capture_filename`（cf/sr 单位解析）、`import_wav`/`import_raw`/`import_sc16`（设置 `requested_sample_range` 至可用帧）、`read_samples`（有界窗口）、`analyze_psd`/`analyze_stft`。
2. **GUI**（`main.cpp`/`gui.cpp`/`main_window.cpp`/`import_wizard.cpp`）：`--self-test` 无头路径不构造 QApplication；GUI 路径 QMainWindow + 菜单（File/View/Help）+ 三个可视化控件（时域/功率谱/瀑布图）+ 状态栏；导入向导 QDialog 确认 SC16 参数；隐藏视图切换（View 菜单）停止计算。
3. **Designer .ui**：`main_window.ui`（Designer 可打开，布局/菜单/动作/状态栏）。
4. **测试**：`tests/app/`（文件名解析、WAV/SC16 导入、有界读取、PSD、外部 WAV/SC16 集成、self-test）。

## 4. 验证门禁

- 无界面 Debug/Release（UI off，不含应用）与 UI Debug/Release（CUDA）四配置全量 CTest；
- 应用测试仅 UI 构建注册：文件名解析、WAV/SC16 导入、有界读取、PSD、外部数据集成、`signal_studio --self-test`；
- 外部 WAV（20MB）与 SC16（1GB/4GB）仅以有界窗口读取，不读全文件，找不到时 SKIP 不误报；
- 公共 API 不暴露 QWidget；依赖 DAG 不变；应用仅链接公共库；
- `clang-format`/`clang-tidy`/高警告级别通过；完成提交后工作树干净。

## 5. 边界

- 宽窄带联动、任务中心、结果中心、插件/模型留待 MS-05/MS-06。
- 像素级视觉回归、DPI 矩阵、28x28 命中目标回归留待 MS-07。
- CUDA 不自动安装。
