## 根因与本地修正

CMake 和工作流已声明最低 Qt 6.10.3，但 Visualization 与 Workbench 仍包含 `QT_VERSION_CHECK(6, 11, 0)`。这把本机 Qt 6.11.1 身份错误提升为源码最低版本，导致 CI 在已成功配置 Qt 6.10.3 后编译失败。

当前修正将以下位置统一为最低支持 Qt 6.10.3：

- CMake 配置和安装包依赖；
- Visualization 与 Workbench 编译期守卫及明确诊断；
- 本机 Qt 覆盖/发现逻辑；
- CI 环境与工作流校验器；
- 项目依赖锁兼容性字段和依赖报告；
- `verification.portable_config` 静态扫描。

不可变 BL1.0 的 qtbase 6.11.1#1、qttools 6.11.1 选择未修改，本机 6.11.1 检测证据也未修改。它们与源码最低支持版本是不同语义。
