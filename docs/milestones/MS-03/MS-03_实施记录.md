# MS-03 实施记录

日期：2026-07-23
里程碑：MS-03 SignalVisualization 与 SignalWorkbench
基线：BL1.0；权威依据 `API-VIS-001`~`006`、`API-WB-001`~`004`、任务文档 §7.3

## 1. 目标

交付可复用 Qt 可视化控件与 Workbench 外壳，公共 API 不暴露 QWidget，遵守依赖 DAG（Visualization/Workbench 私有链接 Qt）。

## 2. 交付内容

### 2.1 SignalVisualization（Qt-free 公共头 + Qt 私有实现）

- `data_series.hpp`：`IDataSeries` + `RealSeries`/`SpectrumSeries`/`SpectrogramSeries`/`ComplexSeries`（Qt-free 值类型）。
- `viewport.hpp`：`ViewportRange`（set_window/zoom/pan/clamp/订阅/通知）、`FrequencyViewport`、`TimeViewport`（`LoadedDataRange`，范围=实际读入长度）、`ViewportController`、`frequency_unit_for`/`format_frequency`（Hz/kHz/MHz/GHz 自适应，Hz 级精度）。
- `chart_view.hpp`：`IChartView`（bind/set_visible/native_widget/needs_data/set_needs_data_callback）、`ChartViewKind`。隐藏视图 `needs_data()` 返回 false（隐藏停止计算不变量）。
- `overlay.hpp`：`OverlayModel`（`Cursor`/`Selection`/`Measurement`，选区方向校验）。
- `views.hpp`：`ColorScale`（viridis/magma/turbo/grayscale/inferno）+ `color_rgb` 显示映射、`TimeNavigator`、工厂 `make_time_waveform_view`/`make_spectrum_view`/`make_spectrogram_view`/`make_constellation_view`/`make_eye_diagram_view`。
- `views.cpp`（Qt 私有实现）：`BaseChartWidget : QWidget, IChartView`（QPainter 绘制、无 Q_OBJECT 故无需 MOC）+ 5 个具体控件：时域波形（折线）、功率谱（freq vs dB）、瀑布图（色阶矩阵）、星座图（IQ 散点）、眼图（符号叠加）。工厂在无 QApplication 时返回 `unavailable`。

### 2.2 SignalWorkbench（Qt-free 公共头 + Qt 私有实现）

- `workbench.hpp`：`IServiceRegistry`、`IPanel`/`IPanelFactory`/`PanelFactory`/`PanelContext`/`PanelRegion`、`ICommandRegistry`、`IDiagnosticsProvider`/`ConfigurableDiagnosticsProvider`/`DiagnosticsSnapshot`、`make_*` 工厂。
- `workbench.cpp`：内部 `ServiceRegistry`/`CommandRegistry` + 公共 `PanelFactory`/`ConfigurableDiagnosticsProvider` 实现。诊断的 compute/cuda 字段由宿主注入（Workbench 不依赖 Compute，DAG 不允许）。

## 4. 架构与依赖变化

- 依赖 DAG 不变。Visualization/Workbench 仍 PRIVATE 链接 `Qt6::Core/Widgets`；公共头不含 QWidget（`native_widget()` 返回 `void*`）。
- Visualization/Workbench 测试仅在 `SIGNAL_STUDIO_BUILD_UI` 时注册；offscreen Qt 经 `QT_QPA_PLATFORM=offscreen` + `QT_PLUGIN_PATH` 环境提供。
- 无新增第三方依赖。
