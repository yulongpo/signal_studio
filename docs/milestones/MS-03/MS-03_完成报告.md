## 1. 目标

实现可复用 Qt 可视化控件与 Workbench 外壳，公共 API 不暴露 QWidget，遵守依赖 DAG。

## 2. 完成功能

- **Visualization**：5 个真实 QPainter 控件（时域波形/功率谱/瀑布图/星座图/眼图）、`IChartView` 抽象、共享 `ViewportController`（时间/频率轴）、`OverlayModel`（游标/选区/测量）、`ColorScale` 显示映射、`TimeNavigator`、频率单位自适应+Hz 级精度、隐藏停止计算。
- **Workbench**：`IServiceRegistry`、`PanelFactory`、`ICommandRegistry`、`ConfigurableDiagnosticsProvider`。
