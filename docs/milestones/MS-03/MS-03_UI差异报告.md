# MS-03 Qt UI 原型差异报告

## 1. 对比基准

本轮以不可变基线目录 `docs/baseline/Signal-Studio-Dev-Docs/02_原型设计` 中的标准截图、页面清单、交互规格、状态说明、视觉规范和图表规范为唯一视觉依据。对比页面为 P02 宽带浏览、P04 任务中心和 P07 设置与诊断。

受当前浏览器安全策略限制，本地 `file://` HTML 原型不能在浏览器工具中打开；未绕过该限制，也未改用未批准的浏览器或本地服务器。标准截图是该 HTML 的批准渲染归档，因此本轮以标准截图逐像素尺寸对齐，并记录该项工具限制，不声称重新运行了 HTML。

## 2. 修复前差异

| 优先级 | 差异 | 影响 |
|---|---|---|
| P0 | 缺少左侧项目与数据源导航器 | P02 主结构与基线不同 |
| P0 | P04 任务中心和 P07 设置与诊断没有完整中心页面 | 标准截图对应页面缺失 |
| P0 | Inspector、任务和结果 Dock 默认展开并占据中心空间 | 图谱区域位置和页面层级错误 |
| P1 | 菜单、工具栏、页签、图谱控制条的高度和分区不一致 | 首屏纵向比例明显偏离 |
| P1 | 时域、PSD、STFT 使用近似平均高度 | STFT 主视图占比不足 |
| P1 | 1280×720 下控制条分成两行且低优先控件挤压 | 小窗口可读性和命中区不稳定 |
| P1 | P07 表单与运行时信息区宽度比例错误 | 设置页主体过窄 |
| P2 | 色彩、边框、选中态、字体、底部状态区和右侧属性入口不统一 | 视觉层级与批准主题不一致 |

修复前 P02 截图保存在 `evidence/ui-alignment/before`，未为当时不存在的 P04/P07 页面伪造“修复前”截图。

## 3. 已完成修复

- 使用原生 Qt 6 Widgets、现有 Designer `.ui`、布局管理器和统一 QSS 重建应用菜单条、紧凑工具栏、左侧导航、中心页签、右侧折叠属性入口和底部任务/结果/日志/标记条。
- P02 恢复单行控制条以及时域、PSD、STFT 的基线式纵向比例；PSD 与 STFT 继续共享频率视口，既有交互和公共 API 未被破坏。
- 新增原生 P04、P07 中心页面，页面使用真实 Qt 表格、进度、表单和运行时信息控件，不嵌入 HTML、不迁移 QML。
- 1280×720 时只隐藏重复或低优先级工具栏入口，功能仍可通过菜单或主工具栏调用；所有可见应用按钮保持至少 28×28 逻辑像素。
- 主窗口响应 `DevicePixelRatioChange` 与 `ScreenChangeInternal`，触发布局几何更新和重绘；鼠标事件继续使用逻辑坐标，截图和 Canvas 由 Qt DPR 感知绘制。
- 截图脚本固定中文字体目录，生成逻辑尺寸、物理尺寸、请求缩放和实际 DPR 清单；新增标准截图对比脚本。

## 4. 最终差异结论

P0 差异全部关闭。P1 的页面结构、主要区域比例、图谱层级、字体和主题色差异全部关闭。剩余差异属于 P2：Qt 原生控件与浏览器 CSS 在字形抗锯齿、下拉箭头和标准图标细节上存在平台渲染差异；演示帧的具体波形数据与 HTML 固定样例不同，但轴向、图层、Selection、色标和页面结构一致。

对比证据：

- `evidence/ui-alignment/comparison/MS-03_P02_基线_修复前_修复后.png`
- `evidence/ui-alignment/comparison/MS-03_P04_基线_修复后.png`
- `evidence/ui-alignment/comparison/MS-03_P07_基线_修复后.png`

结论：不存在明显 P0、P1 视觉差异，满足本轮 MS-03 原型对齐门禁。
