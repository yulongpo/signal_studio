# MS-03 计划

## 1. 目标

实现 SignalVisualization 与 SignalWorkbench 生产契约，交付可复用 Qt 图表控件（时域波形/功率谱/瀑布图/星座图/眼图）、共享视口控制器、游标/选区/测量覆盖层、多色阶显示映射，以及 Workbench 服务注册/面板工厂/命令注册/诊断外壳。Qt 私有于 Visualization/Workbench，公共 API 不暴露 QWidget。

## 2. 批准范围

覆盖 `API-VIS-001`~`006` 与 `API-WB-001`~`004`，以及任务文档 §7.3 图表交互要点（时间导航=实际读入长度、共享频率轴、dB/Hz 纵轴、瀑布时间轴、滚轮缩放、右键框选/反向重置、隐藏停止计算、频率单位自适应、Hz 级精度）。

## 3. 实施切片

1. **数据系列**（Qt-free）：`IDataSeries` + `RealSeries`/`SpectrumSeries`/`SpectrogramSeries`/`ComplexSeries`。
2. **视口**（Qt-free）：`ViewportRange`（set_window/zoom/pan/clamp/订阅）、`FrequencyViewport`、`TimeViewport`、`ViewportController`、`LoadedDataRange`、频率单位自适应（Hz/kHz/MHz/GHz）与 Hz 级格式化。
3. **图表视图**：`IChartView`（bind/set_visible/native_widget/needs_data）、`ChartViewKind`、工厂 `make_*_view()`；Qt widget 实现（`TimeWaveformWidget`/`SpectrumWidget`/`SpectrogramWidget`/`ConstellationWidget`/`EyeDiagramWidget`）经 QPainter 真实绘制；隐藏视图 `needs_data()` 返回 false（隐藏停止计算）。
4. **覆盖层**：`OverlayModel`（游标/选区/测量）。
5. **色阶**：`ColorScale`（viridis/magma/turbo/grayscale/inferno）显示映射。
6. **Workbench**：`IServiceRegistry`、`IPanelFactory`/`PanelFactory`、`ICommandRegistry`、`IDiagnosticsProvider`/`ConfigurableDiagnosticsProvider`（宿主注入 compute 信息，因 Workbench 不依赖 Compute）。

## 4. 验证门禁

- 无界面 Debug/Release（UI off，不含 Visualization/Workbench）与 UI Debug/Release（CUDA）四配置全量 CTest；
- Visualization/Workbench 测试仅在 UI 构建注册：视口数学、频率单位/格式化、覆盖层、数据系列、色阶、视图工厂（offscreen Qt）、服务/命令/面板/诊断；
- 公共头无 QWidget/Qt 类型（PIMPL + `native_widget()` 返回 `void*`）；依赖 DAG 不变；Qt 私有链接；
- `clang-format`/`clang-tidy`/高警告级别通过；
- 文档基线/外部数据不变；完成提交后工作树干净。

## 5. 边界

- 可视化为真实 QPainter 绘制控件，但像素级视觉回归/Designer .ui 留待 MS-04（Signal Studio 应用）集成。
- 28x28 命中目标、DPI 矩阵（1280×720/1366×768/1600×900）回归留待 MS-04/MS-07。
- CUDA 不自动安装。
