# MS-03 计划

## 1. 目标

在不改变 BL1.0 十模块依赖 DAG 的前提下，把 `SignalVisualization` 和 `SignalWorkbench` 从模块骨架升级为可安装、可复用、公共头无 Qt/第三方类型的生产平台，并交付真实 Qt Widgets 原型界面。范围覆盖
`FR-VIS-001`～`FR-VIS-018`、`FR-NAV-001`～`FR-NAV-015`、`FR-SEL-001`～`FR-SEL-008`、
`NFR-USA-001`～`NFR-USA-007`、`FR-VIS-101` 和 `FR-WB-101`。

## 2. 实施边界

- `SignalVisualization` 公共层负责视口、原子帧、图层、显示映射、Selection、测量、可见性、图表布局和截图契约。
- Qt 私有层提供时域、PSD、STFT/瀑布、频谱、星座、眼图、导航条、交互 Canvas 和可访问性实现。
- `SignalWorkbench` 公共层提供服务、命令、面板、主题、参数、诊断、布局和内容注入契约。
- Qt 私有层提供主窗口、菜单、工具栏、Dock、Inspector、任务中心、结果中心、设置、诊断、状态栏和布局持久化。
- 演示程序可以显式注入演示内容；生产库默认不得硬编码录制、任务、结果或伪造状态。
- Qt 继续只作为 Visualization/Workbench 的私有实现依赖；无界面构建不得发现 Qt。
- 本里程碑不实现 MS-04 的真实产品数据导入页面和基础分析业务编排，也不进入 MS-04。

## 3. 交付步骤

1. 核验不可变基线、本机 MSVC、Ninja、Qt 6.11.1、CUDA Toolkit 12.4.131 和现有模块边界。
2. 定义并实现两个模块的纯 C++20 公共契约。
3. 实现真实 Qt Widgets 可视化工作区、交互和工作台。
4. 提供由生产构建使用、可在 Qt Designer 中打开的 `.ui` 文件。
5. 增加复用演示程序、自动截图脚本和 1280×720、1600×900、1920×1080、200% DPI 预览。
6. 修复构建树和安装树的 Qt 运行时、平台插件与 `qt.conf` 闭包。
7. 增加 50 项具名需求测试、6 项 UI/平台回归、模块契约和安装消费覆盖。
8. 执行 CPU/CUDA、Debug/Release、Windows 无界面矩阵和质量检查；不执行 Ubuntu 24.04 测试。
9. 更新中文核心文档、里程碑证据和变更日志，创建里程碑提交并验证 Windows GitHub Actions。

## 4. 完成门禁

- 50/50 项 MS-03 需求通过，且不存在占位、伪结果或禁用失败测试。
- 1280×720、1600×900、1920×1080 和 200% DPI 均能显示可用布局。
- 默认 Windows Qt 平台启动、截图、安装消费者和 Designer `uic` 生成全部通过。
- CPU Debug/Release 全量 CTest、CUDA Debug/Release MS-03 集合和无界面 Debug/Release 全量 CTest 通过。
- 变更 C/C++ 文件格式检查、生产实现静态分析、公共头隔离、依赖锁、基线和工作流校验通过。
- `CMakeUserPresets.json` 重复生成字节一致，各路径变量无重复项。
- 废弃生成目录清理，基线与外部数据不变，提交后工作树干净。
- 按用户指令，MS-03 完成后暂停，获得确认前不执行 MS-04。
