# P01～P05 基础产品界面说明

## P01 项目首页

P01 显示当前工程、只读数据源、最近工程和系统状态，提供新建、打开、保存和导入入口。
工程树、工具栏、中心页签、默认可见 Inspector、底部任务中心和状态栏使用工作台统一
布局；关闭 Inspector 后才显示边缘恢复入口。页面没有演示伪数据，内容均由当前
`ApplicationController` 状态注入。

## W01 导入信号

W01 是原生 Qt Widgets 对话框。文件与格式、采样布局、参数校验和确认导入四个阶段在
同一响应式布局中可见，便于与批准原型逐项核对。文件名提示必须明确确认；预览、读取
和解析通过后台任务运行，界面线程只接收状态和不可变结果。

## W05 数据加载任务

W05 显示文件名、路径、大小、信号格式、采样率、进度和任务状态，并提供暂停/继续与
取消。取消语义以完整样本帧为边界，源录制和已保存工程始终保持不变。

## P02 宽带浏览

P02 复用 MS-03 的时域、PSD、STFT 生产 Canvas。应用把真实导入描述符、实际可用范围、
PSD/STFT 参数和当前代际绑定到页面；布局、频率联动、DPI 和输入坐标转换继续遵守
Visualization 公共契约。

## P03 检视器

P03 为独立 AnalysisChannel 保存 Inspector 状态，提供时域、频谱、STFT、星座和眼图
容器，并显示适用条件、单位、预处理和参数版本。上游数据或通道版本变化后，关联结果
进入过期状态；星座图使用 I/Q 坐标、零轴和单位参考圆，不复用频率/时间坐标。布局
模板恢复时若缺少插件，页面明确降级而不伪造视图。

MS-4.5 在 Inspector 中安装 Qt Designer 分析设置面板。基础/高级模式编辑真实频谱、
PSD、STFT、平滑和分析前滤波参数，显示 bin spacing、RBW、时间步长、内存与性能估计；
任务在后台可取消，旧请求不能覆盖新视图。显示参数独立映射，不重算 DSP。该面板不
包含 MS-05 的 Selection 建通道、DDC、重采样输出和宽窄带继承。

## P05 结果中心

P05 使用分类、结果列表、来源详情三栏，可按当前/过期状态和文本过滤真实结果，显示
完整来源版本并支持定位和导出。结果分类涵盖测量、估计、识别、解调和导出；MS-04
实现统一结果包与基础列表，后续插件提供的高级分类格式通过显式格式声明扩展，不改变
Core 公共契约。

## DPI 与截图

所有页面使用布局管理器和逻辑像素，不按物理像素写绝对坐标。自动回归覆盖
1280×720、1920×1080、3840×2160、125%、150%、175% 和 200% DPI。W01/W05 截图把主窗口、
背景遮罩和工作流对话框合成为完整页面。视觉证据使用 Windows 平台隐藏窗口并按本机
原生 DPR 归一化目标缩放，以便保留真实中文字体并与批准 HTML 标准截图并排比较。
