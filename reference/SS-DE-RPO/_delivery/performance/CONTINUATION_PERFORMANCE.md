# SS-DE-RPO 最终代表性性能对照

Release，实际原始 20 MS/s IQ 的 20 窗口 Sample 用例；FFT65536、10 frames/hop5、time hop0.00025s、batch2、raw-head OFF、8 GiB 授权。基线产品7220b2e，计时校准e52c3a9；新版运行代码与11c3b1c一致。构建/其它开发进程停止后串行执行。

每侧驻留运行先排除一次预热，再测3次；始终使用独立 Worker/engine/context，共4个不同 Worker PID。应用状态、OS缓存未清空和每次模型初始化分别记录，不称 TensorRT context 热复用。点击前的源加载/图谱稳定不计入点击耗时；正式 slot 被观察到时停止计时，随后的工程重开为未计时验证门槛。

重开后的3份冷测工程及最后一次驻留工程，每侧4份，共8份，当前正式 Algorithm 对象的9个 observation/segments 和质量字段精确相等；忽略运行ID和导入标签。全部14次运行（包括两次排除的预热）均成功正式发布/重开，不用失败作分母。这是该代表用例结果，不外推到2044窗口或现场RF吞吐。
