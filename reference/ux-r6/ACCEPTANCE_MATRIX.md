# UX-R6 验收矩阵

| ID | 场景 | 必须验证 |
|---|---|---|
| BUG-01-A | FFSCN 65536、0.25ms、Sample、>180窗口 | 记录阶段和错误；成功完结或给出真实可解释失败，不误报完成 |
| BUG-01-B | 同数据改 batch/ROI/时长 | 非固定窗口阈值的复现及预算/异常分支回归 |
| BUG-01-C | 完成前取消、worker 异常、checkpoint 不可用 | 预览与正式数据隔离，错误真实可见，工程可重开 |
| BUG-02-A | 模型/参数编辑、撤销草稿、切页 | 旧正式检测结果始终保留并可查看 |
| BUG-02-B | 新运行成功、0 检出 | 原子替换旧正式结果，0 检出后为空 |
| BUG-02-C | 失败/取消/崩溃 | 上一次完整正式结果不被覆盖 |
| BUG-02-D | 重开 .ssproj / 发现旧任务文件 | 只有当前正式结果出现，旧结果不复活 |
| PERF-A | 同数据 batch 1/2/4/8/16（按 Engine 支持范围） | 真实 GPU enqueue 个数、吞吐、首次延迟、资源回退、显存 |
| PERF-B | Sample 长连续信号 0.1/1/10/60s | 分块 vs 旧算法时间、内存、边界误差、活动段质量 |
| PERF-C | 重叠/短突发/低 SNR/跳频/空白 | 不丢检、不乱合并、不制造时间段，定量性能和精度 |
| STREAM-A | 连续跨批次同一信号 | 单一稳定轨迹 ID、持续更新、最终可靠闭合 |
| STREAM-B | 两信号接近/交叉/断续 | 区分、合并关系与不确定性，避免错误吞并 |
| STREAM-C | 高频 UI 更新/切换文件 | 节流、没有全图谱重算、不阻塞绘制、无旧事件穿透 |
| DATA-A | 原始标签与人工标记 | 两者不会被算法替换删除，来源证据和编辑权限保持 |
| DATA-B | 已转换人工标记、旧窄带通道 | 替换检测后仍可用，快照可保存重开 |
| PUB-A | Review Agent 对最终 HEAD | 独立审核 `APPROVED` 之前没有远端 push |

每项记录：执行时间、环境与 GPU/Engine、数据来源（真实/合成）、期望、实际、日志/截图路径、PASS/FAIL/BLOCKED、根因/限制。不能将上次版本测试直接称为本次版本测试。
