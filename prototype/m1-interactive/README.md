# Signal Studio M1 Interactive Prototype

这是 Signal Studio M1「宽带浏览基础」的离线 HTML5 交互原型。页面使用原生 JavaScript、CSS 和 Canvas/SVG 友好的真实 UI 元素构建，所有 IQ、FFT、STFT、缓存和任务数据均为明确标注的确定性模拟数据，不会读取用户文件。

## 运行

在仓库根目录执行：

```powershell
python -m http.server 8080 --directory prototype/m1-interactive
```

然后打开 <http://localhost:8080>。原型不依赖 CDN、在线字体、远程 API、数据库或后端服务。

## 连续演示路径

1. 空状态点击「打开 IQ 文件」。
2. 在四步导入向导中修改参数，故意清空采样率可查看字段级错误，再恢复并完成预览与校验。
3. 点击「确认导入」，查看读取文件信息、时域概要、FFT、STFT 和更新显示任务。
4. 进入宽带工作区，使用选择、框选缩放、平移、单/双游标、时频框选、滚轮缩放和联动开关。
5. 点击项目树节点，在右侧属性面板编辑、应用或重置属性，并切换图层。
6. 在底部任务/日志面板或「任务与日志」页面查看筛选、搜索、暂停、继续、取消和重试。
7. 点击「模拟读取错误」，使用错误面板中的「重试」恢复任务。

## 页面范围

- 空状态主窗口
- RAW IQ 导入向导（参数、预览、校验、完成）
- 宽带时域 / 频谱 / STFT 工作区
- 图谱交互、低分辨率加载、错误和恢复状态
- 项目树与可编辑属性面板
- 任务、日志与动态状态栏

窄带通道、调制识别、星座图、眼图、多通道比较等 M2/M3 能力仅保留禁用入口或后续版本提示。
